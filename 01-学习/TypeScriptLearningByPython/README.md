# TypeScript 学习路径（Python 迁移版）

> 📌 本学习路径基于 [[03-AI工具/AI协作方法论/技术学习路径创建方法论]] 的方法论构建，专为**有 Python 经验的开发者**设计。以 Python 为锚点，逐篇映射 Python 概念到 TypeScript 等价物，由浅入深完成迁移。

## 快速开始

1. 安装 Node.js ≥ 20 LTS 和 TypeScript ≥ 5.5
2. 打开 [[00-TypeScript 总览索引（Python 迁移版）]] 查看完整路径和角色导航
3. 按角色选择路线（🐍 Python 后端 / 🔄 Python 全栈 / 🚀 Python 数据科学）
4. 按周顺序学习，完成每篇的 🎯 自检清单（🟢/🟡/🔴）
5. 每个阶段末尾完成复习检查点
6. 完成毕业项目 v1→v5

## 学习路径概览

| 阶段 | 笔记数 | 预计学时 | 难度 | 核心目标 |
|------|--------|---------|------|---------|
| 第一周：会用 | 3 + 1 复习 | 12h | ⭐→⭐⭐⭐⭐ | 建立 Python→TS 概念映射，掌握 TS 独有的类型系统 |
| 第二周：深入 | 3 + 1 复习 | 11h | ⭐⭐⭐ | 理解异步模型差异，掌握工程化体系，建立双向对比认知 |
| 第三周：实战 | 2 + 1 复习 | 10h | ⭐⭐⭐⭐ | 10 大场景实战，面试对答如流 |
| 毕业项目 | 5 版本 | 15h | ⭐⭐→⭐⭐⭐⭐ | 从零搭建完整 TS 项目 |

**总学时**：约 27h（核心笔记）+ 15h（毕业项目）= 约 42h
