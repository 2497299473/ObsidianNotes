## 🎯 v2 目标

在 v1 的基础上，用 **interface 重构类型**、用 **泛型抽象通用 Repository 模式**——这是 Python `TypeVar` 到 TS 泛型的迁移实战。

> [!important] v2 的核心改造
> - ✅ 将全局函数 + 全局数组重构为 `Repository<T>` 泛型类
> - ✅ 使用 `Omit`/`Partial`/`Pick` 等工具类型创建 DTO
> - ✅ 用 `keyof T` 实现类型安全的排序函数
> - ❌ 还不引入异步、模块拆分、测试

---

## 📋 Python 等价代码

```python
from typing import Generic, TypeVar, Protocol

T = TypeVar("T", bound="Identifiable")

class Identifiable(Protocol):
    id: int

class Repository(Generic[T]):
    def __init__(self):
        self._items: list[T] = []
        self._next_id = 1

    def add(self, item: Omit[T, "id"]) -> T:  # Python 无 Omit，需手动
        ...

    def find(self, item_id: int) -> T | None:
        return next((t for t in self._items if t.id == item_id), None)

    def list_all(self) -> list[T]:
        return self._items

    def remove(self, item_id: int) -> bool:
        self._items = [t for t in self._items if t.id != item_id]
        return True
```

## ✏️ 你的任务

### 第一步：定义泛型 Repository 接口

```typescript
interface Identifiable {
  id: number;
}

// 泛型约束 T extends Identifiable
interface Repository<T extends Identifiable> {
  findAll(): T[];
  findById(id: number): T | undefined;
  create(item: Omit<T, "id">): T;
  update(id: number, updates: Partial<T>): T | undefined;
  delete(id: number): boolean;
}
```

### 第二步：实现 MemoryRepository

```typescript
class MemoryRepository<T extends Identifiable> implements Repository<T> {
  private items: T[] = [];

}
```

### 第三步：用工具类型创建 DTO

```typescript
// 创建任务（不含 id 和 createdAt）
type CreateTaskInput = ?;  // 用 Omit

// 更新任务（部分字段可选）

```

## ✅ 验收标准

| 检查项 | 方式 |
|--------|------|
| `Repository<T>` 泛型约束正确 | `T extends Identifiable` |
| `MemoryRepository` 实现所有接口方法 | 编译通过 |
| `Pick`/`Omit`/`Partial` 使用正确 | DTO 类型编译通过 |
| `sortBy` 的 key 被类型约束 | `sortBy(tasks, "invalid")` 应报错 |
| 通过 `tsc --strict` 零错误 | 编译通过 |

```typescript
// === 类型定义 ===
type Priority = "low" | "normal" | "high";
type Filter = "all" | "completed" | "pending";

interface Identifiable {
  id: number;
}

interface Task extends Identifiable {
  id: number;
  title: string;
  completed: boolean;
  priority: Priority;
  createdAt: Date;
}

interface Stats {
  total: number;
  completed: number;
  pending: number;
}

// 工具类型创建 DTO
type CreateTaskInput = Omit<Task, "id" | "createdAt" | "completed"> & {
  completed?: boolean;
};
type UpdateTaskInput = Partial<Omit<Task, "id" | "createdAt">>;
type TaskSummary = Pick<Task, "id" | "title" | "completed">;

// === 泛型 Repository ===
interface Repository<T extends Identifiable> {
  findAll(): T[];
  findById(id: number): T | undefined;
  create(item: Omit<T, "id">): T;
  update(id: number, updates: Partial<T>): T | undefined;
  delete(id: number): boolean;
}

class MemoryRepository<T extends Identifiable> implements Repository<T> {
  private items: T[] = [];
  private nextId = 1;

  findAll(): T[] {
    return [...this.items]; // 返回副本，避免外部修改
  }

  findById(id: number): T | undefined {
    return this.items.find((item) => item.id === id);
  }

  create(data: Omit<T, "id">): T {
    const item = { ...data, id: this.nextId++ } as T;
    this.items.push(item);
    return item;
  }

  update(id: number, updates: Partial<T>): T | undefined {
    const item = this.findById(id);
    if (!item) return undefined;
    Object.assign(item, updates);
    return item;
  }

  delete(id: number): boolean {
    const idx = this.items.findIndex((item) => item.id === id);
    if (idx === -1) return false;
    this.items.splice(idx, 1);
    return true;
  }
}

// === 类型安全的工具函数 ===
function sortBy<T, K extends keyof T>(items: T[], key: K, order: "asc" | "desc"): T[] {
  return [...items].sort((a, b) => {
    const va = a[key];
    const vb = b[key];
    if (va < vb) return order === "asc" ? -1 : 1;
    if (va > vb) return order === "asc" ? 1 : -1;
    return 0;
  });
}

function filterBy<T>(items: T[], predicate: (item: T) => boolean): T[] {
  return items.filter(predicate);
}

// === 使用 ===
const repo = new MemoryRepository<Task>();

const task1 = repo.create({
  title: "学习泛型",
  completed: false,
  priority: "high",
  createdAt: new Date(),
} as Omit<Task, "id">);

const task2 = repo.create({
  title: "写测试",
  completed: false,
  priority: "normal",
  createdAt: new Date(),
} as Omit<Task, "id">);

// sortBy 的类型安全：key 只能是 Task 的属性名
const sorted = sortBy(repo.findAll(), "priority", "desc"); // ✅
// const sorted2 = sortBy(repo.findAll(), "invalid", "desc"); // ❌ 编译报错

// DTO 类型安全
const summary: TaskSummary = { id: 1, title: "学习泛型", completed: false };
const update: UpdateTaskInput = { completed: true }; // 只能包含 Task 的部分字段
```

> **Python 对比**：Python 的 `TypeVar` 只能约束类型，不能约束属性名。TS 的 `keyof T` 可以在编译时确保 `key` 参数是 `T` 的有效属性名——这是 Python 完全做不到的。

## 🐍 Python→TS 泛型对比

| 维度 | Python TypeVar | TypeScript 泛型 |
|------|---------------|----------------|
| 基本语法 | `T = TypeVar("T")` | `<T>` |
| 约束 | `TypeVar("T", bound=Base)` | `<T extends Base>` |
| 默认值 | Python 3.12+ 支持 | `<T = string>` |
| 属性名约束 | 无 | `keyof T`（编译时检查） |
| 递归泛型 | 不支持 | 支持 |
| 条件类型 | 不支持 | 支持 |

| Python 工具类型 | TS 工具类型 |
|----------------|------------|
| `Partial[T]` (typing_extensions) | `Partial<T>` |
| 无等价 | `Omit<T, K>` |
| 无等价 | `Pick<T, K>` |
| `Required[T]` (typing_extensions) | `Required<T>` |
| `ReadOnly[T]` (typing_extensions) | `Readonly<T>` |
