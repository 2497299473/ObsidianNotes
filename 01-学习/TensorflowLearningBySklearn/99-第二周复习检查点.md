## 二、概念自测题（10 题，答对 7 题达标）

**Q1**：`ColumnTransformer` 在 TF 中用什么替代？

<details>
<summary>💡 答案</summary>

Functional API 多 Input + Concatenate。每个 Input 层对应一组特征，各自接预处理层，用 `Concatenate` 合并后送入 Dense 层。
</details>

**Q2**：Embedding 层是什么？为什么比 One-Hot 好？

<details>
<summary>💡 答案</summary>

Embedding 是可训练层，把类别索引映射为稠密向量。优势：维度可配置（远小于类别数）、可学习语义相似性、高基数类别时优势明显。One-Hot 输出固定维度、所有类别等距、无法学习相似性。
</details>

**Q3**：为什么 `Lambda` 层不推荐用于生产？

<details>
<summary>💡 答案</summary>

`Lambda` 层用 Python lambda 函数，`model.save()` 时可能无法序列化。生产环境应定义为 `tf.keras.layers.Layer` 子类，实现 `get_config()` 方法。
</details>

**Q4**：TF 交叉验证怎么写？为什么每个 fold 要重建模型？

<details>
<summary>💡 答案</summary>

手动用 `StratifiedKFold` 循环，每 fold 调用 `build_model()` 重新创建模型。因为 TF 模型训练后会保留权重，不重建会在上一 fold 的权重基础上继续训练，导致结果虚高。
</details>

**Q5**：`ReduceLROnPlateau` 的作用和参数？

<details>
<summary>💡 答案</summary>

验证损失不下降时自动降低学习率。关键参数：`monitor='val_loss'`、`factor=0.5`（学习率乘数）、`patience=5`（无改善的 epoch 数）、`min_lr=1e-6`（最低学习率）。这是 TF 独有，Sklearn 无对应。
</details>

**Q6**：过拟合如何诊断？有哪些对策？

<details>
<summary>💡 答案</summary>

诊断：train_loss↓ 但 val_loss↑。对策：Dropout、L2 正则化、数据增强、EarlyStopping、减小模型容量、增加训练数据。TF 独有：`ReduceLROnPlateau` 自动调学习率。
</details>

**Q7**：KerasTuner 推荐用哪种搜索器？为什么不用 GridSearch？

<details>
<summary>💡 答案</summary>

推荐 `Hyperband`（自适应淘汰差劲的 trial，效率最高）。不用 GridSearch 的原因：TF 模型训练慢（分钟到小时级），网格搜索代价极高。Hyperband 和 Bayesian 比 GridSearch 快 3-5 倍。
</details>

**Q8**：Wide & Deep 的 Wide 部分和 Deep 部分各自做什么？

<details>
<summary>💡 答案</summary>

Wide 部分：线性模型，学习特征交叉（记忆能力）。Deep 部分：Embedding + MLP，泛化到没见过的特征组合（泛化能力）。两者联合训练，共享损失函数，互相增强。这是 Sklearn 完全无法实现的架构。
</details>

**Q9**：Dropout 近似什么集成方法？

<details>
<summary>💡 答案</summary>

Dropout 近似 Bagging。每次前向传播时随机禁用一部分神经元，相当于训练了指数级数量的"子网络"，推理时取平均——隐式 Bagging 效果。
</details>

**Q10**：为什么 Sklearn + TF 混合使用是常态？

<details>
<summary>💡 答案</summary>

Sklearn 强项：传统 ML 算法全覆盖（SVM/KNN/聚类）、特征工程工具链、跨平台、轻量、训练快。TF 强项：深度学习全栈（CNN/RNN/Transformer）、自动微分+GPU、部署生态。两者互补：Sklearn 做特征工程+快速原型，TF 做深度学习+部署。
</details>

## 四、常见错误诊断（15 分钟）

### 错误 1：Stacking 元特征数据泄露

```python
# ❌ 错误：直接用训练集预测结果作为元特征
model1.fit(X_train, y_train)
meta_features = model1.predict(X_train)  # ← 数据泄露！
meta_model.fit(meta_features, y_train)
```

<details>
<summary>🔍 诊断</summary>

直接用训练集预测结果作为元特征会导致元模型过拟合。必须用 K-Fold 交叉验证生成元特征：每个 fold 的模型预测另一个 fold，确保元模型训练时看到的是"未参与训练"的预测。

```python
# ✅ 正确：K-Fold 生成元特征
from sklearn.model_selection import StratifiedKFold
skf = StratifiedKFold(n_splits=5)
meta_features = np.zeros(len(X_train))
for tr_idx, va_idx in skf.split(X_train, y_train):
    model = build_model()
    model.fit(X_train[tr_idx], y_train[tr_idx])
    meta_features[va_idx] = model.predict(X_train[va_idx])
meta_model.fit(meta_features, y_train)
```
</details>

### 错误 3：K-Fold 不重置模型

```python
# ❌ 错误：同一模型对象循环训练
model = build_model()  # ← 在循环外创建
for fold, (tr_idx, va_idx) in enumerate(skf.split(X, y)):
    model.fit(X[tr_idx], y[tr_idx])  # ← 在上一 fold 权重基础上继续训练！
```

<details>
<summary>🔍 诊断</summary>

TF 模型训练后会保留权重。如果不重置模型，下一 fold 会在上一 fold 的权重基础上继续训练，导致交叉验证结果虚高。

```python
# ✅ 正确：每 fold 重新创建模型
for fold, (tr_idx, va_idx) in enumerate(skf.split(X, y)):
    model = build_model()  # ← 在循环内创建
    model.fit(X[tr_idx], y[tr_idx])
```
</details>

### 错误 5：Lambda 层无法保存模型

```python
# ❌ 错误：Lambda 层保存失败
model = Sequential([
    Lambda(lambda x: tf.math.log1p(x), input_shape=(5,)),
    Dense(64, activation='relu'),
    Dense(1)
])
model.save('model.keras')  # ← 可能无法序列化
```

<details>
<summary>🔍 诊断</summary>

`Lambda` 层用 Python lambda 函数，`model.save()` 时可能无法序列化。

```python
# ✅ 正确：自定义 Layer
class LogTransform(Layer):
    def call(self, inputs):
        return tf.math.log1p(inputs)
    def get_config(self):
        return super().get_config()

model = Sequential([
    LogTransform(input_shape=(5,)),
    Dense(64, activation='relu'),
    Dense(1)
])
model.save('model.keras')  # ← 可以正常保存
```
</details>

## 五、综合实操：端到端 ML Pipeline（40 分钟）

### 题目：完整迁移——Sklearn Pipeline → TF 多输入模型

**数据准备**

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split

np.random.seed(42)
n = 1000
df = pd.DataFrame({
    'age': np.random.randint(18, 70, n),
    'income': np.random.exponential(50000, n),
    'city': np.random.choice(['北京', '上海', '广州', '深圳'], n),
    'device': np.random.choice(['iOS', 'Android', 'Web'], n),
    'clicked': np.random.randint(0, 2, n)
})
X_train, X_test, y_train, y_test = train_test_split(
    df[['age', 'income', 'city', 'device']], df['clicked'], test_size=0.2, random_state=42
)
```

**要求**：
- [ ] 用 Functional API 构建多输入模型（数值 + 类别）
- [ ] 数值特征用 `Normalization` 层（嵌入模型）
- [ ] 类别特征用 `StringLookup` + `Embedding`（替代 One-Hot）
- [ ] 用 KerasTuner Hyperband 搜索超参（层数、神经元、学习率）
- [ ] 用 `EarlyStopping` + `ModelCheckpoint` 回调
- [ ] 保存模型后加载验证（预处理层随模型保存）
- [ ] 输出测试集准确率，要求 ≥ Sklearn Pipeline - 5%

<details>
<summary>💡 参考答案</summary>

```python
import tensorflow as tf
import keras_tuner as kt
import numpy as np

# --- 预处理层 ---
input_num = tf.keras.Input(shape=(2,), name='numeric')
normalizer = tf.keras.layers.Normalization(name='normalizer')
normalizer.adapt(X_train[['age', 'income']].values.astype(np.float32))
x_num = normalizer(input_num)

input_city = tf.keras.Input(shape=(1,), dtype=tf.string, name='city')
city_lookup = tf.keras.layers.StringLookup(
    vocabulary=X_train['city'].unique(), output_mode='int')
city_emb = tf.keras.layers.Embedding(len(city_lookup.get_vocabulary()), 4)
x_city = tf.keras.layers.Flatten()(city_emb(city_lookup(input_city)))

input_dev = tf.keras.Input(shape=(1,), dtype=tf.string, name='device')
dev_lookup = tf.keras.layers.StringLookup(
    vocabulary=X_train['device'].unique(), output_mode='int')
dev_emb = tf.keras.layers.Embedding(len(dev_lookup.get_vocabulary()), 4)
x_dev = tf.keras.layers.Flatten()(dev_emb(dev_lookup(input_dev)))

concat = tf.keras.layers.Concatenate()([x_num, x_city, x_dev])

# --- KerasTuner 搜索 ---
def build_model(hp):
    x = concat
    for i in range(hp.Int('num_layers', 1, 3)):
        x = tf.keras.layers.Dense(
            hp.Int(f'units_{i}', 16, 64, step=16), activation='relu')(x)
        x = tf.keras.layers.Dropout(hp.Float('dropout', 0.0, 0.3, step=0.1))(x)
    output = tf.keras.layers.Dense(1, activation='sigmoid')(x)
    model = tf.keras.Model(
        inputs=[input_num, input_city, input_dev], outputs=output)
    model.compile(
        optimizer=tf.keras.optimizers.Adam(
            hp.Float('lr', 1e-4, 1e-2, sampling='log')),
        loss='binary_crossentropy', metrics=['accuracy'])
    return model

tuner = kt.Hyperband(build_model, objective='val_accuracy',
                     max_epochs=50, directory='kt_logs', project_name='pipeline')
tuner.search(
    {'numeric': X_train[['age', 'income']].values.astype(np.float32),
     'city': X_train[['city']].values,
     'device': X_train[['device']].values},
    y_train.values, validation_split=0.2,
    callbacks=[tf.keras.callbacks.EarlyStopping(patience=5, monitor='val_loss')]
)

# --- 最佳模型训练 ---
best_hp = tuner.get_best_hyperparameters(1)[0]
best_model = tuner.hypermodel.build(best_hp)
best_model.fit(
    {'numeric': X_train[['age', 'income']].values.astype(np.float32),
     'city': X_train[['city']].values,
     'device': X_train[['device']].values},
    y_train.values, epochs=100, validation_split=0.2, verbose=0,
    callbacks=[
        tf.keras.callbacks.EarlyStopping(monitor='val_loss', patience=10,
                                          restore_best_weights=True),
        tf.keras.callbacks.ModelCheckpoint('best_model.keras', save_best_only=True,
                                           monitor='val_accuracy', mode='max')
    ]
)

# --- 评估 ---
loaded = tf.keras.models.load_model('best_model.keras')
loss, acc = loaded.evaluate(
    {'numeric': X_test[['age', 'income']].values.astype(np.float32),
     'city': X_test[['city']].values,
     'device': X_test[['device']].values},
    y_test.values, verbose=0
)
print(f"TF 准确率: {acc:.4f}")
print(f"最优超参: {best_hp.values}")
# Functional 模型的 layers[0] 是 InputLayer（没有 mean 属性），要按名字取 Normalization 层
print(f"预处理层均值: {loaded.get_layer('normalizer').mean.numpy()}")  # ← 预处理层已包含
```
</details>

## 六、错题本（个人反思）

> 记录学习过程中遇到的典型错误和解决方案。

| 错误类型 | 具体表现 | 解决方案 |
|----------|---------|---------|
| **API 混淆** | 混淆 `adapt()` 和 `fit()` | Normalization 用 `adapt()`，等价于 Sklearn 的 `fit()` |
| **数据泄露** | Stacking 直接用训练集预测作为元特征 | 用 K-Fold 交叉验证生成元特征 |
| **模型不重置** | K-Fold 循环中同一模型对象连续训练 | 每 fold 调用 `build_model()` 重新创建 |
| **标签不匹配** | 整数标签用 `categorical_crossentropy` | 整数标签用 `sparse_categorical_crossentropy` |
| **Lambda 层保存失败** | `model.save()` 失败 | 用自定义 `Layer` 子类，实现 `get_config()` |
| **TF-DF 平台限制** | Windows 上无法安装 | 用 WSL2 或 Colab，或用 Sklearn RF |
| **学习率搜索** | 线性搜索学习率效果差 | 用 `sampling='log'` 对数搜索 |
| **过拟合诊断** | 训练曲线看不懂 | train_loss↓ val_loss↑ = 过拟合 |

## 七、两周迁移速查表

| 操作 | Sklearn | TensorFlow |
|------|---------|-----------|
| **标准化** | `StandardScaler` | `Normalization` 层 + `adapt()` |
| **One-Hot** | `OneHotEncoder` | `StringLookup(one_hot)` |

| **特征哈希** | `FeatureHasher` | `Hashing` 层 |
| **交叉验证** | `cross_val_score` | 手动 K-Fold + 每 fold 重建模型 |
| **超参搜索** | `GridSearchCV` | `KerasTuner`（Hyperband 推荐） |
| **学习曲线** | `learning_curve` | `history.history` + matplotlib |
| **早停** | `MLPClassifier(early_stopping=True)` | `EarlyStopping` callback |
| **学习率衰减** | ❌ 无 | `ReduceLROnPlateau` |
| **模型检查点** | ❌ 无 | `ModelCheckpoint` |
| **训练可视化** | ❌ 无 | `TensorBoard` |
| **类别不均衡** | `class_weight='balanced'` | `class_weight` / Focal Loss |
| **RandomForest** | `RandomForestClassifier` | `tfdf.keras.RandomForestModel` |
| **GradientBoosting** | `GradientBoostingClassifier` | `tfdf.keras.GradientBoostedTreesModel` |
| **投票集成** | `VotingClassifier` | 手动 `np.mean([probas])` |
| **堆叠集成** | `StackingClassifier` | 手动 K-Fold + 元模型 |
| **Wide & Deep** | ❌ 无 | Functional API 联合训练 |
| **知识蒸馏** | ❌ 无 | Teacher→Student 自定义循环 |
| **多任务学习** | ❌ 无 | 共享层 + 多输出 |
| **部署** | Flask/FastAPI + pickle | TF Serving / TFLite / TF.js |
