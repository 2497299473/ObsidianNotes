# TensorFlow Learning By Sklearn

> 你已经掌握 Sklearn，不需要从零学 TensorFlow。本路径以你的 Sklearn 知识为锚点，逐篇映射已知概念到 TensorFlow 等价物。

---

## 🚀 快速开始

### 第一步：打开总览索引

从 [[00-TensorFlow 总览索引（Sklearn 迁移版）]] 开始，了解课程清单、三周路线图和角色导航。

### 第二步：选择你的路线

| 你的背景 | 推荐路线 | 预计学时 |
|---------|---------|---------|
| 📊 Sklearn 数据分析师 | 01→02→03→08→v1→v2 | ~16h |
| 🔬 Sklearn ML 工程师 | 全路径 00→…→11→v1→…→v5 | ~47.5h |
| ⏰ 紧急项目迁移 | 01→02→07→10→v1 | ~14h |
| 🧠 想深入深度学习 | 01→02→08→09→10→v4→v5 | ~22.5h |

### 第三步：按周学习

```
第一周（会用）：环境搭建 → 数据预处理 → 传统 ML 模型迁移
第二周（深入）：特征工程 → 模型评估与调优 → 集成学习 → 双向对比全景
第三周（实战）：深度学习入门 → CNN/RNN → 业务场景 → 面试准备
```

## 🎯 学习路径的核心理念

本路径遵循 [[03-AI工具/AI协作方法论/迁移式学习路径创建方法论]]：

1. **以已知为锚点**：每篇笔记都以 Sklearn 概念为起点
2. **差异决定深度**：差异小的快速跳过，差异大的深入展开
3. **双向对比**：不仅学 TF 有什么，还要知道 Sklearn 的哪些东西在 TF 中不存在
4. **由浅入深**：三周递进——会用 → 深入 → 实战
5. **每章带练习**：每个知识点后附实践练习（🟢基础/🟡进阶/🔴挑战）+ 注释 + 验收标准
6. **版本递进毕业项目**：v1→v5 每个版本只改一个维度，逐步从"能跑通"到"可部署"
