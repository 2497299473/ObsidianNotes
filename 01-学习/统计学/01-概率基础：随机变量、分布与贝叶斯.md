## 前置知识：为什么概率是量化第一课

预测涨跌，本质是对不确定的未来下**概率断言**。"明天涨的概率 60%"这句话有两种读法：

- **频率派**：在历史所有"与明天条件相似"的日子里，约 60% 后来是涨的——概率是长期频率；
- **贝叶斯派**：它是我当前信念的度量，看到新证据我会更新它——概率是信念强度。

两种读法在阶段二（假设检验）和本篇第四节（贝叶斯）各领一次主角。量化研究里它们不是对立的，而是**两种记账方式**：频率派回答"这个规律在历史里有多稳"，贝叶斯回答"今天我该信它几分"。

> [!important] 本篇的三个落点
> 1. 期望 / 方差 / 分位数 → 年化波动率、VaR 的直觉
> 2. 贝叶斯定理 → "先验判断 + 数据证据"的标准语法
> 3. 大数定律 → 为什么回测样本越大结论越可信（以及何时这个保证失效）

本篇只依赖 Python + NumPy（pandas 偶尔出场），每个代码块都可独立运行。

## 一、随机变量与分布

### 1.1 一句话定义

> [!important] 随机变量与 PMF / PDF / CDF
> 随机变量 = 把随机试验的结果映射成数值。离散型用**分布律 PMF** `P(X=k)`；连续型用**密度 PDF** `f(x)`（单点概率为 0，区间概率是曲线下面积）；两者统一由**累积分布函数 CDF** `F(x)=P(X≤x)` 描述。

对量化来说：**日收益率就是一个随机变量**。特征工程在造它的条件分布的形状，预测在估计它的条件期望/分位数，风控在管它的尾部——一切都是在跟这个分布打交道。

### 1.2 期望、方差、标准差

期望是长期平均，方差/标准差度量围绕期望的波动。

```python
import numpy as np

rng = np.random.default_rng(42)
rets = rng.normal(0.0005, 0.01, size=1000)   # 模拟日均对数收益 0.05%、日波动 1%

print(rets.mean())                        # 期望的样本估计
print(rets.std(ddof=1))                   # 日波动率（样本标准差）
print(np.sqrt(252) * rets.std(ddof=1))    # 年化波动率 ≈ 16%
```

> [!tip] 年化口径：×√252
> 日波动率 × √252 ≈ 年化波动率（A 股一年约 252 个交易日）。这不是经验凑数，是**独立随机变量方差可加**的推论：Var(X₁+…+X₂₅₂) = 252·Var(X)。它成立的前提是"日收益独立"——而金融数据恰恰弱违反这一点（波动聚集），所以年化波动率是**口径换算**，不是精确预言。

### 1.3 分位数与 VaR 的直觉

```python
q05 = np.percentile(rets, 5)
print(q05)   # ≈ -1.6%：历史上约 5% 的日子比这更惨
```

这就是**历史模拟法 VaR** 的雏形：5% 分位的日收益 ≈ "95% 置信下、单日最差也就亏到这"。它的正式定义、与参数法 VaR 的差异、以及"VaR 不管分位之外有多惨"的缺陷，在量化研究·策略评价阶段展开。

## 二、常见分布：每个都要有金融对应物

| 分布 | 一句话 | 金融对应物 |
|------|--------|-----------|
| 伯努利 Bernoulli(p) | 单次试验的成败 | 明日涨 / 跌 |
| 二项 Binomial(n, p) | n 次独立试验的成功次数 | 20 日里上涨的天数 |
| 正态 N(μ, σ²) | 钟形、对称、薄尾 | 日**对数收益**的一阶近似 |
| 对数正态 | exp(正态) | **价格本身**——价格永远 ≥ 0 的原因：P = P₀·e^r |
| 学生 t(ν) | 低自由度 → 厚尾 | 更真实的收益分布（尖峰厚尾） |
| 指数 / 泊松 | 事件间隔 / 单位时间事件数 | （后续）大单到达、成交事件 |

**对数正态那一行是"为什么用对数收益"的答案**：价格 = 初始价格 × 连乘每日涨幅，连乘取对数变连加，所以对数收益近似正态、价格对数正态。这也是[[01-学习/算法/基础概念/前缀和基础与通用解题框架|前缀和]]笔记里"任意区间收益 = 两次前缀和相减"能成立的原因。

> [!warning] "收益近似正态"的适用边界
> 正态是**中心区域**的好近似、**尾部**的坏近似。按正态假设，1987 年那种单日 -20% 是几十亿年一遇——它就是发生了。厚尾的正式工具（峰度、t 拟合）见下，完整讨论见 [[00-统计学学习路径总索引|总索引]] 的"金融数据的统计特殊性"。

手工计算偏度与峰度（不依赖 scipy），对比正态样本与 t(3) 样本：

```python
def skew_kurt(x):
    m, s = x.mean(), x.std(ddof=1)
    return ((x - m) ** 3).mean() / s ** 3, ((x - m) ** 4).mean() / s ** 4 - 3

z = rng.standard_normal(200_000)
t3 = z / np.sqrt(rng.chisquare(3, 200_000) / 3)   # 手工构造自由度 3 的 t 分布

print(skew_kurt(z))    # ≈ (0, 0)：正态样本
print(skew_kurt(t3))   # 峰度显著 > 0：同样的"标准差"，尾部厚得多
```

## 三、条件概率、独立与不相关

### 3.1 条件概率与全概率

> [!important] 三个公式
> 条件概率：P(A|B) = P(A∩B) / P(B)
> 乘法公式：P(A∩B) = P(B|A)·P(A)
> 全概率：P(B) = Σᵢ P(B|Aᵢ)·P(Aᵢ)（把"原因"拆开加权）

### 3.2 独立 ⇒ 不相关，但不相关 ⇏ 独立

经典反例：X 服从标准正态，Y = X²。X 与 Y 完全函数相关，但协方差为 0（正负对称抵消）：

```python
x = rng.standard_normal(200_000)
print(np.corrcoef(x, x ** 2)[0, 1])   # ≈ 0：线性不相关
```

> [!warning] 量化含义
> "收益与某因子**线性不相关**"绝不等于"该因子不含未来信息"。用相关系数做特征初筛可以，**判死刑之前看条件结构**（散点、分箱均值、条件分布）——这也是树模型经常捡到线性筛选漏掉的信号的原因之一。

## 四、贝叶斯定理：先验、似然、后验

> [!important] 贝叶斯定理
> P(A|B) = P(B|A)·P(A) / P(B)，即 **后验 ∝ 似然 × 先验**。
> 读法：我本来信什么（先验）× 数据说了什么（似然）= 看到数据后我该信什么（后验）。

### 4.1 基率谬误：P(A|B) ≠ P(B|A)

检测准确率 99%、患病率 1%，查出阳性后真实患病概率只有 **50%**：

```python
p_d, sens, fpr = 0.01, 0.99, 0.01
print(sens * p_d / (sens * p_d + fpr * (1 - p_d)))   # 0.5
```

> 量化对应：**"上涨日出现利好信号的频率"（P(信号|涨)）≠ "出现利好后上涨的频率"（P(涨|信号)）**。混淆这两个条件概率，是消息面策略回测里最常见的逻辑错误。

### 4.2 金融例子：利好消息更新涨跌判断

先验 P(涨) = 0.5；历史统计得 P(利好|涨) = 0.6、P(利好|跌) = 0.3：

```python
p_up, lk_up, lk_dn = 0.5, 0.6, 0.3
post = lk_up * p_up / (lk_up * p_up + lk_dn * (1 - p_up))
print(post)   # 0.667：一条利好把"五五开"更新到"三分之二"
```

### 4.3 序贯更新：似然比连乘（odds 形式）

每来一条**独立**证据，后验几率乘一次似然比：

| 时点 | 先验几率 | 似然比 | 后验几率 | 后验概率 |
|------|---------|--------|---------|---------|
| 初始 | 1 : 1 | — | 1 : 1 | 0.50 |
| 利好① | 1 : 1 | 0.6/0.3 = 2 | 2 : 1 | 0.67 |
| 利好② | 2 : 1 | 0.6/0.3 = 2 | 4 : 1 | 0.80 |

```python
odds = 1.0
for _ in range(2):
    odds *= lk_up / lk_dn
    print(f"odds={odds:.1f}, P={odds / (1 + odds):.2f}")
```

> [!tip] 两个工程提醒
> 1. "独立"是假设不是事实——同一条消息被媒体反复报道时，证据会被重复计费（对应回测里的数据窥拜/data snooping）。
> 2. 似然比 0.6/0.3 本身是从历史数据估计的，带采样误差。阶段二的置信区间就是用来量化"这个似然比本身有多可信"的工具。

## 五、大数定律与中心极限定理（预告）

- **大数定律（LLN）**：样本均值依概率收敛于真实期望 → **回测样本越大，平均收益的估计越稳**。
- **中心极限定理（CLT）**：只要方差有限，不管原分布长什么样，样本均值的抽样分布趋于正态 → 阶段二 t 检验与置信区间的地基。

```python
for m in [10, 100, 1_000, 10_000, 100_000]:
    print(m, round(rng.normal(0.0005, 0.01, m).mean(), 5))
```

> [!warning] 金融数据对 IID 的弱违反
> LLN / CLT 的教科书版本假设独立同分布。日收益"接近但不完全"满足——波动聚集使方差随时间漂移。修正工具（Newey-West / HAC 标准误、Block Bootstrap）见 [[00-统计学学习路径总索引|总索引]] 的"金融数据的统计特殊性"，学完阶段二假设检验后回读。

## 六、常见易错点

> [!warning] 坑 1：算术平均收益 ≠ 复利增长（波动拖累）
> 日均对数收益 μ 的策略，长期**典型**财富增长速率 ≈ μ − σ²/2，不是 μ——波动本身吃掉复利。

```python
n, mu, sigma = 250, 0.001, 0.02
r = rng.normal(mu, sigma, size=(20_000, n)).sum(axis=1)
paths = np.exp(r)

print(np.exp(n * mu))     # 理论中位数终值 ≈ 1.284（e^0.25）
print(np.median(paths))   # 模拟中位数 ≈ 1.28（典型路径的真实增长）
print(paths.mean())       # 均值终值 ≈ 1.35（被少数右尾路径抬高：e^{0.25+0.05}）
```

> 记住大小关系：**中位数 ≈ e^{nμ} < 均值 = e^{nμ + nσ²/2}**。均值被尾部拉高，不代表典型命运。比较策略时先看中位数与分位数，再谈均值。

> [!warning] 坑 2：把正态分位数当 VaR 用在厚尾数据上
> 正态 5% VaR 会**低估**真实尾部亏损（对比：t(3) 的 5% 分位深得多）。先算峰度 / 画 QQ 图确认分布，再选口径——这正是 4.1 节代码要会手算的原因。

> [!warning] 坑 3：把"统计显著"当"经济显著"
> 样本量极大时，日均 0.01% 的微弱效应也会"显著"。阶段二给出正式判据；先立住直觉：**先问效应大小，再问显著性**——这一条会一路管到回测（年化 0.1% 的"显著 alpha"扣完成本可能一文不值）。
