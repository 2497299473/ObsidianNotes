## 为什么需要这个专题

涨跌预测本质是时间序列预测，而普通 ML 的**随机切分交叉验证在时序数据上会因数据泄漏直接失效**——用未来数据训练、去"预测"过去，是量化项目最常见的死因。本专题先立时序世界观，再谈模型。

## 数据泄漏红线（贯穿全专题，正式展开见量化研究）

- Look-ahead bias：归一化用全量均值、特征构造用到未来窗口、目标构造错位
- 用随机 K-Fold 切时序数据 = 直接作废实验
- **point-in-time 因果特征可以沿全时间轴构造**（如 `price.shift(1).rolling(20).mean()`）——只要 t 时刻只访问 ≤t 的数据；❌ "中心窗口"（`xs[t-w : t+w]`）在实盘等于偷看未来
- **从数据中学习参数的变换**（StandardScaler / Imputer / PCA / 特征选择 / 目标编码）只能在训练窗 `.fit()`，验证/测试窗一律 transform-only——这是比"先切分后构造"更准确的纪律表述

## 量化场景锚点

- 阶段一 → 对收益序列做 ADF 检验，理解"价格非平稳、收益近似平稳"对建模意味着什么
- 阶段二 → ARIMA 对指数收益做基线预测，作为后续 ML 模型的对照组
- 阶段三 → 用 Pandas 滚动窗口实现波动率/回撤/夏普的计算（衔接 [[01-学习/算法/基础概念/滑动窗口基础与通用解题框架|算法/滑动窗口]]）
- 阶段三 → "金融收益 ≠ IID 正态"：串联 [[01-学习/统计学/00-统计学学习路径总索引|统计学]] 的自相关/异方差/厚尾与 HAC/Block Bootstrap
- 阶段四 → Kalman 滤波对带噪价格做平滑，理解其与简单移动平均的本质差异
