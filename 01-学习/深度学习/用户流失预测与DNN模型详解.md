## 📝 正文内容

## 1. 业务场景与问题定义

- **业务需求**：运营部门希望在用户停付会费前预测流失风险，以便及时触发留客机制。
- **任务类型**：基于“易速鲜花”会员数据集（标签为“是否已停付会费”），属于典型的**监督学习二元分类问题**。
- **数据准备**：构建特征集 $X$（17维）与标签集 $y$，按 8:2 拆分训练集与测试集。

## 2. 逻辑回归基准模型

- **算法原理**：在线性回归基础上叠加 Sigmoid 函数，将输出映射为 0~1 的概率值，以 0.5 为阈值判定类别。
- **实战结果**：测试集准确率达到 **78.70%**，作为后续深度学习模型的对比基准。

## 3. DNN 神经网络代码逐行解析

### 3.1 模型构建代码

```python
import keras
from keras.models import Sequential
from keras.layers import Dense

dnn = Sequential()
dnn.add(Dense(units=12, input_dim=17, activation='relu'))
dnn.add(Dense(units=24, activation='relu'))
dnn.add(Dense(units=1, activation='sigmoid'))
dnn.compile(optimizer='RMSProp', loss='binary_crossentropy', metrics=['acc'])
```

### 3.2 核心参数详解

|代码/参数|含义|关键说明|
|:--|:--|:--|
|`Sequential()`|序贯模型容器|数据线性堆叠流动，无分支跳跃连接|
|`input_dim=17`|输入特征维度|**仅第一层需要指定**，由数据本身决定，非超参数|
|`units=12/24/1`|各层神经元数量|隐藏层大小是需调优的超参数；输出层1个神经元对应二元分类|
|`activation='relu'`|隐藏层激活函数|引入非线性，缓解梯度消失，加速收敛|
|`activation='sigmoid'`|输出层激活函数|将输出压缩至(0,1)区间，适配二元分类概率输出|
|`optimizer='RMSProp'`|优化器|自适应学习率算法，适合结构化数据DNN训练|
|`loss='binary_crossentropy'`|损失函数|二元分类标准损失，衡量预测概率与真实标签的差异|
|`metrics=['acc']`|评估指标|监控准确率，不影响梯度更新，仅用于观察模型性能|

## 4. 核心概念通俗解读

### 4.1 为什么必须使用激活函数？

- **无激活函数 = 只会走直线的笨模型**：纯线性运算无论叠加多少层，数学上永远等价于单层线性模型，无法拟合现实世界中复杂的非线性关系。
- **激活函数 = 让模型学会拐弯的非线性开关**：
    - **ReLU**：单向阀门，信号>0原样通过，<0截断为0，打破线性关系，拼接出复杂曲线。
    - **Sigmoid**：概率压缩器，将任意实数映射到(0,1)，赋予输出业务可解释性。
- **本质总结**：`Dense` 层负责线性特征组合，`activation` 负责引入非线性变换，二者配合使神经网络成为能描绘任意复杂形状的“万能画笔”。

### 4.2 第一个隐藏层为何设置为12个神经元？

> ⚠️ **重要澄清**：`units=12` 是**第一个隐藏层**的神经元数，而非输入层神经元数。输入维度由 `input_dim=17` 声明，由数据决定，不可人为设定。

选择12作为起始值的工程依据：

1. **信息压缩与提炼**：17→12 实现降维，强迫网络提炼抽象特征而非记忆原始数据，提升泛化能力。
2. **瓶颈结构设计**：形成 17→12→24→1 的“先压缩再展开”结构，先降噪筛选，再在高维空间学习复杂交互。
3. **任务规模匹配**：17维结构化数据的中小规模分类任务，过大隐藏层易过拟合，12是保守合理的起点。
4. **调参惯例**：12是常用基数，计算开销小，便于快速迭代验证。

### 4.3 隐藏层神经元调优方法

隐藏层大小是**试出来的，不是算出来的**，应以12为基准通过实验搜索：

|候选值|观察重点|潜在风险|
|:--|:--|:--|
|8|训练速度、欠拟合迹象|容量不足，学不到复杂模式|
|**12**|**基准表现**|**当前调参起点**|
|16|准确率变化、过拟合迹象|可能开始过拟合|
|24|验证集损失是否上升|大概率过拟合，需加正则化|

## 5. 数据归一化的关键作用

- **问题现象**：未归一化时验证集损失与准确率曲线剧烈振荡，模型训练不稳定。
- **解决方案**：使用 `MinMaxScaler` 将特征缩放到 [0,1] 区间。
- **效果**：振荡消失，曲线平滑，训练稳定收敛，测试准确率从77%提升至78%。
- **核心结论**：**归一化是神经网络成功训练的前提**，能有效避免梯度下降震荡，加速收敛。

## 6. 总结与实战建议

- **算法选择**：逻辑回归可作为快速基准；DNN表达能力更强，但对数据预处理要求更高。
- **工程核心**：数据预处理（尤其是归一化）比模型结构更重要，是神经网络稳定训练的关键。
- **进阶方向**：尝试其他分类算法（朴素贝叶斯、KNN等）；调整DNN层数、神经元数及超参数，结合验证集表现进行系统性调优。
