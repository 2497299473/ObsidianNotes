# Rust 学习路径

> 📌 本学习路径基于 [[03-AI工具/AI协作方法论/技术学习路径审查与优化方法论]] 的多 Agent 审查方法论构建，采用三阶段递进、毕业项目版本递进、每篇自检清单、双向交叉引用设计。

## 快速开始

1. 准备环境：rustup 安装 Rust stable 工具链、VS Code + rust-analyzer
2. 打开 [[00-Rust学习路径总索引]] 查看完整路径和角色导航
3. 按角色选择路线（🆕 新手 / 🔄 转行者 / 🚀 专家）
4. 按阶段顺序学习，完成每篇的 🎯 自检清单（🟢/🟡/🔴）
5. 每个阶段末尾完成复习检查点
6. 从 v1 到 v7 完成毕业项目（Rust 任务管理器）

## 路径特色

Rust 的学习曲线集中在所有权与借用（阶段一第 3 课）——本路径在该课投入最多学时，并在毕业项目 v2 专门安排「所有权建模」版本巩固；v7 升级为 tokio + axum 异步服务，可与 [[01-学习/跨技术栈学习路径总览]] 中的 PostgreSQL（sqlx/diesel）、Go（FFI）路线衔接。
