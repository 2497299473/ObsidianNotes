## 1. 变量：let、mut 与 shadowing

Rust 中变量**默认不可变**（immutable），这是推动你写出安全、并发友好代码的核心设计之一。

```rust
fn main() {
    let x = 5;        // 不可变绑定
    let mut y = 10;   // 可变绑定
    y += x;           // OK
    // x += 1;        // 编译错误：cannot assign twice to immutable variable
    println!("x = {}, y = {}", x, y);
}
```

### shadowing（遮蔽）

用 `let` 重新声明同名变量，会**创建一个新变量**并遮蔽前一个。与 `mut` 的关键区别：shadowing 可以**改变类型**。

```rust
fn main() {
    let spaces = "   ";          // 类型：&str
    let spaces = spaces.len();   // 类型：usize，合法

    let mut size = "  ";
    // size = size.len();        // 编译错误：mut 不能改变类型
    println!("{}, {}", spaces, size.len());
}
```

| 对比项 | `mut` | shadowing |
|--------|-------|-----------|
| 是否新变量 | 否，同一块绑定 | 是，每次 `let` 都是新变量 |
| 能否换类型 | 不能 | 能 |
| 典型场景 | 值需要多次修改 | 对同一语义的值做一次性转换 |

> 💡 提示：shadowing 适合「字符串 → 解析为数字 → 取长度」这类链式转换，不必绞尽脑汁起 `spaces_str`、`spaces_num` 之类的名字；但同一作用域里反复 shadow 会让类型难以追踪，克制使用。

## 2. 基本数据类型

### 标量类型

| 类型 | 示例 | 说明 |
|------|------|------|
| 整数 | `i32`、`u64`、`isize` | 有符号 i8~i128，无符号 u8~u128；`i32` 是默认推断类型 |
| 浮点 | `f32`、`f64` | `f64` 为默认，精度与速度权衡下的推荐选择 |
| 布尔 | `bool` | `true` / `false` |
| 字符 | `char` | 4 字节 Unicode 标量值，单引号：`'R'`、`'中'`、`'🦀'` |

```rust
fn main() {
    let a: i32 = 98_222;        // 下划线分隔
    let b: u64 = 0xff;          // 十六进制
    let pi: f64 = 3.14;
    let ok: bool = true;
    let c: char = '🦀';

    let guess = "42".parse::<i32>().expect("不是数字"); // 显式标注，否则推导不出具体类型
    println!("{}, {}, {}, {}, {}, {}", a, b, pi, ok, c, guess);
}
```

### 复合类型

```rust
fn main() {
    let tup: (i32, f64, char) = (500, 6.4, 'R');
    let (x, _y, z) = tup;          // 解构
    let five_hundred = tup.0;      // 按索引访问
    println!("{}, {}, {}", x, z, five_hundred);

    let arr: [i32; 5] = [1, 2, 3, 4, 5];
    let zeros = [0u8; 4];          // [0, 0, 0, 0]
    let first = arr[0];
    // let bad = arr[10];          // 常量索引越界 → 编译期直接报错
    println!("{}, {}, {:?}", first, zeros[3], arr);
}
```

- **tuple**：长度固定，可混合类型，用 `.0`/`.1` 或解构访问
- **array**：长度固定、单一类型，分配在**栈**上；越界访问若是常量索引，**编译期报错**；若是运行时变量索引越界，则 **panic**（而不是像 C 那样继续读脏内存）

> 💡 提示：需要长度可变时用 `Vec<T>`（堆分配）；长度在编译期就确定且不变时才用数组，例如固定 12 个月名。

## 3. if/else：控制流也是表达式

Rust 中 `if` 是**表达式**，可以直接返回值。注意：分支返回值类型必须一致，且分支块**末尾不加分号**。

```rust
fn main() {
    let number = 7;

    let parity = if number % 2 == 0 { "偶数" } else { "奇数" };
    println!("{} 是{}", number, parity);

    // 多条件：Rust 没有 else if 链括号，直接写
    let desc = if number > 10 {
        "大"
    } else if number > 5 {
        "中"
    } else {
        "小"
    };
    println!("{}", desc);
}
```

> 💡 提示：在分支末尾加分号会把表达式变成语句，整个 `if` 的类型变成 `()`，赋值时就会得到类型不匹配的编译错误。

## 4. 循环：loop、while、for 与 Range

### loop：可返回值、可带标签

```rust
fn main() {
    let mut counter = 0;

    // break 可以返回值，常用于「循环重试直到成功」
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2;
        }
    };
    println!("result = {}", result); // 20

    // 循环标签：在嵌套循环中从外层跳出
    let mut hits = 0;
    'outer: for i in 0..3 {
        for j in 0..3 {
            if i + j >= 3 {
                hits += 1;
                break 'outer;
            }
        }
    }
    println!("hits = {}", hits); // 1
}
```

### while 与 for

```rust
fn main() {
    let mut n = 3;
    while n > 0 {          // 条件循环
        println!("{}!", n);
        n -= 1;
    }

    let a = [10, 20, 30];
    for v in a {           // 遍历集合，无需手动管理索引
        println!("{}", v);
    }

    for i in 0..5 {        // 0,1,2,3,4（不含 5）
        print!("{} ", i);
    }
    println!();
    for i in 1..=3 {       // 1,2,3（含 3）
        print!("{} ", i);
    }
    println!();
    for i in (0..5).rev() { // 4,3,2,1,0
        print!("{} ", i);
    }
}
```

| Range 语法 | 含义 |
|-----------|------|
| `0..5` | 左闭右开：0,1,2,3,4 |
| `1..=3` | 两端都含：1,2,3 |
| `(0..5).rev()` | 反转迭代 |

> 💡 提示：遍历集合优先用 `for item in &collection` 或 `for item in collection`，几乎永远不要用 `while index < len` 手动索引——后者既啰嗦又容易越界。

## 常见陷阱

| 陷阱 | 表现 | 对策 |
|------|------|------|
| 数组定长与 `Vec` 混淆 | 想给 `[i32; 5]` 增删元素，编译报错 | 长度会变就用 `Vec<T>`；定长场景才用数组 |
| 整数溢出 | debug 模式 panic；`--release` 下默认**回绕**（wrapping），结果静默错误 | 需要时用 `checked_add` / `wrapping_add` / `saturating_add` 显式表达意图 |
| shadowing 滥用 | 同一作用域连续 shadow，读代码时搞不清当前变量的类型 | 只在「一次性类型转换」时用 shadowing，其余换新名字 |
| if 分支末尾误加分号 | `let x = if ... { 1; } else { 2; };` 报类型错误（得到 `()`） | 分支块作为表达式返回值时不要加分号 |
