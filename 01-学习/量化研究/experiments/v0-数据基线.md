## 管道与结果

```text
fetch_data.py（Windows，akshare）──→ data/raw_510300_qfq_20260906.csv（1211 行）
        │

        │

```

- 首次落库：`csv_rows=1211 inserted=1211 table_total=1211`
- **幂等重跑：`inserted=0`**——`(symbol, trade_date)` 主键 + ON CONFLICT 防重验证通过

## 真实数据的第一个统计事实（衔接 [[01-概率基础：随机变量、分布与贝叶斯|统计学 01]]）

| 统计量 | 值 | 含义 |
|--------|-----|------|
| 日对数收益均值 | ≈0.00001 | 五年几乎零漂移 |
| 日波动率 | 1.20% | **年化 18.97%**（×√252 口径换算） |
| 偏度 | 0.02 | 近对称 |
| **超额峰度** | **9.6** | **厚尾实锤**——正态假设在此数据上不成立 |
| 5% 分位 | -1.74% | 历史模拟 VaR 雏形 |
| 单日最大跌幅 | **-9.74%（2024-10-09）** | 国庆后暴跌 |
| 单日最大涨幅 | **+9.49%（2024-09-30）** | 国庆前暴涨 |

> 统计学 01 的两个预防针在第一次接触真实数据时全部应验：① 峰度 9.6 ≫ 0，VaR/检验必须避开正态假设；② 最大涨跌幅集中在 2024 年国庆前后——**波动聚集**（异方差）肉眼可见，这正是"金融收益 ≠ IID 正态"的实例。

## 环境实录（为什么是 PG 16 而不是 18）

1. Docker Hub 与 DaoCloud 镜像源拉取 `postgres:18-alpine` 均超时停滞（本机网络对这些源限速 ~40-100KB/s）；
2. WSL apt 切**阿里云镜像源**（实测 2.7MB/s）安装 Ubuntu 24.04 自带的 **PostgreSQL 16.15**——完全符合版本口径"教学基线 14–16"，schema（BRIN 索引 / COPY / staging）全兼容；
3. Windows→WSL 的 5433 端口转发被拒（localhost 与 WSL-IP 均拒绝）→ **落库与质检在 WSL 内运行**（`/mnt/d` 直读库内 CSV），Windows 侧负责取数（akshare）与日常分析；
4. WSL 内 apt 的 numexpr/bottleneck 与用户级 numpy 2.5.1 存在编译版本冲突告警——纯噪音，不影响 pandas 运行。

日常连接备忘：`wsl -e sh -c 'cd /mnt/d/Obsidian/My-First-Obsidian/01-学习/量化研究/code/v0 && QUANT_PG_HOST=localhost python3 ...'`（PG 重启命令：`wsl -u root -e pg_ctlcluster 16 main start`）。
