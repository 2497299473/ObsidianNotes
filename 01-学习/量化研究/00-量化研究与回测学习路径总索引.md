## 模型评估 ≠ 策略评估

| 模型层（预测质量） | 金融层（决策质量） |
|------------------|------------------|
| Accuracy / Precision / Recall / F1 | 年化收益 / 波动率 / 胜率 |
| LogLoss / AUC | Sharpe / Sortino / Calmar |
| MAE / RMSE | 最大回撤 / 换手率 / 盈亏比 |

链路：**Forecast（预测）→ Decision Rule（决策规则）→ Position Sizing（仓位规模）→ Portfolio Construction（组合构建）→ 风险调整后收益**。模型指标好只保证链路第一环。

> [!warning] 预测模型 ≠ 交易策略
> 模型只产出分数；分数如何变成买卖（阈值？截面分位数？波动率倒数定仓？）是独立的、同样会过拟合的设计层——每一环都要单独回测，不许混在一起调。

## 三条戒律

1. 相关 ≠ 因果；p-value ≠ 策略有效；Sharpe ≠ 预测能力
2. 先跑通 v0→v2 的最朴素基线，再谈复杂模型；**任何模型必须先赢基准对照组（Buy & Hold / Naive）**，赢不了一律不进版本线
3. 同一测试集看第二次起就在消耗它——调参在验证窗做，测试窗只碰一次

## 环境口径：Python 按工作负载锁定

| 工作负载 | Python 版本 | 说明 |
|---|---|---|
| 通用 / 量化研究 | **3.13 优先** | pandas/NumPy/LightGBM 生态成熟；3.14 的 free-threaded 构建仍非默认、尚未普及，不追 |
| TensorFlow 2.21 | 3.10–3.13 | 官方支持区间（3.9 已停） |
| TFX 1.21 | 3.12 / 3.13 | 按官方兼容矩阵锁定，用 uv/venv/Docker 隔离，勿与主环境混装 |

## 每次实验必记录的字段

Experiment ID、数据集版本、特征版本、模型版本、超参数、训练/验证/测试窗口、模型指标、回测指标、Git commit、随机种子、运行环境。

## 自检清单

- 🟢 能指出自己特征流水线中至少三处潜在 look-ahead 并修复
- 🟢 能为自己的项目定义至少 3 种标签（如未来 3 日方向 / 未来 5 日最大回撤 / 相对基准超额收益）并说明各自适用的验证方法
- 🟢 能列出自己数据源的至少 3 个 Point-in-Time 风险点（复权因子生效、公告发布日、成分变更）及处理办法
- 🟢 能实现 Walk-Forward 验证并解释与随机 K-Fold 的区别
- 🟢 能在回测中加入手续费与滑点并解释其对高频信号的毁灭性影响
- 🟢 能对同一模型给出模型指标 + 回测指标两张表并说明各自局限
