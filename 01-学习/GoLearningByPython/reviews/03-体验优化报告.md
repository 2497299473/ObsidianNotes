## 练习设计亮点

1. **每个练习都有注释**：解释代码思路，对比 Python 写法
2. **练习难度递进**：基础（语法）→ 进阶（数据结构）→ 挑战（综合项目）
3. **练习可运行**：所有练习都是完整程序，可直接 `go run` 验证

## 巩固机制亮点

1. **复习检查点回指具体笔记**：第一周 → 01/02/03，第二周 → 04/05/06，第三周 → 07/08
2. **自评清单 🟢/🟡/🔴**：每篇笔记末尾都有三级自检
3. **毕业项目版本递进**：每版本只改一个维度，降低学习难度，持续成就感

## 学习者自测 Checklist 草案

完成本路径后，学习者应能：

- [ ] 独立搭建 Go 开发环境，用 `go mod` 管理项目
- [ ] 用 struct + method 实现 OOP 设计，不用继承
- [ ] 定义 interface 并用多个类型隐式实现
- [ ] 用 `if err != nil` 处理错误，用 `errors.Is/As` 检查错误链
- [ ] 用 goroutine + channel 实现并发任务处理
- [ ] 用 context + select 实现超时控制和优雅退出
- [ ] 用 `go test` 编写表格驱动测试和基准测试
- [ ] 交叉编译 Go 程序到不同平台
- [ ] 在面试中用 Python 对比展示 Go 优势
