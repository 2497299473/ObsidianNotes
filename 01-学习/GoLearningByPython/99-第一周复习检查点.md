## 一、理论问答

1. **为什么 Go 不需要像 Python 那样创建虚拟环境？**

   > Go 的 `go mod` 在项目级别管理依赖，每个项目的依赖都是独立的，无需 `venv`。

2. **Go 的 `:=` 和 `var` 有什么区别？**

   > `:=` 是短变量声明，只能在函数内使用，且至少有一个新变量；`var` 可以在函数内外使用，显式声明类型。

3. **Go 的 `for range` 遍历切片时，为什么常常写成 `for i, v := range` 或 `for _, v := range`？**

   > Go 的 `range` 返回索引和值两个值。如果只需要值，必须用 `_` 忽略索引；否则单变量 `for v := range` 会把索引赋给 `v`。

4. **Go 的 slice 切片和 Python list 切片有什么本质区别？**

   > Python 的切片创建副本，Go 的切片共享底层数组。修改 Go 的切片可能影响原数组。

5. **Go 的 struct embedding 和 Python 的类继承有什么本质区别？**

   > Embedding 是组合（has-a）不是继承（is-a）。Go 通过嵌入 struct 或 interface 复用代码，但没有继承语义。

6. **什么情况下使用指针接收者 `(c *Counter)`？什么情况下使用值接收者 `(c Counter)`？**

   > 需要修改接收者状态或 struct 较大时使用指针接收者；只读或 struct 很小时使用值接收者。

### 练习 1：基础语法

编写 Go 程序，读取命令行输入的两个整数，打印它们的和、差、积、商（处理除零错误）。

```go
package main

import (
    "errors"
    "fmt"
    "os"
    "strconv"
)

// calculate 对两个整数执行四则运算
// 返回和、差、积、商和可能的错误（Go 多返回值模式）
func calculate(a, b int) (sum, diff, product int, quotient float64, err error) {
    sum = a + b
    diff = a - b
    product = a * b
    if b == 0 {
        err = errors.New("division by zero")
        return  // 裸 return，返回当前命名返回值
    }
    quotient = float64(a) / float64(b)
    return
}

func main() {
    if len(os.Args) < 3 {
        fmt.Println("用法: go run main.go <整数1> <整数2>")
        return
    }
    // strconv.Atoi 将字符串转成 int（等价 Python 的 int()）
    a, err := strconv.Atoi(os.Args[1])
    if err != nil {
        fmt.Println("参数1不是有效整数:", err)
        return
    }
    b, err := strconv.Atoi(os.Args[2])
    if err != nil {
        fmt.Println("参数2不是有效整数:", err)
        return
    }

    sum, diff, product, quotient, err := calculate(a, b)
    if err != nil {
        fmt.Println("错误:", err)
        return
    }
    fmt.Printf("和: %d\n差: %d\n积: %d\n商: %.2f\n", sum, diff, product, quotient)
}
```

**注释**：这个练习综合了命令行参数（`os.Args`）、类型转换（`strconv.Atoi`）、多返回值、命名返回值、错误处理。对比 Python 的 `a, b = int(sys.argv[1]), int(sys.argv[2])`，Go 的错误处理更显式。

### 练习 2：数据结构

实现 `unique()` 去重函数和 `wordCount()` 词频统计函数。

```go
package main

import (
    "fmt"
    "strings"
)

// unique 对 slice 去重并保持原始顺序
// 用 map[int]bool 模拟 set（Go 无内置 set 类型）
func unique(nums []int) []int {
    seen := make(map[int]bool)
    result := make([]int, 0)
    for _, n := range nums {
        if !seen[n] {
            seen[n] = true
            result = append(result, n)
        }
    }
    return result
}

// wordCount 统计文本中每个单词的出现次数
// 对比 Python: collections.Counter(text.split())
func wordCount(text string) map[string]int {
    // strings.Fields 按空白分割（等价 Python 的 text.split()）
    words := strings.Fields(text)
    freq := make(map[string]int)
    // range slice 返回 (索引, 值)，用 _ 忽略索引
    for _, word := range words {
        freq[word]++  // 零值 0 直接 ++，无需 defaultdict
    }
    return freq
}

func main() {
    nums := []int{1, 2, 2, 3, 3, 3, 4}
    fmt.Println(unique(nums))  // [1 2 3 4]

    text := "go go python rust go"
    for word, count := range wordCount(text) {
        fmt.Printf("%s: %d\n", word, count)
    }
    // go: 3, python: 1, rust: 1（map 遍历顺序随机）
}
```

**注释**：`map[int]bool` 模拟 set 是 Go 的标准做法。`freq[word]++` 利用零值特性——不存在的 key 返回 0，`0++` 变成 1。Python 需用 `defaultdict(int)` 或 `Counter`。

### 练习 3：结构体与方法

设计 `Rectangle` struct，实现 `Area()`、`Perimeter()` 和 `String()` 方法。

```go
package main

import "fmt"

// Rectangle 矩形结构体（等价 Python 的 @dataclass）
type Rectangle struct {
    Width  float64
    Height float64
}

// NewRectangle 构造函数约定（Go 无 __init__）
func NewRectangle(w, h float64) *Rectangle {
    return &Rectangle{Width: w, Height: h}
}

// Area 计算面积（值接收者，只读方法）
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// Perimeter 计算周长（值接收者，只读方法）
func (r Rectangle) Perimeter() float64 {
    return 2 * (r.Width + r.Height)
}

// String 实现 fmt.Stringer 接口（等价 Python 的 __str__）
// 隐式实现：不需要声明 implements Stringer
func (r Rectangle) String() string {
    return fmt.Sprintf("Rectangle{%.1f × %.1f, area=%.2f, peri=%.2f}",
        r.Width, r.Height, r.Area(), r.Perimeter())
}

func main() {
    r := NewRectangle(3.0, 4.0)
    // fmt.Println 会自动调用 String() 方法
    fmt.Println(r)  // Rectangle{3.0 × 4.0, area=12.00, peri=14.00}
    fmt.Printf("面积: %.2f, 周长: %.2f\n", r.Area(), r.Perimeter())
}
```

**注释**：这个练习展示了 Go OOP 的完整模式：struct 定义数据、`NewXxx()` 构造函数、值接收者只读方法、`String()` 实现 `fmt.Stringer` 接口（隐式实现，等价 Python 的 `__str__`）。
