## 📝 正文内容

### 题目描述

规定一种密码的加密方法：

- **英文字母**：按照字母表顺序向后移动一位，同时改变大小写
  - `Z` → `a`，`A` → `b`，`B` → `c`，...，`Y` → `z`
- **数字**：增加 1，`9` → `0`

字符串的解密方法即为加密方法的逆过程。

给定明文字符串 `s`，将其加密；给定密文字符串 `t`，将其解密。

### 输入输出

| 项目 | 说明 |
|------|------|
| **输入** | 第一行：明文字符串 `s`（长度 1 ≤ len ≤ 10³）<br>第二行：密文字符串 `t` |
| **输出** | 第一行：加密后的 `s`<br>第二行：解密后的 `t` |
| **字符范围** | 仅包含英文字母和数字 |

### 示例

```
输入：
abcdefg1
0BCDEFGH

输出：
BCDEFGH2
9abcdefg
```

### 解题思路

#### 加密规则
| 原字符 | 加密后 | 说明 |
|--------|--------|------|
| `a~y` | 后移一位 + 转大写 | `a→B` |
| `z` | `A` | 循环 |
| `A~Y` | 后移一位 + 转小写 | `A→b` |
| `Z` | `a` | 循环 |
| `0~8` | 数字 + 1 | `0→1` |
| `9` | `0` | 循环 |

#### 解密规则
与加密相反：字母前移一位并转换大小写，数字减 1（`0→9`）。

### 参考代码

```python
import string

def encoder_func(decoder_str):
    encoder_str = ""
    # 小写字母：后移一位 + 转大写，a→B, ..., z→A
    next_upper = {
        c: string.ascii_uppercase[(i + 1) % 26]
        for i, c in enumerate(string.ascii_lowercase)
    }
    # 大写字母：后移一位 + 转小写，A→b, ..., Z→a
    next_lower = {
        c: string.ascii_lowercase[(i + 1) % 26]
        for i, c in enumerate(string.ascii_uppercase)
    }
    # 数字：+1，9→0
    next_digit = {str(d): str((d + 1) % 10) for d in range(10)}
    code_dict = next_upper | next_lower | next_digit
    for item in decoder_str:
        encoder_str += code_dict[item]
    return encoder_str

def decoder_func(encoder_str):
    decoder_str = ""
    # 大写字母：前移一位 + 转小写，B→a, ..., A→z
    pre_lower = {
        c: string.ascii_lowercase[(i - 1) % 26]
        for i, c in enumerate(string.ascii_uppercase)
    }
    # 小写字母：前移一位 + 转大写，b→A, ..., a→Z
    pre_upper = {
        c: string.ascii_uppercase[(i - 1) % 26]
        for i, c in enumerate(string.ascii_lowercase)
    }
    # 数字：-1，0→9
    pre_digit = {str(d): str((d - 1) % 10) for d in range(10)}
    code_dict = pre_lower | pre_upper | pre_digit
    for item in encoder_str:
        decoder_str += code_dict[item]
    return decoder_str

while True:
    try:
        print(encoder_func(input()))
        print(decoder_func(input()))
    except EOFError:
        break
```
