## 题目描述

对于给定的十六进制数，输出其对应的十进制表示。

在本题中，十六进制数的格式为：`0x` 开头，后跟若干个十六进制数字（保证为 `0-9` 和 `A-F` 中的一个）。其中，`A-F` 依次代表十进制中的 $10 \sim 15$。

## 输入描述

在一行上输入一个十六进制数 $s$，代表待转换的十六进制数，格式见题干。保证 $s$ 转化得到的十进制数 $x$ 的范围为 $1 \leq x < 2^{31}$。

## 输出描述

在一行上输出一个整数，代表 $s$ 对应的十进制数。

## 示例

**输入：**
```
0xFA93
```

**输出：**
```
64147
```

**说明：**
回忆十六进制转化为十进制的方法：从右往左，将第 $i$ 位乘以 $16^{i}$，然后求和。

在这个样例中，`0xFA93` 的第 $0$ 位是 `3`，第 $1$ 位是 `9`，第 $2$ 位是 `A`，第 $3$ 位是 `F`，因此：

$$
\text{0xFA93} = 3 \times 16^{0} + 9 \times 16^{1} + 10 \times 16^{2} + 15 \times 16^{3} = 64147
$$

## Python 进制转换方法

### 内置函数

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| `bin(x)` | 十进制 → 二进制（`0b` 前缀） | `bin(42)` | `'0b101010'` |
| `oct(x)` | 十进制 → 八进制（`0o` 前缀） | `oct(42)` | `'0o52'` |
| `hex(x)` | 十进制 → 十六进制（`0x` 前缀） | `hex(42)` | `'0x2a'` |
| `int(s, base)` | 任意进制 → 十进制 | `int('0xFA93', 16)` | `64147` |

```python
# 十进制 → 各进制
n = 64147
print(bin(n))   # 0b1111101010010011
print(oct(n))   # 0o175223
print(hex(n))   # 0xfa93

# 任意进制 → 十进制
print(int('0xFA93', 16))   # 64147
print(int('0b1010', 2))    # 10
print(int('0o77', 8))      # 63
# int() 的第二个参数可以是 2~36 之间的任意进制
print(int('zz', 36))       # 1295
```

### f-string 格式化

```python
n = 255

print(f"{n:b}")    # 11111111       二进制，无前缀
print(f"{n:#b}")   # 0b11111111     二进制，带前缀
print(f"{n:08b}")  # 11111111       二进制，8位补零

print(f"{n:o}")    # 377            八进制，无前缀
print(f"{n:#o}")   # 0o377          八进制，带前缀

print(f"{n:x}")    # ff             十六进制，小写
print(f"{n:X}")    # FF             十六进制，大写
print(f"{n:#x}")   # 0xff           十六进制，带前缀
print(f"{n:#06x}") # 0x00ff         十六进制，4位补零
```

### 手动转换算法

#### 十进制 → 其他进制（除基取余法）

```python
def dec_to_base(n: int, base: int) -> str:
    """将十进制数 n 转换为 base 进制（2 <= base <= 36）"""
    if n == 0:
        return "0"

    digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    result = []
    is_negative = n < 0
    n = abs(n)

    while n > 0:
        result.append(digits[n % base])
        n //= base

    if is_negative:
        result.append("-")

    return "".join(reversed(result))

# 示例
print(dec_to_base(64147, 16))  # FA93
print(dec_to_base(64147, 2))   # 1111101010010011
print(dec_to_base(64147, 8))   # 175223
```

#### 任意进制 → 十进制（按权展开法）

```python
def base_to_dec(s: str, base: int) -> int:
    """将 base 进制字符串 s 转换为十进制"""
    digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    s = s.upper().lstrip("-")
    result = 0
    for ch in s:
        result = result * base + digits.index(ch)
    return result

# 示例
print(base_to_dec("FA93", 16))         # 64147
print(base_to_dec("1111101010010011", 2))  # 64147
```

### 进制间快速互转

```python
# 二进制 ↔ 八进制：每 3 位一组
# 二进制 ↔ 十六进制：每 4 位一组

def bin_to_hex(bin_str: str) -> str:
    """二进制 → 十六进制"""
    return hex(int(bin_str, 2))[2:].upper()

def hex_to_bin(hex_str: str) -> str:
    """十六进制 → 二进制"""
    return bin(int(hex_str, 16))[2:]

print(bin_to_hex("1111101010010011"))  # FA93
print(hex_to_bin("FA93"))              # 1111101010010011
```
