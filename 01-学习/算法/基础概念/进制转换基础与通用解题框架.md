## 前置知识

### 什么是进制

每个数位有不同的**权重**。十进制每位权重是 10 的幂，二进制每位权重是 2 的幂：

```
十进制 356 = 3×10² + 5×10¹ + 6×10⁰ = 300 + 50 + 6
二进制 1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11
```

### 常见进制

| 进制 | 基数 | 数字 | 前缀 | 应用 |
|------|------|------|------|------|
| 二进制 | 2 | 0,1 | `0b` | 计算机底层 |
| 八进制 | 8 | 0-7 | `0o` | Unix 权限 |
| 十进制 | 10 | 0-9 | 无 | 日常 |
| 十六进制 | 16 | 0-9,A-F | `0x` | 颜色码、内存地址 |

## Python 内置转换

```python
# 十进制 → 其他进制（返回字符串）
bin(42)   # '0b101010'
oct(42)   # '0o52'
hex(42)   # '0x2a'

# 其他进制 → 十进制
int('101010', 2)   # 42
int('52', 8)       # 42
int('2a', 16)      # 42

# 通用转换（2-36进制都支持）
int('zz', 36)      # 1295
```

## 手写转换（核心模板）

### 模板 A：十进制 → N 进制（短除法）

```python
def decimal_to_base(num, base):
    """十进制整数转 base 进制（2-16），返回字符串"""
    if num == 0:
        return "0"

    digits = "0123456789ABCDEF"
    res = []
    while num > 0:
        res.append(digits[num % base])   # 每次取余数 = 当前位
        num //= base                      # 整除基数
    return ''.join(reversed(res))         # 倒序！

# 示例
decimal_to_base(42, 2)   # '101010'
decimal_to_base(42, 16)  # '2A'
```

> [!tip] 短除法口诀
> **"不断除以基数，倒着读余数"** — 就像剥洋葱，先剥出来的是最低位。

### 模板 B：N 进制 → 十进制（按权展开）

```python
def base_to_decimal(s, base):
    """base 进制字符串 → 十进制整数"""
    digits = "0123456789ABCDEF"
    res = 0
    for ch in s:
        res = res * base + digits.index(ch.upper())   # 秦九韶算法
    return res

# 示例
base_to_decimal("101010", 2)   # 42
base_to_decimal("2A", 16)      # 42
```

> [!tip] 按权展开口诀
> **"逐位乘基数，累加当前值"** — 从左到右一遍过。

## 经典题型

### 类型 A：大数加法/乘法（模拟进位）

```python
# ====== 415. 字符串相加 ======
def addStrings(num1, num2):
    i, j = len(num1) - 1, len(num2) - 1
    carry = 0
    res = []
    while i >= 0 or j >= 0 or carry:
        n1 = int(num1[i]) if i >= 0 else 0
        n2 = int(num2[j]) if j >= 0 else 0
        total = n1 + n2 + carry
        res.append(str(total % 10))
        carry = total // 10
        i -= 1; j -= 1
    return ''.join(reversed(res))
```

### 类型 B：Excel 列名转换（特殊的 26 进制）

```python
# ====== 168. Excel 表列名称 ======
# 1→A, 26→Z, 27→AA, 28→AB ...
# ⚠️ 这不是标准 26 进制！没有 0，是 1-26
def convertToTitle(n):
    res = []
    while n > 0:
        n -= 1                     # 关键！偏移到 0-25
        res.append(chr(ord('A') + n % 26))
        n //= 26
    return ''.join(reversed(res))
```

## 常见易错点

> [!warning] **坑 1：`bin()` 返回带 `0b` 前缀的字符串**
> ```python
> bin(5)       # '0b101' — 有前缀！
> bin(5)[2:]   # '101'   — 需要去掉前缀
> ```

> [!warning] **坑 2：Excel 列名不是标准 26 进制**
> 标准 26 进制的数字范围是 0-25，但 Excel 列名是 1-26（A-Z）。
> 转换前必须 `n -= 1` 做偏移。

> [!warning] **坑 3：进位模拟中 `carry` 最后可能还有残留**
> ```python
> while i >= 0 or j >= 0 or carry:   # ← 必须检查 carry！
> ```

> [!warning] **坑 4：短除法结果需要反转**
> 每次 `% base` 拿到的是最低位，不反转的话结果就反了。
