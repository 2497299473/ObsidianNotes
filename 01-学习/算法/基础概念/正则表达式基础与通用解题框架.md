## 前置知识：正则表达式是什么

正则表达式 = **用模式（pattern）描述字符串的规则**，用来做匹配、查找、替换、分割。

---

## 基础语法速查

### 字符匹配

| 符号 | 含义 | 示例 |
|------|------|------|
| `.` | 匹配任意单个字符（除换行） | `a.c` → "abc", "a1c" |
| `\d` | 数字 [0-9] | `\d{3}` → "123" |
| `\w` | 字母数字下划线 [a-zA-Z0-9_] | |
| `\s` | 空白字符（空格、tab、换行） | |
| `[abc]` | 字符组，匹配 a/b/c 之一 | `[aeiou]` → 元音 |
| `[^abc]` | 否定字符组，不匹配 a/b/c | |
| `\D` `\W` `\S` | 取反：非数字/非单词/非空白 | |

### 量词

| 符号 | 含义 |
|------|------|
| `*` | 0 次或多次（贪婪） |
| `+` | 1 次或多次（贪婪） |
| `?` | 0 次或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |
| `*?` `+?` | 非贪婪（尽可能少匹配） |

### 位置

| 符号 | 含义 |
|------|------|
| `^` | 字符串开头 |
| `$` | 字符串结尾 |
| `\b` | 单词边界 |

### 分组

| 符号 | 含义 |
|------|------|
| `(abc)` | 捕获组（提取匹配内容） |
| `(?:abc)` | 非捕获组（只分组，不提取） |
| `\|` | 或 |

## Python `re` 模块核心方法

```python
import re

# ① 判断是否匹配（从开头匹配）
re.match(r'\d+', '123abc')    # 匹配到 '123'（从开头）
re.match(r'\d+', 'abc123')    # None（不在开头）

# ② 搜索第一个匹配（任意位置）
re.search(r'\d+', 'abc123def')  # 匹配到 '123'

# ③ 查找所有匹配
re.findall(r'\d+', 'a1b2c3')    # ['1', '2', '3']

# ④ 替换
re.sub(r'\d+', '#', 'a1b2c3')   # 'a#b#c#'

# ⑤ 分割
re.split(r'\s+', 'a  b   c')    # ['a', 'b', 'c']

# ⑥ 编译（复用同一个正则）
pattern = re.compile(r'\d+')
pattern.findall('a1b2c3')
```

> [!tip] 用 `r''` 原始字符串
> 正则里反斜杠特别多，用 `r'\d'` 而不是 `'\d'`，避免 Python 先转义一次。

## LeetCode 中的正则实战

### 题型 A：使用正则一行秒杀

```python
# ====== 125. 验证回文串（正则版） ======
def isPalindrome(s):
    s = re.sub(r'[^a-zA-Z0-9]', '', s).lower()
    return s == s[::-1]

# ====== 151. 翻转字符串里的单词 ======
def reverseWords(s):
    return ' '.join(re.split(r'\s+', s.strip())[::-1])
```

### 题型 B：手写简易正则引擎

部分题目要求**自己实现**正则匹配（有限状态自动机 / DP）：

```python
from functools import lru_cache

# ====== 10. 正则表达式匹配 ======
# 实现 . 和 * 的匹配（DP 解法）
def isMatch(s, p):
    m, n = len(s), len(p)

    @lru_cache(None)
    def dp(i, j):
        if j == n:
            return i == m
        first_match = i < m and p[j] in {s[i], '.'}
        if j + 1 < n and p[j+1] == '*':
            return dp(i, j+2) or (first_match and dp(i+1, j))
        return first_match and dp(i+1, j+1)

    return dp(0, 0)
```

## 常见易错点

> [!warning] **坑 1：忘记转义特殊字符**
> `.` `*` `+` `?` `[` `]` `(` `)` `{` `}` `^` `$` `|` `\` 都是特殊字符，匹配字面值时要转义：`\.` `\*`

> [!warning] **坑 2：贪婪 vs 非贪婪**
> ```python
> re.findall(r'<.*>', '<a><b>')    # ['<a><b>']  — 贪婪，尽量多匹配
> re.findall(r'<.*?>', '<a><b>')   # ['<a>', '<b>'] — 非贪婪
> ```

> [!warning] **坑 3：`re.match` vs `re.search`**
> `match` 只从开头匹配；`search` 在任意位置搜索。多数时候你要的是 `search` 或 `findall`。

> [!warning] **坑 4：`re.sub` 默认替换所有匹配**
> 用 `count=1` 参数限制替换次数。
