## 第一部分：分治（Divide & Conquer）

### 1.1 一句话理解

> 把大问题拆成**和原问题一模一样的小问题**，递归解决，再把答案拼回来。

三个步骤：

```
分治(问题):
    1. 分（Divide）  → 拆成 k 个规模更小的子问题
    2. 治（Conquer） → 递归解决每个子问题（直到触底）
    3. 合（Combine） → 把子问题的解合并成最终答案
```

### 1.2 通用模板

```python
def solve(problem):
    # 1. 终止条件（触底）
    if 问题足够小:
        return 直接求解(problem)
    
    # 2. 分：拆成子问题
    subproblems = split(problem)
    
    # 3. 治：递归求解
    sub_results = [solve(sub) for sub in subproblems]
    
    # 4. 合：合并结果
    return merge(sub_results)
```

### 1.3 经典实例

#### 归并排序 —— 分治的完美原型

```python
def merge_sort(nums):
    # 终止：只剩一个元素时天然有序
    if len(nums) <= 1:
        return nums
    
    # 分：从中间切开
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])
    
    # 合：合并两个有序数组
    return merge(left, right)

def merge(a, b):
    res = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            res.append(a[i]); i += 1
        else:
            res.append(b[j]); j += 1
    res.extend(a[i:])
    res.extend(b[j:])
    return res
```

**时间复杂度推导**：$T(n) = 2T(n/2) + O(n)$ → $O(n \log n)$

#### 快速排序 —— 另一种分治形态

```python
def quick_sort(nums):
    if len(nums) <= 1:
        return nums
    
    pivot = nums[0]  # 选基准
    left = [x for x in nums[1:] if x <= pivot]
    right = [x for x in nums[1:] if x > pivot]
    
    # 组合：左边 + pivot + 右边
    return quick_sort(left) + [pivot] + quick_sort(right)
```

> **快排 vs 归并**：快排的"分"在工作（partition），"合"是免费的不需要额外操作；归并的"分"是免费的（切两半），"合"是重头戏。

#### 快速幂 —— 分治化简计算

```python
def my_pow(x, n):
    if n == 0:
        return 1
    if n < 0:
        return 1 / my_pow(x, -n)
    
    half = my_pow(x, n // 2)
    if n % 2 == 0:
        return half * half
    else:
        return half * half * x
```

时间复杂度从 $O(n)$ 降到 $O(\log n)$。

### 1.5 什么时候想到分治？

- **"把大问题拆成相同的子问题"** → 比如「合并 K 个」可以拆成「合并 2 个」
- **数据具有自相似结构** → 比如二叉树的子树也是二叉树
- **$O(n^2)$ 可以压到 $O(n \log n)$** → 比如归并、快速幂
- **看到 $\log n$ 或 $\log k$** → 大概率是分治或二分

## 第二部分：堆（Heap / 优先队列）

### 2.1 一句话理解

> 一个能**动态维护极值**的数据结构：任何时候取最小/最大值只要 $O(1)$，插入删除只要 $O(\log n)$。

### 2.2 核心概念

```
最小堆（小顶堆）：
        1        ← 堆顶永远是最小值
       / \
      3   2
     / \ / \
    7  4 5  6
    
- 父节点 ≤ 子节点
- 是完全二叉树，用数组存
- 插入（上浮）：加到末尾，一路跟父节点交换直到就位
- 删除（下沉）：堆顶换到末尾删掉，新堆顶一路跟较小子节点交换
```

### 2.3 Python `heapq` 速查

```python
import heapq

# Python 只有最小堆，最大堆需要对值取负
heap = []

# 插入
heapq.heappush(heap, 5)   # [5]
heapq.heappush(heap, 2)   # [2, 5]
heapq.heappush(heap, 8)   # [2, 5, 8]

# 取堆顶（不删除）
top = heap[0]             # 2

# 弹出堆顶
min_val = heapq.heappop(heap)  # 2, heap → [5, 8]

# 批量建堆（线性时间！）
nums = [5, 2, 8, 1]
heapq.heapify(nums)       # nums → [1, 2, 8, 5]（堆序，不一定完全排序）

# 最大堆：取负值
max_heap = []
heapq.heappush(max_heap, -5)   # 存 -5
max_val = -heapq.heappop(max_heap)  # 取 5

# 堆元素为元组时，按第一个元素排序
# 常用于：需要额外信息 + 按优先级排列
heapq.heappush(heap, (priority, item))
```

### 2.4 通用模板

#### Top K 问题模板

```python
import heapq

def top_k(nums, k):
    """
    Top K 大 → 用最小堆（维护当前最大的 k 个）
    Top K 小 → 用最大堆（维护当前最小的 k 个）
    """
    heap = []
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)  # 踢掉最小的
    return heap  # 堆里就是最大的 k 个
```

#### 多路归并模板

```python
import heapq

def merge_k_streams(streams):
    """
    streams: 多个有序迭代器
    用最小堆维护每个流的当前头元素
    """
    heap = []
    # 初始化：每个流的第一个元素入堆
    for i, stream in enumerate(streams):
        first = next(stream, None)
        if first is not None:
            heapq.heappush(heap, (first, i, stream))
    
    result = []
    while heap:
        val, i, stream = heapq.heappop(heap)
        result.append(val)
        # 从同一个流取下一个元素
        nxt = next(stream, None)
        if nxt is not None:
            heapq.heappush(heap, (nxt, i, stream))
    
    return result
```

### 2.6 什么时候想到堆？

- **Top K** — 最直接的信号："第 K 大/小"、"前 K 个"
- **动态数据取极值** — 数据在变化，每次都想知道当前最大/最小
- **多路归并** — K 个有序序列合并成一个
- **中位数** — 最大堆存左半、最小堆存右半
- **看到 $O(n \log k)$** — 大概率堆

## 第三部分：分治 vs 堆 —— 交叉与选择

以 [[23. 合并 K 个升序链表]] 为例，两种解法对比：

| 维度 | 分治（两两归并） | 堆（优先队列） |
|------|-----------------|---------------|
| **思路** | 像归并排序：两两配对合并 | 像排队：每次取全局最小 |
| **时间复杂度** | $O(n \log k)$ | $O(n \log k)$ |
| **空间复杂度** | $O(1)$（递归栈 $O(\log k)$） | $O(k)$（堆大小） |
| **代码难度** | 中等（递归） | 中等（heapq） |
| **适用场景** | k 较大时空间更优 | 流式数据更适合 |
| **核心操作** | 合并两个有序链表 | 堆的 push/pop |

### 选择策略

```
数据是一次性给我的（静态）
    ├── k 很大 → 分治（省内存）
    └── k 不大 → 哪个顺手写哪个

数据是流式/动态的
    └── 只能用堆（新数据随时来，堆动态维护）
```

## 第四部分：常见陷阱与易错点

### 分治

- **忘了终止条件** → 死循环/栈溢出，永远是第一行写 `if ... return`
- **子问题不是原问题的同构** → 分治要求子问题结构一致
- **合并步骤的时间复杂度被忽略** → 比如合并两个链表是 $O(m+n)$，不能用数组拼接思维

### 堆

- **Python 只有最小堆** → 最大堆记住**取负**
- **堆不是有序的** → `heap[0]` 是最小值，但 `heap[1]` 不一定比 `heap[2]` 小
- **自定义对象要可比较** → 存元组 `(priority, index, item)`，index 用来破平
- **建堆用 `heapify` 是 $O(n)$** → 比逐个 push 的 $O(n \log n)$ 更快

## 第六部分：量化场景应用——TopK 就是截面选股

> 2026-09 增补。堆在量化研究里的对应物是"截面筛选"：每个交易日从几千只股票里按因子得分选前 K 只——见 [[01-学习/量化研究/00-量化研究与回测学习路径总索引|量化研究与回测]] 专题。

### 应用 1：截面 TopK 选股

全市场按因子值排序取前 100：全排序 O(n log n)，Top K 模板 O(n log k)（n=5000、k=100 时差距明显），且逐日滚动筛选天然是**流式**场景，堆更贴合：

```python
import heapq

def top_k_stocks(factor_scores: dict, k: int):
    """截面因子筛选：返回得分最高的 k 只股票
    factor_scores: {股票代码: 因子得分}"""
    heap = []  # 最小堆维护当前最大的 k 个
    for code, score in factor_scores.items():
        if len(heap) < k:
            heapq.heappush(heap, (score, code))
        elif score > heap[0][0]:
            heapq.heapreplace(heap, (score, code))  # 踢掉当前第 k 大
    return sorted(heap, reverse=True)  # 按得分降序
```

### 应用 2：事件驱动的回测调度

事件驱动回测引擎的"下一个该处理谁"——撮合、止盈、止损、数据到达都是带时间戳的事件。最小堆按 `(时间, 优先级)` 组织，pop 最早事件、处理完再 push 新事件，正是**多路归并模板**的直接应用。

### 应用 3：流式数据的中位数/分位数

盘中监控"当前全部持仓收益的中位数"，数据不断流入、不能每次全排序——[[295. 数据流的中位数]] 的双堆模板就是标准答案。

> [!tip] 选型口诀（量化版）
> 每天全市场排序一次 → `sorted` 就够；**逐笔/逐日滚动维护 TopK 或极值** → 堆；**K 个数据源按时间归并** → 多路归并堆。
