## 前置知识：矩阵就是二维数组

### 一行一行地理解

矩阵在代码中就是 `List[List[int]]` —— 外层 list 的每个元素是一个 list（一行），内层 list 的元素是具体数值。

```python
# 一个 3×4 矩阵
matrix = [
    [1,  2,  3,  4],   # 第 0 行
    [5,  6,  7,  8],   # 第 1 行
    [9, 10, 11, 12]    # 第 2 行
]

# 访问规则
# matrix[i][j] = 第 i 行、第 j 列的元素
# matrix[1][2] = 7
```

```
         列 0   列 1   列 2   列 3
行 0:   [ 1  ][ 2  ][ 3  ][ 4 ]
行 1:   [ 5  ][ 6  ][ 7  ][ 8 ]
行 2:   [ 9  ][ 10 ][ 11 ][ 12 ]

matrix[0][0] = 1     matrix[0][3] = 4
matrix[2][0] = 9     matrix[2][3] = 12
```

### 基本属性

```python
rows = len(matrix)        # 行数：外层 list 的长度
cols = len(matrix[0])     # 列数：内层 list 的长度（假设非空）

# 遍历每一个元素
for i in range(rows):
    for j in range(cols):
        print(matrix[i][j])
```

> [!warning] 空矩阵判断
> ```python
> if not matrix or not matrix[0]:
>     return 0   # 行数为 0 或列数为 0
> ```

## 核心遍历模式

### 模式 1：按行遍历（最基础）

```python
# 一行一行处理
for i in range(rows):
    for j in range(cols):
        # 对 matrix[i][j] 做操作
        pass
```

### 模式 2：按列遍历

```python
# 一列一列处理（修改列优先的题目）
for j in range(cols):
    for i in range(rows):
        # 对 matrix[i][j] 做操作
        pass
```

### 模式 3：对角线遍历

```python
# 主对角线：i == j，元素为 matrix[i][i]
for i in range(min(rows, cols)):
    print(matrix[i][i])

# 副对角线：i + j == cols - 1（以 m×n 方形为例）
for i in range(rows):
    print(matrix[i][cols - 1 - i])
```

### 模式 4：螺旋遍历

```python
# 按 上→右→下→左 的顺序，一圈一圈收缩
# 见模板 B：边界收缩法
```

> [!tip] 遍历模式的选择
> • 大部分题目：**按行遍历**就够了
> • 列优先的题目（如"每列的最大值"）：**按列遍历**
> • 对角线相关（如"判断托普利茨矩阵"）：**对角线遍历**
> • 螺旋矩阵类：**边界收缩法**

### 🟢 模板 A：按行 / 按列遍历（基础）

**适用场景**：矩阵基础操作、统计、查找、reshape。

```python
# ====== 模板 A：按行遍历 ======
def row_traverse(matrix):
    """基础的行优先遍历框架"""
    if not matrix or not matrix[0]:
        return 结果

    rows, cols = len(matrix), len(matrix[0])

    for i in range(rows):
        for j in range(cols):
            # 对 matrix[i][j] 进行操作
            pass

    return 结果
```

> [!example] 示例：766. 托普利茨矩阵
> ```python
> def isToeplitzMatrix(matrix):
>     rows, cols = len(matrix), len(matrix[0])
>     for i in range(1, rows):
>         for j in range(1, cols):
>             if matrix[i][j] != matrix[i-1][j-1]:
>                 return False
>     return True

> [!example] 示例：566. 重塑矩阵
> ```python
> def matrixReshape(mat, r, c):
>     m, n = len(mat), len(mat[0])
>     if m * n != r * c:
>         return mat
>     flat = [mat[i][j] for i in range(m) for j in range(n)]
>     return [flat[i*c:(i+1)*c] for i in range(r)]
> ```

### 🔵 模板 B：边界收缩法（螺旋矩阵、旋转图像）

**核心思想**：用四个变量 `top/bottom/left/right` 标记当前待处理区域的边界，每处理完一条边就缩一格。

```python
# ====== 模板 B：边界收缩法 ======
def spiralOrder(matrix):
    """
    54. 螺旋矩阵
    核心：定义四个边界，按 左→右、上→下、右→左、下→上 的顺序遍历，
    每走完一条边就收缩对应边界。
    """
    if not matrix or not matrix[0]:
        return []

    rows, cols = len(matrix), len(matrix[0])
    top, bottom = 0, rows - 1
    left, right = 0, cols - 1
    result = []

    while top <= bottom and left <= right:
        # ① 左 → 右（顶行）
        for j in range(left, right + 1):
            result.append(matrix[top][j])
        top += 1                       # 顶行处理完，缩上边界

        # ② 上 → 下（右列）
        for i in range(top, bottom + 1):
            result.append(matrix[i][right])
        right -= 1                     # 右列处理完，缩右边界

        if top <= bottom:               # ⚠️ 防止重复处理
            # ③ 右 → 左（底行）
            for j in range(right, left - 1, -1):
                result.append(matrix[bottom][j])
            bottom -= 1                # 底行处理完，缩下边界

        if left <= right:               # ⚠️ 防止重复处理
            # ④ 下 → 上（左列）
            for i in range(bottom, top - 1, -1):
                result.append(matrix[i][left])
            left += 1                  # 左列处理完，缩左边界

    return result
```

> [!warning] 边界收缩的两道防线
> ```python
> if top <= bottom:    # 走完左右之后，上下边界可能已经交叉
> if left <= right:    # 走完上下之后，左右边界可能已经交叉
> ```
> 不加这两个判断，长方矩阵（如 3×1）会重复输出。

> [!example] 示例：48. 旋转图像
> ```python
> def rotate(matrix):
>     """
>     旋转 90 度 = 转置 + 水平翻转
>     也可以用边界收缩法：每次旋转四个角。
>     """
>     n = len(matrix)
>     # 方法一：转置 + 翻转
>     for i in range(n):
>         for j in range(i + 1, n):
>             matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
>     for i in range(n):
>         matrix[i].reverse()
>     # 方法二：边界收缩旋转四个角（见下面）
> ```
>
> 边界收缩旋转法：
> ```python
> def rotate_boundary(matrix):
>     n = len(matrix)
>     for i in range(n // 2):                    # 第 i 圈
>         for j in range(i, n - 1 - i):          # 该圈中的每个元素
>             temp = matrix[i][j]
>             matrix[i][j] = matrix[n-1-j][i]           # 左 → 上
>             matrix[n-1-j][i] = matrix[n-1-i][n-1-j]   # 下 → 左
>             matrix[n-1-i][n-1-j] = matrix[j][n-1-i]   # 右 → 下
>             matrix[j][n-1-i] = temp                    # 上 → 右
> ```

**对应题目**：

| 题目 | 边界收缩用法 | 关键技巧 |
|------|------------|---------|
| 54. 螺旋矩阵 | 标准四步收缩 | 两个 if 防重复 |
| 59. 螺旋矩阵 II | 同上，边填数字 | 模拟填充 |
| 48. 旋转图像 | 四角旋转 / 转置翻转 | 每一圈独立旋转 |

### 🔶 模板 C：原地标记（矩阵置零、岛屿数量）

**核心思想**：用矩阵本身的空间存储标记位，避免额外 O(mn) 的空间。

```python
# ====== 模板 C：原地标记 ======
def setZeroes(matrix):
    """
    73. 矩阵置零
    用第一行和第一列作为「标记数组」，O(1) 额外空间。
    """
    rows, cols = len(matrix), len(matrix[0])
    row0_zero = False   # 第 0 行是否有零（单独记录）
    col0_zero = False   # 第 0 列是否有零（单独记录）

    # ① 扫描：用第一行/第一列记录哪些行/列需要置零
    for i in range(rows):
        for j in range(cols):
            if matrix[i][j] == 0:
                if i == 0:
                    row0_zero = True
                if j == 0:
                    col0_zero = True
                matrix[i][0] = 0    # 标记第 i 行
                matrix[0][j] = 0    # 标记第 j 列

    # ② 根据第一行/第一列的标记，将对应的行/列置零
    for i in range(1, rows):
        for j in range(1, cols):
            if matrix[i][0] == 0 or matrix[0][j] == 0:
                matrix[i][j] = 0

    # ③ 处理第一行
    if row0_zero:
        for j in range(cols):
            matrix[0][j] = 0

    # ④ 处理第一列
    if col0_zero:
        for i in range(rows):
            matrix[i][0] = 0
```

> def numIslands(grid):
>     """DFS 遍历，遇陆地标记为水（'0'），避免 visited 数组"""

> ```

### 🟣 模板 D：DP on Grid（网格 DP）

**核心思想**：`dp[i][j]` 表示走到 `(i, j)` 的最优解，由 `dp[i-1][j]`（从上面来）和 `dp[i][j-1]`（从左边来）推导。

```python
# ====== 模板 D：网格 DP ======
def grid_dp(grid):
    """
    通用网格 DP 框架
    dp[i][j] = f(dp[i-1][j], dp[i][j-1], grid[i][j])
    """
    rows, cols = len(grid), len(grid[0])
    dp = [[0] * cols for _ in range(rows)]

    # ① 初始化起点
    dp[0][0] = grid[0][0]

    # ② 初始化第一行（只能从左边来）
    for j in range(1, cols):
        dp[0][j] = dp[0][j-1] + grid[0][j]

    # ③ 初始化第一列（只能从上面来）
    for i in range(1, rows):
        dp[i][0] = dp[i-1][0] + grid[i][0]

    # ④ 填充剩余格子
    for i in range(1, rows):
        for j in range(1, cols):
            dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
            #          ↑ 具体操作取决于题意

    return dp[rows-1][cols-1]
```

> [!example] 示例：64. 最小路径和
> ```python
> def minPathSum(grid):
>     rows, cols = len(grid), len(grid[0])
>     for i in range(rows):
>         for j in range(cols):
>             if i == 0 and j == 0:
>                 continue
>             elif i == 0:
>                 grid[i][j] += grid[i][j-1]     # 第一行：只能从左边
>             elif j == 0:
>                 grid[i][j] += grid[i-1][j]     # 第一列：只能从上边
>             else:
>                 grid[i][j] += min(grid[i-1][j], grid[i][j-1])
>     return grid[rows-1][cols-1]
> ```

> [!example] 示例：62. 不同路径
> ```python
> def uniquePaths(m, n):
>     """机器人从左上到右下，无障碍物"""
>     dp = [[1] * n for _ in range(m)]
>     for i in range(1, m):
>         for j in range(1, n):
>             dp[i][j] = dp[i-1][j] + dp[i][j-1]
>     return dp[m-1][n-1]
> ```

> [!tip] 网格 DP 的空间优化
> 因为 `dp[i][j]` 只依赖 `dp[i-1][j]`（上一行）和 `dp[i][j-1]`（左边），所以可以用**一维数组**代替二维：
> ```python
> def uniquePaths_1d(m, n):
>     dp = [1] * n
>     for i in range(1, m):
>         for j in range(1, n):
>             dp[j] += dp[j-1]     # dp[j] 是上面的值，dp[j-1] 是左边的值
>     return dp[-1]
> ```

**对应题目**：

| 题目 | dp 含义 | 转移方程 |
|------|--------|---------|
| 62. 不同路径 | 到 (i,j) 的路径数 | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` |
| 63. 不同路径 II | 同上，有障碍 | 障碍格 dp=0 |
| 64. 最小路径和 | 到 (i,j) 的最小和 | `dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]` |
| 120. 三角形最小路径和 | 自顶向下 | row 依赖 row-1 |
| 221. 最大正方形 | 以 (i,j) 为右下角的最大边长 | `dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1` |

## 常见易错点

> [!warning] **坑 1：行列索引写反**
> ```python
> # ❌ 容易写反
> matrix[j][i]    # i 是行，j 是列，顺序是 matrix[行][列]
>
> # ✅ 始终记住：matrix[i][j]，i=行，j=列
> ```

> [!warning] **坑 2：边界条件检查不全**
> ```python
> # ✅ 每次写 `matrix[i][j]` 或 `matrix[i+1][j]` 前，先确认索引不越界
> if i + 1 < rows and matrix[i+1][j] == target:
>     ...
>
> # ❌ 忘记检查 i+1 < rows，索引越界
> if matrix[i+1][j] == target:   # 可能越界！
> ```

> [!warning] **坑 3：螺旋矩阵漏加中间防重复判断**
> ```python
> # 54. 螺旋矩阵
> # ✅ 走完左右两步后，上下边界可能已经交叉，必须判断
> if top <= bottom:
>     for j in range(right, left - 1, -1): ...
>
> # ❌ 不加判断，长方矩阵会输出重复元素
> ```

> [!warning] **坑 4：原地标记忘记单独处理第一行/列**
> ```python
> # 73. 矩阵置零
> # 第一行和第一列既存储标记，又可能自身需要置零
> # ✅ 必须用两个布尔变量单独记录第一行/列自身是否需要置零
> row0_zero = any(matrix[0][j] == 0 for j in range(cols))
> col0_zero = any(matrix[i][0] == 0 for i in range(rows))
> ```

> [!warning] **坑 5：网格 DP 的第一行/第一列初始化**
> ```python
> # ✅ 第一行只能从左边来
> for j in range(1, cols):
>     dp[0][j] = dp[0][j-1] + grid[0][j]
>
> # ✅ 第一列只能从上面来
> for i in range(1, rows):
>     dp[i][0] = dp[i-1][0] + grid[i][0]
>
> # ❌ 直接用 i-1 和 j-1 公式，会导致索引 -1 取到最后一行/列
> ```
