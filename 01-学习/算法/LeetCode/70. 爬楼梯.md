## 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**示例 1：**

```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

**示例 2：**

```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```

**提示：** `1 <= n <= 45`

---

## 核心思路

### 为什么是斐波那契数列？

到达第 `n` 级台阶，**最后一步**只有两种可能：

- 从第 `n-1` 级迈 **1 步**上来 → 有 `f(n-1)` 种方法
- 从第 `n-2` 级迈 **2 步**上来 → 有 `f(n-2)` 种方法

**递推公式**：`f(n) = f(n-1) + f(n-2)`

| n   | f(n) | 斐波那契对照 |
|-----|------|------------|
| 1   | 1    | —          |
| 2   | 2    | —          |
| 3   | 3    | F(4)=3     |
| 4   | 5    | F(5)=5     |
| 5   | 8    | F(6)=8     |
| 6   | 13   | F(7)=13    |

> **关系**：`climbStairs(n) = Fib(n+1)`

---

## 动态规划五部曲

1. **dp[i] 含义**：爬到第 i 层有 dp[i] 种方法
2. **递推公式**：`dp[i] = dp[i-1] + dp[i-2]`
3. **初始化**：`dp[1] = 1, dp[2] = 2`
4. **遍历顺序**：从前往后（`i = 3 → n`）
5. **举例推导**：n=5 时 `[1, 2, 3, 5, 8]`

## 代码实现

### 方法一：记忆化递归（自顶向下）

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        from functools import lru_cache

        @lru_cache(maxsize=None)
        def dfs(i: int) -> int:
            if i <= 2:
                return i
            return dfs(i - 1) + dfs(i - 2)

        return dfs(n)
```

### 方法二：动态规划（自底向上，推荐面试）

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n

        dp = [0] * (n + 1)
        dp[1] = 1
        dp[2] = 2

        for i in range(3, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]

        return dp[n]
```

### 方法三：滚动变量（O(1) 空间，最优）

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n

        a, b = 1, 2  # f(1)=1, f(2)=2
        for _ in range(3, n + 1):
            a, b = b, a + b

        return b
```

### 方法四：通项公式（O(1) 时间）

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        n = n + 1  # 偏移到斐波那契
        sqrt5 = 5 ** 0.5
        phi = (1 + sqrt5) / 2
        psi = (1 - sqrt5) / 2
        return int((phi ** n - psi ** n) / sqrt5)
```

> ⚠️ 浮点精度在高 n 时可能出错，不推荐。

## 拓展：完全背包视角

可以推广为**一次最多爬 m 个台阶**：

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        m = 2  # 最多爬 2 个台阶
        dp = [0] * (n + 1)
        dp[0] = 1
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if i - j >= 0:
                    dp[i] += dp[i - j]
        return dp[n]
```
