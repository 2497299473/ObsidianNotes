## 题目描述

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**（原题示意图缺失，可参考 LeetCode 题面；下例柱高即上图：`[0,1,0,2,1,0,1,3,2,1,2,1]`，能接 6 个单位的雨水）

```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。
```

**示例 2：**

```
输入：height = [4,2,0,3,2,5]
输出：9
```

**提示：**

- `n == height.length`
- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`

---

## 核心思路

对于每个位置 `i`，该位置能接的雨水量由**左右两边最高柱子的较小者**决定：

$$\text{water}[i] = \max(0,\ \min(\text{leftMax}[i],\ \text{rightMax}[i]) - \text{height}[i])$$

> 想象每个位置是一个"木桶"，木桶能装多少水取决于**较短的"桶壁"**减去**自身高度**。

---

## 解法一：双指针（最优解）⭐

### 思路

不用预处理左右最大值数组，而是用两个指针 `left` 和 `right` 从两端向中间移动，**动态维护**左右两侧的最大高度。

核心洞察：对于 `left` 指针，只要 `leftMax < rightMax`，那么 `left` 位置的雨水量就完全由 `leftMax` 决定，无需关心 `rightMax` 的具体值（反之亦然）。

### 代码

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        if not height:
            return 0

        left, right = 0, len(height) - 1
        leftMax, rightMax = 0, 0
        ans = 0

        while left < right:
            leftMax = max(leftMax, height[left])
            rightMax = max(rightMax, height[right])

            if leftMax < rightMax:
                ans += leftMax - height[left]
                left += 1
            else:
                ans += rightMax - height[right]
                right -= 1

        return ans
```

```java
class Solution {
    public int trap(int[] height) {
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int ans = 0;

        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            if (leftMax < rightMax) {
                ans += leftMax - height[left];
                left++;
            } else {
                ans += rightMax - height[right];
                right--;
            }
        }
        return ans;
    }
}
```

|--------|-----|
| 时间 | $O(n)$ |
| 空间 | $O(1)$ |

## 解法二：动态规划（前缀/后缀最大值）

### 思路

预处理两个数组：
- `leftMax[i]`：`i` 左边（含 `i`）的最大高度
- `rightMax[i]`：`i` 右边（含 `i`）的最大高度

然后遍历每个位置计算雨水。

### 代码

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        if n == 0:
            return 0

        leftMax = [0] * n
        rightMax = [0] * n

        # 预处理 leftMax
        leftMax[0] = height[0]
        for i in range(1, n):
            leftMax[i] = max(leftMax[i - 1], height[i])

        # 预处理 rightMax
        rightMax[n - 1] = height[n - 1]
        for i in range(n - 2, -1, -1):
            rightMax[i] = max(rightMax[i + 1], height[i])

        # 计算雨水
        ans = 0
        for i in range(n):
            ans += min(leftMax[i], rightMax[i]) - height[i]

        return ans
```

| 复杂度 | 值 |
|--------|-----|
| 时间 | $O(n)$ |
| 空间 | $O(n)$ |

## 解法三：单调栈

### 思路

维护一个**单调递减栈**（存下标）。当遇到一个比栈顶高的柱子时，说明栈顶位置形成了一个"凹槽"，可以接水。

- 弹出栈顶作为**底部**
- 新栈顶作为**左边界**
- 当前柱子作为**右边界**
- 宽度 = `i - left - 1`，高度 = `min(height[left], height[i]) - height[bottom]`

### 代码

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        stack = []  # 单调递减栈，存下标
        ans = 0

        for i, h in enumerate(height):
            while stack and h > height[stack[-1]]:
                bottom = stack.pop()  # 凹槽底部
                if not stack:         # 没有左边界，无法接水
                    break
                left = stack[-1]      # 左边界
                width = i - left - 1
                height_diff = min(height[left], h) - height[bottom]
                ans += width * height_diff
            stack.append(i)

        return ans
```

| 复杂度 | 值 |
|--------|-----|
| 时间 | $O(n)$ |
| 空间 | $O(n)$ |

## 解法四：最小堆（逐层消除 — 你的思路！）🧠

### 直觉

把柱子想象成俄罗斯方块：**从最低的洼地开始，一层一层往上填平**。每次处理全局最矮的那个"边界"，如果它的邻居更矮，就形成洼地，先接满这一层的水；填平后邻居变成新的边界继续参与后续判断。

### 算法

这本质上是一个**从边界出发的洪水填充（Flood Fill）**，用最小堆来保证每次都处理当前最低的边界：

1. 把数组**两端**放入最小堆作为初始"外壳"
2. 弹出堆中**高度最小**的边界点
3. 检查其邻居：
   - 邻居更矮 → 产生洼地 → 接水量 = 当前边界高度 - 邻居高度
   - 邻居入堆，高度取其与当前边界的**较大值**（相当于"填平"到边界高度）
4. 重复直到堆空

### 代码

```python
import heapq

class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        if n <= 2:
            return 0

        visited = [False] * n
        heap = []

        # 1. 最外层边界入堆
        for i in [0, n - 1]:
            heapq.heappush(heap, (height[i], i))
            visited[i] = True

        ans = 0
        dirs = [-1, 1]  # 左右方向

        # 2. 从最低边界开始向内"灌水"
        while heap:
            h, i = heapq.heappop(heap)  # 当前全局最低边界

            for d in dirs:
                ni = i + d
                if 0 <= ni < n and not visited[ni]:
                    visited[ni] = True
                    # 邻居更矮 → 形成洼地，接水
                    if height[ni] < h:
                        ans += h - height[ni]
                    # 填平后入堆成为新边界
                    heapq.heappush(heap, (max(height[ni], h), ni))

        return ans
```

### 以 `[2, 0, 1, 3]` 为例演示

```
初始:
        █
    █   █
█   █ █ █
2 0 1 3        堆: [(2,0), (3,3)]
               ↑最低

弹出 (2,0):  邻居 0 < 2 → 接水 2，填平到 2 入堆
弹出 (2,1):  邻居 1 < 2 → 接水 1，填平到 2 入堆

总水量 = 3 ✓
```

> 这个解法完美对应了你「从最低点开始、像俄罗斯方块一样逐层消除洼地」的直觉！

| 复杂度 | 值 |
|--------|-----|
| 时间 | $O(n \log n)$ |
| 空间 | $O(n)$ |

## 四种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 核心思想 |
|------|-----------|-----------|----------|
| 双指针 | $O(n)$ | $O(1)$ ⭐ | 从两端收缩，动态维护左右最大值 |
| DP 前缀最大值 | $O(n)$ | $O(n)$ | 预处理左右最大值，直观计算 |
| 单调栈 | $O(n)$ | $O(n)$ | 遇到高点时弹出栈顶，计算凹槽积水 |
| 最小堆（逐层消除） | $O(n \log n)$ | $O(n)$ | 自底向上 flooding，逐层填平洼地 |

> **面试推荐**：优先掌握**双指针**（最优空间），并了解 DP 方法便于解释思路。单调栈和最小堆作为加分项，其中最小堆的「逐层消除」直觉天然、易于理解。

## 图解本质

```
        █
    █░░░██░█
█░█░██░██████
```

柱子用 `█` 表示，水用 `░` 表示。每个位置的水量 = 两边"挡板"的最低值 - 自身高度。
