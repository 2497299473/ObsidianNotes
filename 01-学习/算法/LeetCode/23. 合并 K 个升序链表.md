## 题目描述

给你一个链表数组，每个链表都已经按**升序**排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

### 示例 1

```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6
```

### 示例 2

```
输入：lists = []
输出：[]
```

### 示例 3

```
输入：lists = [[]]
输出：[]
```

### 提示

- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- `lists[i]` 按 **升序** 排列
- `lists[i].length` 的总和不超过 `10^4`

## 解法思路

### 方法一：顺序合并（两两合并）

复用「合并两个有序链表」，逐个将 `lists[i]` 与当前结果合并。

- 时间复杂度：$O(k \cdot n)$，假设 k 个链表共 n 个节点

```python
class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        if not lists:
            return None
        p = lists[0]
        for i in range(1, len(lists)):
            p = self.mergeTwoLists(p, lists[i])
        return p

    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        if list1 is None:
            return list2
        if list2 is None:
            return list1
        if list1.val < list2.val:
            list1.next = self.mergeTwoLists(list1.next, list2)
            return list1
        else:
            list2.next = self.mergeTwoLists(list1, list2.next)
            return list2
```

### 方法二：分治合并

类似归并排序，两两配对后合并，减少重复合并次数。

- 时间复杂度：$O(n \log k)$

### 方法三：优先队列（最小堆）

将所有链表的头节点放入最小堆，每次弹出最小节点并加入其 next 节点。

- 时间复杂度：$O(n \log k)$
- 适合 k 较大的场景

### 方法四：暴力连接 + 排序

直接把 K 个链表连成一个，然后排序。

- 等价于 [[148. 排序链表]]
