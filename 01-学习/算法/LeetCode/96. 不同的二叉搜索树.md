## 题目描述

给你一个整数 `n` ，求恰由 `n` 个节点组成且节点值从 `1` 到 `n` 互不相同的 **二叉搜索树** 有多少种？返回满足题意的二叉搜索树的种数。

**示例 1：**

```
输入：n = 3
输出：5
```

**示例 2：**

```
输入：n = 1
输出：1
```

**提示：**

- `1 <= n <= 19`

---

## 核心疑惑：为什么 n=3 是 5 而不是 6？

> 你的疑惑非常关键：**{1, 2, 3} 明明有 6 种排列（3! = 6），为什么答案只有 5？那个 [2, 3, 1] 对应的结构去哪了？**

### 关键认知纠正

这道题求的不是「排列」，而是 **结构不同的二叉搜索树的个数**。不同的插入顺序可能产生**相同的 BST 结构**。

以 n=3 为例，6 种插入顺序对应的 BST 结构：

| 插入顺序 | BST 结构 | 说明 |
|----------|----------|------|
| [1, 2, 3] | 1 → 2 → 3（全右链） | 根=1，右子树含 {2,3}，呈链状 |
| [1, 3, 2] | 1 为根，3 为右子，2 为 3 的左子 | 根=1 |
| **[2, 1, 3]** | 2 为根，1 左子，3 右子 | 根=2，左右各一个 |
| **[2, 3, 1]** | **同上：2 为根，1 左子，3 右子** | ← 与 [2,1,3] **完全相同的结构！** |
| [3, 1, 2] | 3 为根，1 左子，2 为 1 的右子 | 根=3 |
| [3, 2, 1] | 3 → 2 → 1（全左链） | 根=3，左子树含 {1,2}，呈链状 |

**关键发现：[2, 1, 3] 和 [2, 3, 1] 产生完全相同的 BST！**

```
     [2, 1, 3] 构造过程:          [2, 3, 1] 构造过程:
     插入 2 →    2               插入 2 →    2
     插入 1 →  1   2  (1<2)      插入 3 →    2
                                              \
     插入 3 →    2               插入 1 →    3  (1<2)
               / \                                \
              1   3                  插入 1 →      2
                                               / \
    最终结构:    2                             1   3  ← 相同！
              / \
             1   3
```

这就是为什么答案是 **5** 而不是 6 — 两个不同的插入顺序收敛到了同一个 BST 结构。

## 解题思路

### 动态规划

定义 `dp[i]` = 由 i 个节点组成的结构不同的 BST 数量。

**核心思想**：枚举 1~n 每个数作为根节点，计算左右子树的组合数。

当以 `j` 为根节点时：
- 左子树由 `{1, 2, ..., j-1}` 共 `j-1` 个节点组成 → `dp[j-1]` 种结构
- 右子树由 `{j+1, ..., i}` 共 `i-j` 个节点组成 → `dp[i-j]` 种结构
- 左右子树的组合相互独立，乘法原理 → `dp[j-1] × dp[i-j]`

**状态转移方程：**

$$dp[i] = \sum_{j=1}^{i} dp[j-1] \cdot dp[i-j]$$

**边界条件：**

- `dp[0] = 1`（空树也算一种结构）
- `dp[1] = 1`（单节点只有一种结构）

### 数学视角：卡特兰数

这个递推公式本质上就是**卡特兰数（Catalan Number）**：

$$C_n = \frac{1}{n+1} \binom{2n}{n}$$

前几项：1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, ...

## Python 代码

### 方法一：动态规划（推荐）

```python
class Solution:
    def numTrees(self, n: int) -> int:
        # dp[i] 表示 i 个节点能组成的 BST 数量
        dp = [0] * (n + 1)
        dp[0] = 1  # 空树算一种
        dp[1] = 1  # 单节点算一种

        for i in range(2, n + 1):
            # 枚举每个节点作为根节点
            for j in range(1, i + 1):
                # 左子树 j-1 个节点 × 右子树 i-j 个节点
                dp[i] += dp[j - 1] * dp[i - j]

        return dp[n]
```

**复杂度分析：**
- 时间复杂度：O(n²)
- 空间复杂度：O(n)

### 方法二：卡特兰数公式（数学法）

```python
import math

class Solution:
    def numTrees(self, n: int) -> int:
        # 卡特兰数公式: C_n = C(2n, n) / (n + 1)
        return math.comb(2 * n, n) // (n + 1)
```

**复杂度分析：**
- 时间复杂度：O(n)（计算组合数）
- 空间复杂度：O(1)

## 手算验证 n=3

```
dp[0] = 1
dp[1] = 1

dp[2] = dp[0]×dp[1] + dp[1]×dp[0]
      = 1×1 + 1×1 = 2

dp[3] = dp[0]×dp[2] + dp[1]×dp[1] + dp[2]×dp[0]
      = 1×2 + 1×1 + 2×1 = 5  ✓
```

## 扩展思考

- 为什么「空树」要算作 1？因为当根节点是最小值或最大值时，一边子树为空，空的子树只有一种"结构"（什么都没有），这样才能正确做乘法。
- 这题是 **「95. 不同的二叉搜索树 II」** 的简化版——95 题要求返回所有具体的 BST 结构，而本题只求数量。
- n ≤ 19 的约束很小，因为卡特兰数增长极快：C₁₉ 已经达到了 17 亿级别。
