```mermaid

    Q["缓存查询"] --> H{"命中?"}
    H -->|"是"| R["返回数据"]
    H -->|"否"| DB{"DB 查询"}

    DB -->|"查不到<br/>（穿透）"| P["布隆过滤器 / 空值缓存"]
    DB -->|"查到"| E{"热点 Key?"}

    E -->|"是"| B["互斥锁 / 逻辑过期"]

    C --> TTL{"大量 Key 同时过期?"}
```

## 🎯 阶段目标

学完本阶段后，你应该能：

1. 用 Lua 脚本实现原子操作
2. 配置 maxmemory 与淘汰策略并分析影响
3. 设计缓存-数据库一致性方案
4. 实现分布式锁并评估 Redlock 适用场景

| 层次 | 检查项 |
|------|--------|
| 🟢 基础 | 三篇的 🟢 项各跑通一条：`MULTI` 内必错命令不影响其余命令生效、`CONFIG GET maxmemory-policy` 输出当前策略、空值缓存下连读两次不存在的 key 只让 DB 计数 `+1` |
