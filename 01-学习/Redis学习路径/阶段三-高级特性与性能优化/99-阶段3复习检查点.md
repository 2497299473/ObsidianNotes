# 99-阶段3复习检查点

## 🟢 基础（必须掌握）

- [ ] 能使用 `MULTI`/`EXEC`/`WATCH` 实现事务
- [ ] 能用 Lua 脚本实现原子操作
- [ ] 能解释缓存穿透、缓存击穿、缓存雪崩的区别
- [ ] 能用 SETNX/Redisson/Redlock 实现分布式锁

## 🟡 进阶（综合运用）

- [ ] 能用布隆过滤器或空值缓存解决缓存穿透
- [ ] 能用互斥锁或逻辑过期解决缓存击穿
- [ ] 能使用 `INFO`、`SLOWLOG`、`MONITOR` 排查性能问题
- [ ] 能配置 maxmemory 与淘汰策略并分析其影响

## 🔴 挑战（独立判断）

- [ ] 能设计一个完整的缓存-数据库一致性方案（含更新、失效、补偿）
- [ ] 能独立分析 Redis 慢查询并给出优化方向
- [ ] 能评估 Redlock 的适用场景与争议点
