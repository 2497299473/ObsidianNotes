# 99-阶段2复习检查点

> 🎯 阶段验收口径：三行全绿即视为阶段二过关；每一行都要拿得出“命令输出或日志片段”作为证据，拿不出就不算过。

---

## 🎯 本文学完自检

| 层次 | 检查项 |
|------|--------|
| 🟢 基础 | `CONFIG SET appendfsync always/everysec/no` 各改一次并用 `CONFIG GET` 复核；`REPLICAOF` 搭 1 主 1 从，主 `SET` 后从 `GET` 一致且 `role:slave`；`--cluster create … --cluster-replicas 1` 后 `CLUSTER INFO` 为 `cluster_state:ok`、`cluster_slots_assigned:16384` |
| 🟡 进阶 | 给 RPO=1s / RPO=5min / 允许丢 1 小时 三档需求各选一种持久化组合并写 1 行理由；3 哨兵 quorum 2 杀主，日志凑齐 `+sdown` → `+odown`（带 `#quorum` 计数）→ `+switch-master`；`--cluster reshard` 迁 1000 槽后用 `CLUSTER COUNTKEYSINSLOT` 或 `CLUSTER SLOTS` 证明槽位分布已变 |
| 🔴 挑战 | 给一个 200GB、读写比 9:1、允许丢 1s、跨 3 机房的业务，产出 5 行选型结论（单机 / 主从+哨兵 / Cluster + 持久化组合 + 一个必踩的坑 + 一个可验收指标），并说明另两种方案为何出局 |
