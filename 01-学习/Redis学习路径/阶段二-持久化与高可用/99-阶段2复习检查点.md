# 99-阶段2复习检查点

## 🟢 基础（必须掌握）

- [ ] 能解释 RDB 与 AOF 的原理、触发条件与优缺点
- [ ] 能配置 AOF 的 always/everysec/no 三种刷盘策略
- [ ] 能搭建主从复制并验证数据同步
- [ ] 能搭建哨兵模式实现故障自动转移

## 🟡 进阶（综合运用）

- [ ] 能根据业务恢复点目标选择 RDB/AOF/混合持久化
- [ ] 能分析主从复制延迟的原因并给出优化方案
- [ ] 能配置 Redis Cluster 并实现数据分片
- [ ] 能处理 Cluster 节点扩容、缩容、故障迁移

## 🔴 挑战（独立判断）

- [ ] 能设计跨机房的 Redis 高可用架构
- [ ] 能制定 Redis 数据备份与灾难恢复方案
- [ ] 能对比 Codis、Twemproxy、Redis Cluster 三种分片方案
