# v7-监控与压测调优版

> 📍 **前置**：[[v6-Lua脚本与事务版]] → 本版本（最终版）

## 🎯 本版本目标

用 redis-benchmark 压测，分析慢查询，完成性能调优闭环。

---

## 💻 核心实现

### 压测

```bash
# 单机压测
redis-benchmark -h 127.0.0.1 -p 6379 -c 100 -n 100000 -t set,get -q -d 256
# SET: 120000 requests per second
# GET: 130000 requests per second

# Cluster 压测
redis-benchmark -h 127.0.0.1 -p 7000 --cluster -c 200 -n 200000 -t set,get
```

### 慢查询分析

```bash
redis-cli CONFIG SET slowlog-log-slower-than 10000  # >10ms 记录
redis-cli CONFIG SET slowlog-max-len 128
redis-cli SLOWLOG GET 10
redis-cli SLOWLOG RESET
```

### 性能监控

```bash
redis-cli INFO stats      # 命中率、连接数
redis-cli INFO memory     # 内存使用
redis-cli INFO cpu        # CPU 使用
redis-cli --bigkeys       # 大 Key 扫描
redis-cli --hotkeys       # 热 Key 扫描（需 LFU 策略）
```

### 调优清单

```bash
# 生产推荐配置
redis-cli CONFIG SET maxmemory 2gb
redis-cli CONFIG SET maxmemory-policy allkeys-lru
redis-cli CONFIG SET slowlog-log-slower-than 5000
redis-cli CONFIG SET activedefrag yes
```

| 项目 | 默认值 | 优化值 | 说明 |
|------|--------|--------|------|
| maxmemory-policy | noeviction | allkeys-lru | 缓存淘汰策略 |
| slowlog-log-slower-than | 10000 | 5000 | 慢查询阈值 |
| hash-max-ziplist-entries | 512 | 1024 | 减少内存 |
| activedefrag | no | yes | 碎片整理 |

### 完整压测脚本

```bash
#!/bin/bash
echo "=== Redis 压测报告 ==="

echo "1. 基准压测（SET/GET）"
redis-benchmark -h 127.0.0.1 -p 6379 -c 100 -n 100000 -t set,get -q

echo "2. Pipeline 压测"
redis-benchmark -h 127.0.0.1 -p 6379 -c 100 -n 100000 -P 10 -t set,get -q

echo "3. 大 Key 扫描"
redis-cli --bigkeys

echo "4. 慢查询"
redis-cli SLOWLOG GET 5

echo "5. 内存状态"
redis-cli INFO memory | head -5
```
