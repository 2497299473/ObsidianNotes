# v4-主从高可用版

> 📍 **前置**：[[v3-持久化与AOF版]] → 本版本 → [[v5-Cluster分片版]]

## 🎯 本版本目标

搭建 1 主 2 从 + 3 哨兵，实现：**故障自动转移 + 客户端无缝切换**。

---

## 💻 核心实现

### 哨兵配置

```bash
# sentinel.conf
port 26379
sentinel monitor mymaster 127.0.0.1 6379 2
sentinel down-after-milliseconds mymaster 5000
sentinel failover-timeout mymaster 60000
sentinel parallel-syncs mymaster 1
```

### 启动集群

```bash
# 启动主节点和从节点
redis-server --port 6379 --daemonize yes
redis-server --port 6380 --daemonize yes --replicaof 127.0.0.1 6379
redis-server --port 6381 --daemonize yes --replicaof 127.0.0.1 6379

# 启动 3 个哨兵
redis-sentinel sentinel1.conf  # port 26379
redis-sentinel sentinel2.conf  # port 26380
redis-sentinel sentinel3.conf  # port 26381

# 查看状态
redis-cli -p 6379 INFO replication
redis-cli -p 26379 SENTINEL masters
```

### 应用层连接哨兵

```python
from redis.sentinel import Sentinel

sentinel = Sentinel([
    ('127.0.0.1', 26379),
    ('127.0.0.1', 26380),
    ('127.0.0.1', 26381),
], socket_timeout=0.5)

# 写走 Master
master = sentinel.master_for('mymaster')
master.set("key", "value")

# 读走 Replica
replica = sentinel.replica_for('mymaster')
print(replica.get("key"))
```

### 故障转移验证

```bash
# 模拟 Master 宕机
redis-cli -p 6379 SHUTDOWN

# 查看哨兵日志 → 新 Master 选举
redis-cli -p 26379 SENTINEL get-master-addr-by-name mymaster
# 自动切换到 6380 或 6381

# 应用层无需修改代码，Sentinel 自动切换
```

---

## ✅ 验收标准

- [ ] 1 主 2 从复制正常
- [ ] 3 哨兵（quorum 2）存在时，Master 宕机后自动切换：以 `SHUTDOWN` 返回时刻为 T0，以 `SENTINEL get-master-addr-by-name` 返回新端口为 T1，T1−T0 < 30s
- [ ] 客户端自动连接到新 Master
- [ ] 旧 Master 恢复后自动成为 Replica

## 🎯 本文学完自检

| 层次 | 检查项 |
|------|--------|
| 🟢 基础 | 主 `INFO replication` 有 `connected_slaves:2`，两个从节点均 `role:slave`、`master_link_status:up`；主上 `SET key v` 后从 `GET key` 得 `v` |
| 🟡 进阶 | 杀主后按前述口径记 T0/T1：日志出现 `+sdown` → `+odown`（带 `#quorum` 计数）→ `+switch-master`，`sentinel.master_for('mymaster')` 写入仍成功且指向新主（`GET key` 不报错） |
| 🔴 挑战 | 旧主重启后默认变 `role:slave`（贴 `INFO replication`）；再演示 `min-replicas-to-write 1` + `min-replicas-max-lag 10`：停掉全部从库后主写入报 `NOREPLICAS Not enough good replicas to write`，说明它如何阻断脑裂期写入 |
