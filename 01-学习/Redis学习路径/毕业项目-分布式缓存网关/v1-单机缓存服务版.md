# v1-单机缓存服务版

> 📍 **前置**：[[../阶段一-数据结构与命令/01-Redis基础与字符串命令]]
> 📍 **路线**：v1（本版本） → [[v2-多数据结构组合版]]

## 🎯 本版本目标

用 Python + redis-py 实现基础缓存 API：GET/SET/DELETE，支持 TTL，实现：**缓存服务跑起来**。

---

## 💻 核心实现

```python
from flask import Flask, request, jsonify
import redis
import json

app = Flask(__name__)
r = redis.Redis(host='localhost', port=6379, decode_responses=True)

@app.route('/cache/<key>', methods=['GET'])
def get(key):
    value = r.get(key)
    return jsonify({"key": key, "value": value, "exists": value is not None})

@app.route('/cache/<key>', methods=['PUT'])
def put(key):
    data = request.get_json()
    value = json.dumps(data.get('value'))
    ttl = data.get('ttl', 300)
    r.setex(key, ttl, value)
    return jsonify({"status": "ok", "ttl": ttl})

@app.route('/cache/<key>', methods=['DELETE'])
def delete(key):
    r.delete(key)
    return jsonify({"status": "deleted"})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

```bash
pip install flask redis
python app.py

# 测试
curl -X PUT http://localhost:5000/cache/user:1 \
  -H "Content-Type: application/json" \
  -d '{"value":"alice"}'
curl http://localhost:5000/cache/user:1
curl -X DELETE http://localhost:5000/cache/user:1
```
