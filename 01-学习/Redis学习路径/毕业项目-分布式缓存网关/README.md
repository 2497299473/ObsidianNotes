# 毕业项目：分布式缓存网关

> 📍 **本毕业项目采用版本递进设计，每完成一个版本即是一个可用的里程碑。**
>
> 📚 **参考既有笔记**：[[00-Redis学习路径总索引]]

## 🎯 项目目标

实现一个支持多业务方接入的分布式缓存网关服务，涵盖数据结构应用、持久化、高可用、分片、事务与性能优化。

---

## 版本路线图

| 版本 | 主题 | 核心输出 |
|------|------|---------|
| v1 | [[v1-单机缓存服务版]] | Python + Redis，基础缓存 API |
| v2 | [[v2-多数据结构组合版]] | String/Hash/ZSet/Set 组合使用 |
| v3 | [[v3-持久化与AOF版]] | 启用 AOF 并验证数据恢复 |
| v4 | [[v4-主从高可用版]] | 主从 + 哨兵，故障自动转移 |
| v5 | [[v5-Cluster分片版]] | Redis Cluster 分片部署 |
| v6 | [[v6-Lua脚本与事务版]] | Lua 脚本实现原子缓存更新 |
| v7 | [[v7-监控与压测调优版]] | 监控 + 压测 + 性能调优 |
