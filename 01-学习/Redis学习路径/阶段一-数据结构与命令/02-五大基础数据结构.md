## 📖 核心内容

### 五大结构对比

| 结构 | 底层编码 | 特点 | 典型场景 |
|------|---------|------|---------|
| **String** | SDS | 二进制安全、原子计数 | 缓存、计数器、分布式锁 |
| **Hash** | ziplist / hashtable | 字段-值映射 | 对象存储、购物车 |
| **List** | quicklist（ziplist 链表） | 有序列表、可重复 | 消息队列、时间线 |
| **Set** | intset / hashtable | 无序、去重 | 标签、共同好友 |
| **ZSet** | ziplist / skiplist+hashtable | 有序、去重、按 score | 排行榜、延迟队列 |

### Hash 哈希表

适用：对象存储（用户信息、商品详情、购物车）。

```redis
HSET user:1 name "alice" age 30 city "beijing"
HGET user:1 name
HGETALL user:1
HINCRBY user:1 age 1        # 原子自增字段
HDEL user:1 city
HLEN user:1                 # 字段数
HEXISTS user:1 name
HKEYS user:1                # 所有字段名
HVALS user:1                # 所有值
```

**业务场景**：购物车
```redis
HSET cart:user:1 item:1001 2    # 商品1001数量2
HSET cart:user:1 item:1002 1
HINCRBY cart:user:1 item:1001 1 # 加1件
HDEL cart:user:1 item:1002      # 移除商品
HGETALL cart:user:1             # 查看购物车
```

### List 链表

适用：消息队列、时间线、最新动态。

```redis
LPUSH messages "hello"     # 左插入
RPUSH messages "world"     # 右插入
LRANGE messages 0 -1       # 查看全部
LPOP messages              # 左弹出
RPOP messages              # 右弹出
BLPOP messages 10          # 阻塞弹出（超时10秒）
LLEN messages              # 长度
LINDEX messages 0          # 按索引取
LTRIM messages 0 99        # 只保留前100条
```

**业务场景**：最新消息
```redis
LPUSH timeline:user:1 "post:100"
LTRIM timeline:user:1 0 999  # 只保留最新1000条
LRANGE timeline:user:1 0 9   # 最新10条
```

### Set 集合

适用：标签、好友关系、去重。

```redis
SADD tags:1 "python" "redis" "docker"
SADD tags:2 "python" "go" "k8s"
SMEMBERS tags:1            # 所有元素
SISMEMBER tags:1 "python"  # 是否存在
SCARD tags:1               # 元素数量
SREM tags:1 "docker"       # 移除
SINTER tags:1 tags:2       # 交集（共同标签）
SUNION tags:1 tags:2       # 并集
SDIFF tags:1 tags:2        # 差集
```

**业务场景**：共同好友
```redis
SADD friends:user:1 "alice" "bob" "charlie"
SADD friends:user:2 "bob" "charlie" "dave"
SINTER friends:user:1 friends:user:2  # 共同好友 → bob, charlie
```

### Sorted Set (ZSet)

适用：排行榜、延迟队列、优先级队列。

```redis
ZADD leaderboard 100 "alice" 200 "bob" 150 "charlie"
ZRANGE leaderboard 0 -1 WITHSCORES               # 升序
ZREVRANGE leaderboard 0 9 WITHSCORES             # 降序 Top10
ZRANGEBYSCORE leaderboard 100 200                 # 分数范围
ZINCRBY leaderboard 50 "alice"                   # 增加分数
ZRANK leaderboard "alice"                        # 排名（升序）
ZREVRANK leaderboard "alice"                     # 排名（降序）
ZSCORE leaderboard "alice"                        # 分数
ZREM leaderboard "alice"                          # 移除
```

**业务场景**：游戏排行榜
```redis
ZADD game:rank 1500 "player1" 1800 "player2"
ZINCRBY game:rank 100 "player1"   # 胜利+100分
ZREVRANGE game:rank 0 9 WITHSCORES  # Top10
```

### 底层编码切换

Redis 会根据元素数量和大小自动切换编码：

| 类型 | 小数据编码 | 大数据编码 | 切换阈值 |
|------|-----------|-----------|---------|
| Hash | ziplist | hashtable | `hash-max-ziplist-entries`（默认128） |
| List | ziplist | quicklist | `list-max-ziplist-size` |
| Set | intset | hashtable | `set-max-intset-entries`（默认512） |
| ZSet | ziplist | skiplist+hashtable | `zset-max-ziplist-entries`（默认128） |

```bash
redis-cli OBJECT ENCODING leaderboard  # 查看编码
```

### 扩展数据结构

| 结构 | 命令前缀 | 适用场景 |
|------|---------|---------|
| **Bitmap** | SETBIT/GETBIT/BITCOUNT | 签到、在线状态、布隆过滤器 |
| **HyperLogLog** | PFADD/PFCOUNT | UV 统计（误差0.81%，固定12KB） |
| **GEO** | GEOADD/GEOPOS/GEODIST | 位置服务、附近的人 |

```redis
# Bitmap：用户签到
SETBIT user:1:2024:01 15 1
GETBIT user:1:2024:01 15
BITCOUNT user:1:2024:01

# HyperLogLog：页面 UV
PFADD page:1:uv user:1 user:2 user:3
PFCOUNT page:1:uv

# GEO：附近门店
GEOADD stores 116.404 39.915 "store:1" 116.410 39.920 "store:2"
GEODIST stores store:1 store:2 km
```

## 💻 代码示例

```python
import redis
r = redis.Redis(host='localhost', port=6379, decode_responses=True)

# 购物车（Hash）
r.hset("cart:user:1", mapping={"item:1001": 2, "item:1002": 1})
r.hincrby("cart:user:1", "item:1001", 1)
print("购物车:", r.hgetall("cart:user:1"))

# 排行榜（ZSet）
r.zadd("leaderboard", {"alice": 100, "bob": 200, "charlie": 150})
print("Top10:", r.zrevrange("leaderboard", 0, 9, withscores=True))
r.zincrby("leaderboard", 50, "alice")
print("Alice 排名:", r.zrevrank("leaderboard", "alice"))

# 共同好友（Set）
r.sadd("friends:1", "alice", "bob", "charlie")
r.sadd("friends:2", "bob", "charlie", "dave")
print("共同好友:", r.sinter("friends:1", "friends:2"))

# 签到（Bitmap）
r.setbit("user:1:2024:01", 15, 1)
print("是否签到:", bool(r.getbit("user:1:2024:01", 15)))
print("签到天数:", r.bitcount("user:1:2024:01"))
```

## ⚠️ 常见陷阱

| 陷阱 | 后果 | 解决方案 |
|------|------|---------|
| 用 String 存 JSON 对象 | 不能局部更新 | 用 Hash 存字段 |
| List 无限增长 | 内存泄漏 | 用 `LTRIM` 限制长度 |
| ZSet 全量返回 | 网络阻塞 | 用 `LIMIT` 分页 |
| DEL 大 Key | 阻塞主线程 | 用 `UNLINK` 异步删除 |
| 生产用 `KEYS *` | 阻塞 | 改用 `SCAN` |
