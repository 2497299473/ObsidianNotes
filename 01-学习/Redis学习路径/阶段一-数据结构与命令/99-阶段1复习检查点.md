# 99-阶段1复习检查点

> 🎯 阶段验收口径：下表三行全部跑通（可查笔记、不查答案）即视为阶段一过关；卡在某一行就回对应篇目重做。

---

## 🎯 本文学完自检

| 层次 | 检查项 |
|------|--------|
| 🟢 基础 | `docker run -d -p 6379:6379 redis:7.2` 后 `redis-cli ping` → `PONG`；`MSET k1 1 k2 2` + `MGET k1 k2` 取回两值；`SETEX s 2 v` 等 3 秒后 `TTL s` → `-2` 且 `GET s` → `(nil)`；对 String/Hash/List/Set/ZSet 各写一条写入+读回命令，并用 `TYPE` 校验类型 |
| 🟡 进阶 | 同一个购物车分别用 Hash（`HSET`/`HINCRBY`）与 String 存 JSON 各实现一次，说明为何 Hash 能只改一个字段；用 `Pipeline` 把 100 次 `SET` 合成一次 RTT，并给出“逐条 vs Pipeline”的实测耗时对比；`SETBIT` 记 30 天签到后 `BITCOUNT` 数与其一致 |
| 🔴 挑战 | 给定“10 万条订单事件、允许重投、需重试与积压可见”：在 List / Pub/Sub / Stream 中选一个方案，写 5 行论证（含 `XACK`/`XPENDING` 或 `BRPOP` 的具体位置），并指出另两个方案各自在哪个故障点丢消息 |
