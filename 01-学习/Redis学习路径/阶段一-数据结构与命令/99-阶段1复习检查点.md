# 99-阶段1复习检查点

## 🟢 基础（必须掌握）

- [ ] 能独立安装 Redis 并用 redis-cli 连接
- [ ] 能使用 String、Hash、List、Set、Sorted Set 的基础命令
- [ ] 能解释 Redis 单线程 IO 多路复用模型
- [ ] 能使用 `KEYS`、`EXISTS`、`EXPIRE`、`TTL` 管理键空间

## 🟡 进阶（综合运用）

- [ ] 能根据业务场景选择合适的数据结构（如排行榜用 ZSET、购物车用 Hash）
- [ ] 能使用 Pipeline 批量执行命令降低 RTT
- [ ] 能使用 Bitmap/HyperLogLog/GEO 解决特定计数或位置问题
- [ ] 能设计并实现 Pub/Sub 或 Stream 消息模型

## 🔴 挑战（独立判断）

- [ ] 能对比 Redis 与 Memcached 在数据结构、持久化、集群上的差异
- [ ] 能针对高并发计数场景设计原子性方案
- [ ] 能分析大 Key 对 Redis 性能的影响并给出治理方案
