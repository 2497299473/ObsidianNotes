# TypeScript 学习路径

> 📌 本学习路径基于 [[03-AI工具/AI协作方法论/技术学习路径审查与优化方法论]] 的多 Agent 审查方法论构建，采用三阶段递进、毕业项目版本递进、每篇自检清单、双向交叉引用设计。

## 快速开始

1. 安装 Node.js ≥ 18 和 TypeScript ≥ 5.5
2. 打开 [[00-TypeScript学习路径总索引]] 查看完整路径和角色导航
3. 按角色选择路线（🆕 新手 / 🔄 转行者 / 🚀 专家）
4. 按阶段顺序学习，完成每篇的 🎯 自检清单（🟢/🟡/🔴）
5. 每个阶段末尾完成复习检查点
6. 从 v1 到 v7 完成毕业项目

## 学习路径概览

| 阶段 | 笔记数 | 预计学时 | 难度 | 核心目标 |
|------|--------|---------|------|---------|
| 阶段一 | 3 + 1 复习 | 8-10h | ⭐⭐ | 掌握类型标注基本功 |
| 阶段二 | 4 + 1 复习 | 12-15h | ⭐⭐⭐⭐ | 深入类型体操 |
| 阶段三 | 4 + 1 复习 | 14-18h | ⭐⭐⭐ | 工程化落地 |
| 毕业项目 | 7 版本 | 10-15h | ⭐⭐⭐⭐ | 从零搭建完整 TS 项目 |

**总学时**：约 45-55h（新手）/ 30-35h（转行者）/ 20-25h（专家）
