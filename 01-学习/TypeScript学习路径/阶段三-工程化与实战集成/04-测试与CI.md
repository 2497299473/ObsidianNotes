## 1. 测试框架

### 1.1 Vitest（推荐）

```bash
npm install -D vitest @vitest/coverage-v8
```

```typescript
// src/math.ts
export function add(a: number, b: number): number {
  return a + b;
}

export function divide(a: number, b: number): number {
  if (b === 0) throw new Error("Division by zero");
  return a / b;
}

// src/math.test.ts
import { describe, it, expect } from "vitest";
import { add, divide } from "./math";

describe("math", () => {
  it("adds two numbers", () => {
    expect(add(1, 2)).toBe(3);
  });

  it("throws on division by zero", () => {
    expect(() => divide(1, 0)).toThrow("Division by zero");
  });
});
```

### 1.2 配置

```typescript
// vitest.config.ts
import { defineConfig } from "vitest/config";

export default defineConfig({
  test: {
    include: ["src/**/*.test.ts"],
    coverage: {
      provider: "v8",
      reporter: ["text", "json", "html"],
    },
  },
});
```

### 1.3 类型安全测试

```typescript
import { expectTypeOf } from "vitest";

it("returns correct type", () => {
  const result = add(1, 2);
  expectTypeOf(result).toBeNumber();
});

// 测试泛型
it("generic type is correct", () => {
  expectTypeOf<ReturnType<typeof add>>().toBeNumber();
});
```

## 5. CI/CD 配置

### 5.1 GitHub Actions

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest

    strategy:
      matrix:
        node-version: [18, 20, 22]

    steps:
      - uses: actions/checkout@v4

      - name: Use Node.js ${{ matrix.node-version }}
        uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: "npm"

      - name: Install dependencies
        run: npm ci

      - name: Type check
        run: npx tsc --noEmit

      - name: Lint
        run: npx eslint src/

      - name: Test
        run: npx vitest run --coverage

      - name: Build
        run: npm run build
```

### 5.2 关键检查顺序

```
1. npm ci        → 安装依赖
2. tsc --noEmit  → 类型检查（最先失败，快速反馈）
3. eslint        → 代码规范
4. vitest run    → 单元测试 + 覆盖率
5. npm run build → 构建验证
```

## 7. 练习

### 练习 1：为工具函数编写测试

1. 编写 3 个函数（含类型标注）
2. 用 Vitest 编写至少 5 个测试用例
3. 包含边界情况和异常测试
4. 用 `expectTypeOf` 验证返回类型

### 练习 2：配置 ESLint + Prettier

1. 安装并配置 ESLint、Prettier、eslint-config-prettier
2. 添加 `@typescript-eslint/no-explicit-any: error` 规则
3. 验证 `eslint --fix` 和 `prettier --write` 能正常工作

### 练习 3：搭建 CI 流水线

1. 编写 GitHub Actions 工作流文件
2. 包含类型检查、lint、测试、构建四个步骤
3. 在多个 Node.js 版本上运行
