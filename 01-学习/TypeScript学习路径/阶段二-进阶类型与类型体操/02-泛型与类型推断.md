## 1. 泛型函数

### 1.1 基本语法

```typescript
// 泛型类型参数 <T>
function identity<T>(value: T): T {
  return value;
}

const s = identity("hello"); // T 推断为 string → s: string
const n = identity(42);      // T 推断为 number → n: number
```

### 1.2 多类型参数

```typescript
function pair<A, B>(first: A, second: B): [A, B] {
  return [first, second];
}

const p = pair("hello", 42); // [string, number]
```

### 1.3 显式指定类型参数

```typescript
// 当 TS 无法正确推断时，可以显式指定
const result = identity<string>("hello"); // 显式指定 T = string

// 但大多数时候让 TS 推断即可
const result2 = identity("hello"); // 推断 T = string
```

## 2. 泛型约束（Constraints）

### 2.1 用 extends 约束

```typescript
// 要求 T 必须有 length 属性
function logLength<T extends { length: number }>(arg: T): number {
  return arg.length;
}

logLength("hello");    // ✅ string 有 length
logLength([1, 2, 3]); // ✅ array 有 length
// logLength(42);     // ❌ number 没有 length
```

### 2.2 用 keyof 约束

```typescript
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { name: "Alice", age: 30 };
getProperty(user, "name"); // ✅ 返回 string
getProperty(user, "age");  // ✅ 返回 number
// getProperty(user, "email"); // ❌ "email" 不是 user 的键
```

### 2.3 泛型类

```typescript
class Stack<T> {
  private items: T[] = [];

  push(item: T): void {
    this.items.push(item);
  }

  pop(): T | undefined {
    return this.items.pop();
  }

  peek(): T | undefined {
    return this.items[this.items.length - 1];
  }
}

const numberStack = new Stack<number>();
numberStack.push(1);
// numberStack.push("a"); // ❌
```

## 3. 泛型接口与默认类型

### 3.1 泛型接口

```typescript
interface Repository<T> {
  findById(id: string): Promise<T | null>;
  save(entity: T): Promise<T>;
  delete(id: string): Promise<void>;
}
```

### 3.2 默认类型参数

```typescript
interface ApiResponse<T = unknown> {
  code: number;
  message: string;
  data: T;
}

// 不传 T 时 data 为 unknown
const res: ApiResponse = { code: 200, message: "ok", data: "anything" };
```

## 4. 常用工具类型（泛型实现）

```typescript
// Partial —— 所有属性变可选
type Partial<T> = { [K in keyof T]?: T[K] };

// Required —— 所有属性变必选（`-?` 移除可选修饰符）
type Required<T> = { [K in keyof T]-?: T[K] };

// Readonly —— 所有属性变只读
type Readonly<T> = { readonly [K in keyof T]: T[K] };

// Pick —— 选取部分属性
type Pick<T, K extends keyof T> = { [P in K]: T[P] };

// Record —— 构造键值对类型
type Record<K extends keyof any, T> = { [P in K]: T };
```

## 5. 类型推断进阶

### 5.1 上下文类型

```typescript
// 回调函数参数类型由调用方上下文推断
window.addEventListener("click", (event) => {
  // event 被推断为 MouseEvent —— 由 addEventListener 的签名决定
  console.log(event.clientX);
});
```

### 5.2 数组字面量推断

```typescript
const nums = [1, 2, 3]; // 推断为 number[]
const mixed = [1, "a"]; // 推断为 (string | number)[]

// const 断言 → readonly tuple
const tuple = [1, "a"] as const; // readonly [1, "a"]
```

### 5.3 函数返回值推断

```typescript
// 联合返回值
function parse(value: string): number | null {
  const n = parseInt(value);
  return isNaN(n) ? null : n;
}
// 返回类型推断为 number | null
```

## 6. infer 关键字（预告）

`infer` 用于在条件类型中提取类型变量，详见 [[03-条件类型与映射类型]]：

```typescript
// ReturnType 的实现原理
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

// Parameters 的实现原理
type MyParameters<T> = T extends (...args: infer P) => any ? P : never;
```
