## 1. 条件类型（Conditional Types）

### 1.1 基本语法

```typescript
// T extends U ? X : Y
type IsString<T> = T extends string ? true : false;

type A = IsString<string>;  // true
type B = IsString<number>;  // false
```

### 1.2 分布式条件类型

当 `T` 是裸类型参数且传入联合类型时，条件类型会**分布**到联合的每个成员：

```typescript
type ToArray<T> = T extends unknown ? T[] : never;

// 分布行为
type R = ToArray<string | number>;
// 等价于：ToArray<string> | ToArray<number>
// 结果：string[] | number[]
```

### 1.3 阻止分布

用方括号包裹可以阻止分布：

```typescript
type ToArrayNonDist<T> = [T] extends [unknown] ? T[] : never;

type R = ToArrayNonDist<string | number>;
// 结果：(string | number)[] —— 不分布
```

## 2. infer 关键字

### 2.1 提取返回类型

```typescript
type GetReturn<T> = T extends (...args: any[]) => infer R ? R : never;

type R1 = GetReturn<() => string>;        // string
type R2 = GetReturn<() => number>;         // number
type R3 = GetReturn<(x: number) => boolean>; // boolean
```

### 2.2 提取数组元素类型

```typescript
type Unpack<T> = T extends (infer U)[] ? U : never;

type E = Unpack<string[]>;      // string
type E2 = Unpack<number[]>;     // number
```

### 2.3 提取 Promise 值类型

```typescript
type Awaited<T> = T extends Promise<infer U> ? U : T;

type V = Awaited<Promise<string>>; // string
```

### 2.4 多个 infer

```typescript
type FirstArg<T> = T extends (first: infer F, ...rest: any[]) => any ? F : never;

type F1 = FirstArg<(name: string, age: number) => void>; // string
```

## 3. 映射类型（Mapped Types）

### 3.1 基本语法

```typescript
// 将 T 的所有属性变为只读
type MyReadonly<T> = {
  readonly [K in keyof T]: T[K];
};

// 将所有属性变为可选
type MyPartial<T> = {
  [K in keyof T]?: T[K];
};
```

### 3.2 修改修饰符（+/-）

```typescript
// 移除 readonly 修饰符
type Mutable<T> = {
  -readonly [K in keyof T]: T[K];
};

// 移除可选修饰符
type Concrete<T> = {
  [K in keyof T]-?: T[K];
};
```

### 3.3 过滤键（Key Remapping via as）

```typescript
// 只保留字符串类型的属性
type StringValues<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K];
};

interface User {
  name: string;
  age: number;
  email: string;
}

type R = StringValues<User>; // { name: string; email: string }
```

### 3.4 键名重映射

```typescript
// 把所有属性名加前缀 "get"
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type UserGetters = Getters<{ name: string; age: number }>;
// { getName: () => string; getAge: () => number }
```

## 4. 模板字面量类型

### 4.1 基本用法

```typescript
type Greeting = `hello ${string}`;
const g: Greeting = "hello world"; // ✅
// const g2: Greeting = "hi world"; // ❌
```

### 4.2 配合联合类型

```typescript
type Vertical = "top" | "bottom";
type Horizontal = "left" | "right";
type Position = `${Vertical}-${Horizontal}`;
// "top-left" | "top-right" | "bottom-left" | "bottom-right"
```

### 4.3 内置工具类型

```typescript
type Upper = Uppercase<"hello">;      // "HELLO"
type Lower = Lowercase<"HELLO">;      // "hello"
type Cap = Capitalize<"hello">;       // "Hello"
type Uncap = Uncapitalize<"Hello">;   // "hello"
```

## 5. 实战工具类型

### 5.1 DeepPartial（递归）

```typescript
type DeepPartial<T> = {
  [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K];
};
```

### 5.2 Omit + Pick = Omit

```typescript
type MyOmit<T, K extends keyof T> = Pick<T, Exclude<keyof T, K>>;
```

### 5.3 可选属性键提取

```typescript
type OptionalKeys<T> = {
  [K in keyof T]-?: {} extends Pick<T, K> ? K : never;
}[keyof T];
```

```typescript
// Get<T, "a.b.c"> 能获取嵌套对象的属性类型
type Get<T, P extends string> = ?;

type Obj = { a: { b: { c: string } } };
type Result = Get<Obj, "a.b.c">; // 应为 string
// 提示：用 infer + 递归
```
