## 学习者自测 Checklist 草案

### 阶段一结束时应能

- [ ] 用 `tsc --strict` 编译通过任意 JS 到 TS 的迁移
- [ ] 解释 `interface` 和 `type` 的 4 个核心区别
- [ ] 用函数重载精确描述一个多态函数
- [ ] 解释 `any`/`unknown`/`never`/`void` 的区别

### 阶段二结束时应能

- [ ] 手写 `Exclude`、`Extract`、`NonNullable`
- [ ] 用可辨识联合 + 穷尽检查实现状态机
- [ ] 解释分布式条件类型和 `infer` 的用法
- [ ] 手写 `DeepPartial`/`DeepReadonly`
- [ ] 区分 `as` 和 `satisfies`

### 阶段三结束时应能

- [ ] 独立配置完整 tsconfig（含 strict 7 项）
- [ ] 用 ESM 组织多模块项目
- [ ] 为 JS 库编写 `.d.ts` 声明文件
- [ ] 搭建 Vitest + ESLint + CI 流水线

### 毕业项目结束时应能

- [ ] 从 v1 到 v7 独立完成全部版本
- [ ] 用 `npm pack` 验证包内容
- [ ] 向他人解释每个版本的设计决策
