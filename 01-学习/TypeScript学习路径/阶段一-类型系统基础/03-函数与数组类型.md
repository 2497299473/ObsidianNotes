## 1. 函数类型

### 1.1 函数声明与类型标注

```typescript
// 函数声明 —— 参数和返回值都标注
function add(a: number, b: number): number {
  return a + b;
}

// 函数表达式
const multiply = function (a: number, b: number): number {
  return a * b;
};

// 箭头函数
const square = (n: number): number => n * n;
```

### 1.2 用 type/interface 定义函数类型

```typescript
// 用 type
type MathOperation = (a: number, b: number) => number;

// 用 interface
interface StringChecker {
  (input: string): boolean;
}

const isLong: StringChecker = (s) => s.length > 10;
```

### 1.3 可选参数与默认值

```typescript
// 可选参数用 ? 标记，必须放在必选参数后面
function greet(name: string, greeting?: string): string {
  return `${greeting ?? "Hello"}, ${name}!`;
}

// 默认值参数
function createUrl(host: string, port = 80): string {
  return `http://${host}:${port}`;
}
```

### 1.4 剩余参数（rest parameters）

```typescript
function sum(...nums: number[]): number {
  return nums.reduce((a, b) => a + b, 0);
}

// 元组类型的 rest 参数
function pairs(...pairs: [string, number][]): void {
  pairs.forEach(([k, v]) => console.log(k, v));
}
```

## 2. 函数重载（Overloads）

TypeScript 的函数重载与 Java/C# 不同：**需要先写多个签名，最后一个是实现签名（不对 外暴露）**。

```typescript
// 重载签名（对外暴露的类型）
function format(value: number): string;
function format(value: Date): string;

// 实现签名（不对外暴露，必须兼容所有重载）
function format(value: number | Date): string {
  if (typeof value === "number") {
    return value.toFixed(2);
  }
  return value.toISOString();
}

// 使用时 TS 会根据入参类型匹配重载签名
format(42);      // ✅ 匹配第一个重载
format(new Date()); // ✅ 匹配第二个重载
// format("hello"); // ❌ 没有匹配的重载
```

### 重载的常见陷阱

```typescript
// ❌ 坏例子：实现签名暴露了 string，但重载签名没有
function parse(x: number): number;
function parse(x: string): number;
function parse(x: number | string): number {
  return Number(x);
}
// TS 不会暴露 string 之外的重载——调用者看不到

// ✅ 好例子：用联合类型或显式重载覆盖所有入参类型
function parse(x: number | string): number;
```

## 3. this 类型

```typescript
interface Button {
  text: string;
  onClick(this: Button, event: MouseEvent): void;
}

const btn: Button = {
  text: "Click me",
  onClick(event) {
    console.log(this.text); // this 被推断为 Button
  },
};
```

## 4. 数组类型进阶

### 4.1 只读数组

```typescript
// ReadonlyArray 不可修改
const arr: ReadonlyArray<number> = [1, 2, 3];
// arr.push(4); // ❌ 不可修改

// readonly 修饰符
const readonlyArr: readonly number[] = [1, 2, 3];

// 用 const 断言创建只读元组
const tuple = [1, "hello"] as const; // readonly [1, "hello"]
```

### 4.2 多维数组

```typescript
type Matrix = number[][];
const grid: Matrix = [
  [1, 2, 3],
  [4, 5, 6],
];
```

### 4.3 数组操作与类型收窄

```typescript
const mixed: (string | number)[] = [1, "a", 2, "b"];

// filter 不会自动收窄
const strings = mixed.filter((x): x is string => typeof x === "string");
// strings: string[]
```
