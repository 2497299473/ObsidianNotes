## 毕业项目 v1：环境搭建与基础查询迁移

**改造维度**：环境搭建 + 基础 CRUD
**MySQL 锚点**：mysql 命令行 → psql + 基础 SQL
**验收标准**：全表 CRUD 在 PG 跑通

### 目标

用 Docker 启动 PostgreSQL，创建数据库和表，完成基础 CRUD 操作，体验 psql 与 mysql 命令行的差异。

### 任务清单

- [ ] 用 Docker 启动 PostgreSQL 16
- [ ] 用 psql 连接并查看版本、数据库列表、角色列表
- [ ] 创建数据库 `graduation_db`
- [ ] 创建表 `users` 和 `orders`
- [ ] 插入测试数据
- [ ] 完成 SELECT/WHERE/ORDER BY/LIMIT 查询
- [ ] 完成 INSERT/UPDATE/DELETE 操作
- [ ] 使用 RETURNING 子句

### 完整代码

```sql
-- ============================================
-- Step 1：启动 PostgreSQL（在宿主机执行）
-- ============================================
-- docker run --name pg-project -e POSTGRES_PASSWORD=123456 -p 5432:5432 -d postgres:16
-- docker exec -it pg-project psql -U postgres

-- ============================================
-- Step 2：创建数据库并连接
-- ============================================
CREATE DATABASE graduation_db;
\c graduation_db  -- 切换到 graduation_db

-- ============================================
-- Step 3：创建表（MySQL 迁移版）
-- ============================================
-- 原 MySQL：
-- CREATE TABLE users (
--     id INT AUTO_INCREMENT PRIMARY KEY,
--     name VARCHAR(50) NOT NULL,
--     email VARCHAR(100) UNIQUE,
--     is_active TINYINT(1) DEFAULT 1,
--     created_at DATETIME DEFAULT CURRENT_TIMESTAMP
-- );

-- PostgreSQL 版本：
CREATE TABLE users (
    id SERIAL PRIMARY KEY,          -- AUTO_INCREMENT → SERIAL
    name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    is_active BOOLEAN DEFAULT TRUE, -- TINYINT(1) → BOOLEAN
    created_at TIMESTAMPTZ DEFAULT NOW()  -- DATETIME → TIMESTAMPTZ
);

CREATE TABLE orders (
    id SERIAL PRIMARY KEY,
    user_id INT NOT NULL REFERENCES users(id),
    amount NUMERIC(10, 2) NOT NULL,
    status VARCHAR(20) DEFAULT 'pending',
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================
-- Step 4：插入测试数据
-- ============================================
INSERT INTO users (name, email) VALUES
    ('Alice', 'alice@test.com'),
    ('Bob', 'bob@test.com'),
    ('Charlie', 'charlie@test.com');

-- 插入并返回生成的 ID（替代 LAST_INSERT_ID()）
INSERT INTO users (name, email)
VALUES ('David', 'david@test.com')
RETURNING id, name, created_at;

INSERT INTO orders (user_id, amount) VALUES
    (1, 99.99), (1, 49.50), (2, 150.00), (3, 200.00);

-- ============================================
-- Step 5：基础查询
-- ============================================
-- 条件查询（注意：is_active 是 BOOLEAN，不是 TINYINT）
-- MySQL: WHERE is_active = 1
-- PG: WHERE is_active = TRUE 或 WHERE is_active
SELECT * FROM users WHERE is_active;

-- 排序 + 分页（MySQL: LIMIT 0, 2 → PG: LIMIT 2 OFFSET 0）
SELECT * FROM orders ORDER BY amount DESC LIMIT 2 OFFSET 0;

-- JOIN 查询
SELECT u.name, o.amount, o.status
FROM users u JOIN orders o ON u.id = o.user_id
ORDER BY o.amount DESC;

-- 聚合查询
SELECT user_id, COUNT(*) AS order_count, SUM(amount) AS total
FROM orders GROUP BY user_id;

-- ============================================
-- Step 6：UPDATE 和 DELETE（带 RETURNING）
-- ============================================
UPDATE users SET name = 'Alice Smith' WHERE id = 1
RETURNING id, name;

UPDATE orders SET status = 'paid' WHERE id = 1
RETURNING id, status;

DELETE FROM orders WHERE id = 4
RETURNING id, amount;

-- ============================================
-- Step 7：验证
-- ============================================
\d users   -- 查看表结构
\dt        -- 查看所有表
\di        -- 查看索引
```

### 验收标准

- [ ] 能在 Docker 中启动 PostgreSQL 并连接
- [ ] 能创建 database、表、插入数据
- [ ] 能完成 SELECT/JOIN/WHERE/ORDER BY/LIMIT 查询
- [ ] 能使用 RETURNING 子句替代 LAST_INSERT_ID()
- [ ] 能区分 PG 的 BOOLEAN 类型与 MySQL 的 TINYINT(1)
