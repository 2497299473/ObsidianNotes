# React 学习路径

> 📌 本学习路径基于 [[03-AI工具/AI协作方法论/技术学习路径审查与优化方法论]] 的多 Agent 审查方法论构建，采用三阶段递进、毕业项目版本递进、每篇自检清单、双向交叉引用设计。

## 快速开始

1. 准备环境：Node.js 24 LTS（Node 18 已 EOL，勿照旧教程装 18）、Vite、VS Code
2. 打开 [[00-React学习路径总索引]] 查看完整路径和角色导航
3. 按角色选择路线（🆕 新手 / 🔄 转行者 / 🚀 专家）
4. 按阶段顺序学习，完成每篇的 🎯 自检清单（🟢/🟡/🔴）
5. 每个阶段末尾完成复习检查点
6. 从 v1 到 v7 完成毕业项目

## 方法论对应

| 方法论要素 | 对应实现 |
