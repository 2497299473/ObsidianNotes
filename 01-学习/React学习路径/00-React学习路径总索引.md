> [!warning] 内容状态（2026-08-23 总审阅）
> 本路径的**结构骨架与现有代码示例已就绪**（代码经逐个核查全部正确可运行），但各篇正文"核心概念"多为目录式罗列、"常见陷阱"为通用套话、毕业项目 v1-v7 尚无代码骨架，整体处于**待充实**状态。学习时请配合 React 官方文档；正文密度可参照 [[../Redis学习路径/00-Redis学习路径总索引|Redis 学习路径]] 作为目标形态。

> [!info] 版本基线
> React 18（createRoot、自动批处理、并发特性）；React Router 6（Routes/element/useParams）；Next.js 13+（阶段三/04 同时涉及 App Router 与 Pages Router，注意两者 API 不可混用）；测试用 React Testing Library。
>
> 🔄 **2026-09 版本口径（C 层冻结，开学前先读本条）**：当前生态为 **React 19.2 / React Router 8**（2026-06 发布，自 v7 起**非破坏性**升级、ESM-only，要求 React 19.2+/Node 22+）**/ Next.js 16 / Node 24 LTS**（Node 18 已 EOL）。本路径 React 18 + Router 6 + Next 13 的核心心智（组件/状态/Hooks/路由/数据流）在 19.x 下基本不变，**照学有效**；开学前花半小时浏览 React 19 与 Router 8 的变更日志即可。
