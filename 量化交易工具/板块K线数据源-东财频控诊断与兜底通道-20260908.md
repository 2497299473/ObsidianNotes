# 板块K线数据源 — 东财频控诊断与兜底通道（2026-09-08）

> 起因：09-05、09-08 两次 16:00 板块 K 线批量拉取被东财掐断（64/65 fail），
> 本轮做单码 BK0428 五通道诊断，评估 huashu-chrome 能否绕过，并落地晚间补拉机制。

## 一、诊断结论：IP/接口级掐断，本地无解（同 IP 换浏览器无用）

单码 BK0428，16:55 实测（脚本 `experiments\channel_diag\diag_20260908.py`）：

| # | 通道 | 结果 | 说明 |
|:-:|:---|:---|:---|
| A | 原生 urllib（http 明文，生产同姿势） | `RemoteDisconnected` | 生产主通道 |
| B | 顶层导航 goto 接口 URL | `net::ERR_EMPTY_RESPONSE` | **无 CORS 可言**，排除"pw 脚本跨域 bug"假设 |
| C | 页面内 fetch（复现 pw 脚本） | `TypeError: Failed to fetch` | 与 16:00 批量失败同报错 |
| D | JSONP `<script>` 注入 | onerror（网络层） | 无 CORS 可言 |
| E | Playwright request 上下文 | `socket hang up` | 独立连接栈同样被掐 |

**决定性证据（嗅探脚本）**：让无头 Chromium 打开东财板块页，抓页面**自己**发出的
K 线请求——`push2his.kline/get` 用站点自己的 `cb` JSONP + `ut` token 也
`ERR_EMPTY_RESPONSE`，页面 DOM 里日期数为 0（**K 线图本身就是空白的**）。

判定：
- CORS 假设 ❌（B/D 无 CORS 场景同败）
- 指纹/登录态假设 ❌（页面原生请求都失败，身份无可挑剔）
- **同 IP 连接层掐断 ✅**（quote.eastmoney.com 同域 200 正常，只有 push2/push2his 的
  kline/get 死 → 按接口粒度频控，非全域封禁）

推论：**huashu-chrome（真 Chrome + 登录态）对 push2his 无效**——同 IP，且页面本身
已无数据可显示，驱动真实浏览器读到的也是空图。它适用场景是"需要登录态的页面操作"
（CRM 录入、12306 查询），不是"被 IP 掐的数据接口"。
（附带：huashu-chrome 要求 Node ≥20，本机 `D:\Node\node.exe` v18.16.0，桥起后 CLI
崩于 `WebSocket is not defined`，未继续安装。）

## 二、IPv6 换出口：复测仍死

`netutil.py` v5 头注释早已记录（09-04 夜实测）：东财 v6 端点"握手成功但 0 字节断"。
09-08 17:31 复测（`probe_ipv6.py`，单码 6 请求内）：唯一 v6 地址
`2406:d440:201:305:6cd7:85e6:efcd:3553` → `RemoteDisconnected`。**与 v5 结论一致，
IPv6 路径归档为死路**（教训：提方案前先翻 netutil 头注释的历史实测）。

## 三、第二数据源验证：板块级日 K 暂无可用外部源

| 源 | 接口 | 结果 |
|:---|:---|:---|
| 腾讯 web.ifzq.gtimg.cn | `CN_MarketDataService.getKLineData` / `appstock/app/fqkline/get`，symbol=bk0428/pt0428/90.BK0428 | `param error`（**指数 sh000001 正常**，接口通，不认东财板块码体系） |
| 新浪 quotes.sina.cn | `CN_MarketDataService.getKLineData`，symbol=new_dlhy 等板块码 | 返回 `null`（指数正常；板块码不被 K 线接口接受） |
| 新浪板块目录 | `vip.stock...newSinaHy.php` | 200，49 个行业板块（name 可解析，GBK 编码） |
| 东财同域 newapi | `quote.eastmoney.com/newapi/bk/cyzh/jj/...` | 200 但只有实时快照类数据，**无历史 K 线** |
| 名称映射 | 新浪 49 行业 ↔ 东财 65 板块 | 仅 3 对（房地产/交通运输/有色金属），且新浪无概念板块 |

**结论：板块日 K 仍是东财单点依赖。** 指数/个股级外部源（腾讯/新浪）今天全通，
可作为个股面兜底（基金净值已有新浪冗余 `pull_sina_nav.py`），但板块级缺口需等
频控解除后整段重拉（缓存整段重拉，缺口不永久丢失——这是现有设计的安全底线）。
