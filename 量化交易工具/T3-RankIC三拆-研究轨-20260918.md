# T+3 RankIC 三拆（2026-09-18 · 研究轨 C1）

> 背景：V4.2 封版遗留三件事之一「RankIC 三拆」。现有 T+3 证据（WF +0.036 CI[-0.023,+0.092]）是
> pooled 口径，混淆了横截面尺度（轮动排序）与时序尺度（单基金方向）。本文 = 研究轨（C1，零网络）；
> 生产轨（C2，重跑 WF/rolling）需东财授权，另记。

## 一、预注册

- 判据文：`output/forecast_lab_prereg_T3decomp_20260918.md`（跑前写死，提交号 `8243927`；
  跑后仅补一条池子成员数事实更正——v2 面板扩档后 kind 派生主池 = 23 员而非 14，规则未动）。
- 三拆定义：pooled=全体一次（日块 bootstrap CI）；CS=日宽≥4 逐日 IC 的日均值（日重抽样 CI）；
  TS=成员内 n≥60 逐员 IC 的均值（成员重抽样 CI，成员是 TS 的相关单位）。
- 判据：A1 CS CI 下界>0；A2 TS 均值>0 且正值占比≥2/3；A3 pooled 显著而 A1/A2 均否 → 登记「pooled 膨胀」。
- 升格规则：A1∧A2 才升「证据积累」；仅其一 → 注脚只许写成立的那一尺度。

## 二、结果（pool14 主池 = kind 派生 23 员，oos_start=2025-04-30，4 折）

| 端点 | pooled（日块CI） | CS 日均（CI） | TS 成员均（pos占比） |
|---|---|---|---|
| T+1 | +0.0135 [-0.023,+0.050] | +0.0193 [-0.014,+0.051] | +0.0043（0.565） |
| **T+3 主判据** | **+0.0299 [-0.006,+0.065]** | **+0.0090 [-0.024,+0.037]** | **+0.0218（0.652 < 2/3 门槛）** |
| T+5 对照 | +0.0456 [+0.011,+0.082] | +0.0158 [-0.016,+0.048] | +0.0313（0.652） |

- 判定：**T+3 三尺度均不显著 → 不升格，「仅点估计」维持**。A3 也不触发（pooled 自己就不显著）。
- pool17 敏感性（26 员）同向更弱：T+3 pooled +0.0189 / CS +0.0118 / TS +0.0122（pos 0.577）。
- 有意思的对照：**T+5 pooled 显著但 CS、TS 均不显著**——pooled 的信号主要来自尺度混合
  （不同成员水平差 + 日期结构），不是任何一个可操作的单尺度。这正是三拆要防的坑。
- 可复现：pool14×T+3 双跑全主统计 ≤1e-9 一致；sha256 `c67dc6b9…` 校验通过；socket 守卫全程零网络。
