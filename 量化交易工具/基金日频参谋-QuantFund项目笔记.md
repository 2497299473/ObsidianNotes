## 一、这个工具是什么

一个本地运行的轻量基金参考工具：每天 **早盘 / 午盘 / 收盘后** 三个时点自动生成一份 Markdown 报告，
用 6 维技术信号综合评分，给出每只基金「加仓 / 减仓 / 持有观望」的建议。

**数据源**：腾讯行情（主源）→ akshare 东财（降级1）→ yfinance（兜底），三级降级，全部免费，无需 API Key。

**不做什么**：不实时交易、不荐股、不替代人工判断——就是一份每日参考。

## 四、信号评分体系（6 维）

| 维度 | 逻辑 | 防追高设计 |
|:---|:---|:---|
| 均线 | 价格站上几条 MA(5/10/20/60) + 多头/空头排列 | — |
| 动量 | 5/20/60 日收益率分段打分 | — |
| RSI(14) | 超卖(+10) / 中性(+5) / 超买(**-20** 重罚) | ✅ 超买不追 |
| 量能 | 放量方向（涨放量加分 / 跌放量扣分） | ✅ |
| 回撤 | 距 60 日高点回撤越深越加分（左侧布局） | ✅ 贴近高点扣分 |
| 分位 | 近 60 日价格分位，>80% 扣分 | ✅ 高位谨慎 |

**综合评分 → 操作建议**：
- 总分 ≥ 30 → 🟢 加仓
- 总分 ≤ -10 → 🔴 减仓
- -10 < 总分 < 30 → 🟡 持有/观望

阈值可在 `config.json` 的 `signal_thresholds` 里调。

## 五、如何使用

### 手动跑一次

```bash
cd D:\QuantFund
python main.py --slot close       # 收盘复盘（默认）
python main.py --slot morning     # 早盘参考
python main.py --slot noon        # 午盘参考
python main.py --slot close --force   # 强制刷新数据（跳过缓存）
```

跑完看报告：`D:\QuantFund\reports\latest_close.md`

### 常驻定时模式（工作日三时点自动跑）

```bash
python main.py --daemon
```

内置调度：工作日 08:45 早盘 / 11:35 午盘 / 15:35 收盘。

## 七、调试过程中踩过的坑

1. **akshare 东财源 SSL 中断**：连续请求 3 只以上后 `push2his.eastmoney.com` 连接中断。
   → 解决：改为腾讯源作主源（`web.ifzq.gtimg.cn`），稳定不限流。
2. **yfinance 限流**：`Too Many Requests`。
   → 解决：降为兜底源，且加了 1 秒请求间隔。
3. **RSI 显示与评分不一致**：原始值 69.9 在显示中取整为 70（超买标签），但评分按 <70 未触发超买惩罚。
   → 解决：统一在 `signals.py` 里 `rsi = round(rsi_raw)` 取整后再判定。
