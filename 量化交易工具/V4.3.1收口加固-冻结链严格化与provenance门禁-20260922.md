## 背景

外部复审后剩三条跟进：校验侧对显式指定侧车过宽（静默回退）、冻结指纹 fund 侧未 scope、registry 的 provenance **只写不查**（③ 写了五键但授权门不验）。三条同批落地，编号 V4.3.1-⑤a/⑤b/⑤c。

## ⑤a 显式 --kfp 严格化（freeze_verify_tool.py）

- 显式 `--kfp` ⇒ 严格模式：文件不存在 / 不可解析（JSONDecodeError → UNKNOWN，不再裸 traceback，P2-② 并入）/ 文件名日期标签与样本不符 / scoped 侧车 cutoff+stock_n 与 meta scope 不符 ⇒ 一律判 **UNKNOWN**，**拒绝回退**同目录兄弟 / meta 字段。
- 理由：显式指定 = 调用方已知该用哪份；回退会静默校验另一份文件 ⇒ 假 PASS / 假 DRIFTED（09-18 事故形态）。
- 边界：自动发现路径（不传 --kfp）与库路径（frozen_dataset.verify_comparability 固定 explicit=None）行为不变；G-B 仍为软标记，UNKNOWN 不改 exit 码，报告原样记录。
- 验证：test_freeze_verify_tool 新增 TestExplicitKfpStrict 6 条（缺失不回退兄弟 / 坏 JSON 不崩 / tag 不符 / cutoff 漂移 / stock_n 不符 / 全符正例）。

## ⑤b 冻结 fund 侧 scope（freeze_samples.py）

- `build_fingerprint` 另传 `fund_codes=sorted({s["fund"] for s in samples})`：基金侧只哈希样本实际出现的基金。无关基金缓存变化（扩池 / 新基金引入 / 净值 TTL 改写）不再改冻结指纹——此前 scoped KFP 只锁了 stock 侧 universe，fund 侧收全量 `data/klines/*.json`。
- 既有锚点不回归：09-10 锚点时 `data/klines` 恰只含 4 只样本基金（002112/002207/022853/025687，已核实留档 kfp 的 fund_sha 键），新口径下 canonical 逐字节不变。
- 验证：kline_fingerprint selftest 23→27（无关基金新增文件 / 净值改写 → scoped KFP 不变；在域基金改写仍敏感；默认口径（无 fund 参）语义不变，旧锚点可比性不受影响）；freeze 测例新增 fund_codes 断言。

## ⑤c registry provenance 门禁（core/model_registry.py）

- `verify_approval` 末尾增一条门禁：`snapshot_provenance` 五键（snapshot_file / samples_sha256_lf / kfp_recorded_sha256 / kfp_current_sha256 / kfp_comparability）齐全才允许对外展示；缺键拒 `snapshot_provenance_incomplete:<缺哪些>`。
- 语义：FROZEN（五键齐全）= 可对外；FRESH（全 None）/ 历史无此块 = research-only，不得对外展示。V4.3.1-③ 让 registry 能"回答"模型基于哪份冻结件训练，本条让它"可拒"——只写不查等于没有门禁。
- 边界（硬）：
  - 门禁只进 `verify_approval`（对外展示 / 决策链授权入口）；
  - `--fresh` 训练路径不经过 verify_approval，不受影响（研究轨照跑）；
  - `derive_promotion` 是五审契约纯函数，判据一字不动（它只读 validation，与 provenance 无关）；
  - v2/v3 条目 promotion 本就 blocked，门禁加在其后 ⇒ 无回归。
- 验证：test_model_registry 27→33（正例改按新契约带完整 FROZEN provenance 注册；新增 FRESH 拒 / 历史无块拒 2 条 + 辅助）。
