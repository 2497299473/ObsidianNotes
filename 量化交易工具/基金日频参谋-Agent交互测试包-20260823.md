## 二、项目背景（自包含，其他 Agent 无需任何额外上下文）

- **项目**：基金日频参谋 v2 —— 场外开放式基金日频参考系统（**只出参考建议，绝不自动下单**）
- **基金池**：002112 德邦鑫星价值 / 025687 国泰半导体制造精选 / 022853 中航优选领航 / 002207 前海开源金银珠宝（均为 C 类）
- **关键约束**：场外基金 **T+1**，唯一有效截止点 **15:00**；三时点 = 盘前 08:30 今日决策 / 盘中 14:30 执行窗口 / 盘后 15:30 次日评估
- **数据源**：东方财富免费接口（`pingzhongdata/{code}.js` 全量净值 + `f10/lsjz` 净值明细/申赎状态），无需 API Key
- **技术路线**：三因子弱参考（MACD柱趋势 + 池内排名20日 + 距60日新高回调）→ 偏多/偏空/中性；**账户面管理为核心**（浮盈浮亏/市值/次日净值区间预估/申赎状态/异常波动告警）
- **自动化**：Windows 定时任务 08:30 / 14:30 / 15:30（工作日）+ 飞书 webhook 推送 + A股节假日日历（`data/holidays.json`）+ 桌面快捷方式
- **历史结论（重要）**：旧 10 维打分引擎历史回测**无正超额**（总分 IC=-0.041 方向性错误）；新三因子有正超额（≥+2 买入 20日超额 +1.56%）但**时段依赖** → 故定位「弱参考」，不构成买卖指令
