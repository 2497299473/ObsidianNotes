## 一、为什么今天三时点内容相同、且下跌却显示偏多

**不是信号引擎算错，也不是推送通道错 —— 是「数据时点」问题。**

实测三份报告（2026-08-25 pre/mid/post）+ 运行日志 + 直连东财接口核验：

| 证据 | 内容 |
|:---|:---|
| 三份报告净值 | 全部 **2026-08-24**（4.9321 / 2.1056 / 1.5890 / 3.1470） |
| 三份信号 | 完全一致：002112+2 偏多 / 025687+1 偏多 / 022853-1 偏空 / 002207+1 偏多 |
| 东财接口实测 | 直到当晚仍无 8-25 净值，最新停留在 8-24 |

### 根因（两层）

**① 三时点内容相同 = 场外基金数据天生 T+1 滞后**
- 场外基金当日净值约 **当晚 20:00 后**才公布。
- pre 08:30 / mid 14:30 / post 15:30 时点时，最新可用净值永远是**上一个交易日**的。
- 于是三时点反复用 8-24 净值算 → 分数/建议完全一致。

**② 下跌却显示偏多 = 信号反映「昨天」而非「今天」**
- 🔴偏多 / 🟢偏空 是**三因子弱参考**判定（MACD柱趋势 + 距60日新高 + 池内20日排名），**不是当日涨跌，也不是次日预测**。
- 它基于 8-24 净值计算：002112 在 8-24 虽单日 -4.1%，但 MACD 柱 +0.08（0 轴上方）、距 60 日新高 -27%（未透支）→ 判"偏多"。
- **8-25 实际下跌的数据根本不在输入里**，所以偏多只是昨天趋势的中性延续，与今天下跌不冲突。

### 关键认知澄清（重要）
> **偏多/偏空 ≠ 次日涨跌幅预测。** 它是当前趋势的状态快照。2026-08-22 回测已实测旧 10 维引擎做时序择时 **IC=-0.041（方向性错误）**，三因子只在横截面（选基）有效、时段依赖严重，所以恒为"弱参考，不构成买卖指令"。**勿当次日预测用。**
