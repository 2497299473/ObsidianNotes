## 一、作者定位

> 用 AI 把投资中的模糊判断变成可审计的流程，并把实践过程开源分享。

勇麦的核心主张：**AI 是副驾驶，不是自动驾驶**。AI 负责收集、整理、监控和补充视角，最终买卖判断永远由人执行。所有产出物均为 Markdown 文件，无私有格式、无数据库锁定、无 SaaS 依赖，本地任意目录可运行，搭配 Obsidian 体验更佳。

这个定位与「每日基金参考工具」的需求完全同频：我们要的是**参考**，不是自动交易。

## 三、YMOS V4 深度剖析

### 3.1 三层架构（核心设计）

```
投研层  →  策略内核层  →  操盘层
看市场、做研究    形成自己的判断    计划、门禁、执行、留痕
Eyes + Skills   Brain + Profile   Console + Human
```

| 层 | 回答的问题 | 对应能力 | 我的类比 |
|---|---|---|---|
| **投研层** | 市场发生了什么？和我的持仓有什么关系？ | 市场洞察 + 投资雷达 + 数据触角 | 「每日基金参考」的信息收集引擎 |
| **策略内核层** | 面对事实我怎么判断？什么时候承认错了？ | Strategy Profile + P1-P18 判断工具 | 缠论方法论 + 我的买卖规则 |
| **操盘层** | 判断形成后怎么计划、过门禁、执行、留痕？ | 交易计划台 + 买卖决策台 + 决策审计 | 基金买卖清单 + 纪律约束 |

### 3.2 关键机制

- **轻脚本 + 重 SOP + 软路由**：脚本只做原子能力（取数据/提取/落盘），Markdown SOP 驱动工作流，大模型 + P 系列提示词做判断。用自然语言暗号触发（如「跑一下投资雷达」），**不需要写代码，说人话就能触发**。
- **Strategy Profile**：唯一的策略配置文件，框架（共用）与个人参数（自定）彻底分离。所有具体阈值、权重、持有周期都不写在 P 里，由 Profile 定义。
- **P1-P18 判断工具**：完整开源不删减，每个模块标注 `invariant`（结构约束）/ `profile`（可整体替换）/ `optional`（无关可停用）。
- **Markdown 状态机**：持仓、Watchlist、账户快照均为 Markdown 文件，只追加不覆盖，可审计。
- **反馈闭环**：BrainStorm（认知语料）+ 平仓复盘（结果证据）→ 进化审查 → Human 审批 → 策略内核更新。单笔结果不改内核，修改必须有反证条件和回滚方案。
- **Human in the Loop**：系统没有自动交易层，所有交易建议只是输入，最终决策权在人。

### 3.3 数据源分级（Level 0-2）

| 级别 | 配置 | 解锁能力 |
|---|---|---|
| Level 0 | 零配置，无需 API Key | RSS + Yahoo Finance（市场洞察 + 投资雷达可直接跑） |
| Level 1 | FINNHUB_API_KEY（免费） | 美股/Crypto 实时报价和新闻 |
| Level 1+ | TUSHARE_TOKEN（免费） | **A股日线与最近交易日价格** |
| Level 1++ | 外部问财 Skills + IWENCAI_API_KEY | A 股 What's Hot / 条件选股 / 公告研报新闻财务 |
| Level 2 | YMOS_MARKET_API_* | 结构化市场事件 API |

### 3.4 定时任务（与「每日参考」直接相关）

| 任务 | 建议触发 | 作用 |
|---|---|---|
| 市场洞察 | 市场收盘后或每天一次 | 建立市场背景与事件地图 |
| 投资雷达 | 市场洞察完成后 | 把事实映射到持仓、关注与偏好 |
| 平仓复盘归档 | 每周或每次平仓后 | 把实际结果变成策略验证证据 |
| 内核周期审计 | 月度/季度 | 样本不足 10 笔不提案 |

### 3.5 许可与边界

- **CC BY-NC 4.0**：个人使用/学习/研究自由，公开发布衍生作品需注明来源，商业用途需单独授权
- 明确边界：不提供荐股信号、不自动交易、所有报告只是输入
- 需要用户已有一定投资经验（不是给新手找「买什么」答案的工具）

### 4.3 缠论方法论如何装入 YMOS

YMOS 的策略内核层是「框架与参数分离」设计，正好承接缠论：

| YMOS 模块 | 装入缠论内容 |
|---|---|
| **Strategy Profile** | 定义我的基金标的范围、入场依据（三类买点）、失效信号（中枢跌破/背驰破坏）、仓位规则、止损门禁 |
| **新增「缠论裁判」P 模块**（P19 或替换 P6 退出裁判） | 笔/段/中枢/背驰/买卖点判定规则，标注 `profile`（可整体替换） |
| **BrainStorm + 缠论知识库** | 缠论 PDF 提取的知识（笔/段/中枢/买卖点定义）作为长期认知语料；向量库做 RAG 检索补充 |
| **买卖决策台门禁** | 缠论买点确认（三类买点 + 次级别走势完成）+ 基本面过滤（PE 分位/ROE/资金流）双门禁 |
| **反馈闭环** | 每笔基金交易按「计划 vs 实际」留痕，周期审计验证缠论规则是否有效，样本 ≥10 笔才提案改规则 |

### 4.4 与我已有笔记的关系

- `基金日频买卖工具-项目分析.md`：5 项目选型 → **YMOS 可替代其中「报告生成 + 决策框架」部分**（a-share-us-catalyst 的日频早报思路、TradingAgents 的多 Agent 决策、Vibe-Trading 的 IM 适配）
- `缠论知识库-Schema设计.md`：知识库设计 → **概念/规则层映射为 YMOS 的 P 模块 + Profile**，策略层映射为 YMOS 的 SOP 路由

## 五、方案对比：自建 vs 基于 YMOS

| 维度 | 纯自建（原方案） | 基于 YMOS 魔改 |
|---|---|---|
| 日频报告引擎 | 自己写市场洞察/投资雷达逻辑 | ✅ 现成（SOP + 暗号 + 定时任务） |
| 决策框架 | 自己设计 Prompt 链 | ✅ P1-P18 完整开源，标注了哪些可替换 |
| 缠论整合 | 自己设计规则库 | ✅ 装入 Profile + P 模块，结构清晰 |
| 纪律约束 | 无（纯参考推送） | ✅ 买卖门禁 + 决策审计 + 只追加留痕 |
| 进化机制 | 无 | ✅ 反馈闭环（但需要至少 10 笔真实交易） |
| 手机推送 | ✅ 自建 webhook | ⚠️ 需自建推送层（YMOS Console 无推送） |
| 学习成本 | 从零设计 | ⚠️ 需理解 YMOS 的 SOP/暗号/目录约定 |
| 数据源 | tdxrs/a-stock-data | ✅ 可替换，Tushare 原生支持 |

**结论**：YMOS 是「自建方案」的**高级起点**而非替代品——数据层、推送层仍按我的方案（tdxrs + a-stock-data + 飞书 webhook），决策框架和日频 SOP 直接借用 YMOS 的成熟设计，缠论作为我的策略内核装入 Profile。

## 七、风险与注意事项

1. **许可证**：CC BY-NC 4.0，个人使用自由；若将来商业化需单独联系作者授权
2. **不自动交易**：YMOS 无自动交易层，正好符合「参考工具」定位；不要魔改成自动下单（合规 + 风险）
3. **框架 ≠ 策略**：YMOS 的作者参数是「打样」，必须改成自己的（缠论 + 基金）；直接照抄参数等于没有策略
4. **样本门槛**：反馈闭环需要 ≥10 笔已平仓交易才有统计意义，初期不要过早改规则
5. **数据源稳定性**：Tushare 免费 token 有积分限制，仍需 tdxrs 本地源互备
6. **缠论主观性**：缠论有大量「当下判断」成分（笔的划分、背驰确认），规则化时保留 Human 确认环节，别让 AI 全权判定
