# 基金日频参谋 v2 · 交易策略说明

> 版本：v2.0（混合定位，2026-08-22）
> 定位：**账户面管理为核心 + 三因子弱参考为辅，不构成买卖指令**
> 策略依据：[[基金日频参谋-回测校准-20260822]]（四阶段证据链：IC 诊断 → 连续因子检验 → 新引擎重组 → 时间分段验证）

---

## 一、策略定位

本系统用于辅助场外基金投资者进行**日常账户面监控**与**技术面弱参考**，不做自动交易，不提供买卖指令。

- **核心**：持仓盈亏、市值、申赎状态、T+1 确认规则、次日净值区间预估
- **弱参考**：基于净值的三个技术指标，给出「偏多 / 偏空 / 中性」的观察姿态
- **决策权**：始终由用户手动执行

## 三、三因子弱参考引擎

### 3.1 因子定义

经过逐维度 IC 诊断、连续因子检验、新引擎重组与时间分段验证后，保留 3 个在统计上相对最稳健、逻辑最自洽的因子：

| 因子 | 含义 | 正向条件 | 回测证据（4802 交易日） |
|---|---|---|---|
| 趋势 | MACD 柱方向 | MACD 柱 > 0 | 时序 IC +0.032，横截面 IC +0.299 |
| 相对强度 | 池内 20 日收益排名 | 排名 > 50% | 分桶单调 ↗ 2.8→5.7→5.8% |
| 回调 | 距离 60 日新高的幅度 | < -3%（刚回调） | 分桶单调 ↘ 2.5→0.9→0.7%（买回调不追高） |

每个因子贡献 -1 / 0 / +1，最终合成 **参考分 -3 ~ +3**：

- **≥ +1**：偏多（📈）
- **≤ -1**：偏空（📉）
- **其余**：中性（➖）

### 3.2 为什么只作「弱参考」

回测证据链（阶段① ~ ③.5）显示：

- 旧 10 维引擎总分 IC = -0.041，方向性错误（买入跑输基准 0.8~1.1pp）
- 新引擎买入 ≥2 超额转正（002112 +1.56% / 002207 +0.54%），但**时间分段验证存在时段依赖**（002112 前 50% 时段 -0.53%）
- **没有找到时间稳定的短周期买卖信号**（卖出信号全程无效）

因此弱参考仅作为技术面观察，不触发买入/卖出建议。

## 四、账户面管理核心

### 4.1 录入持仓

在 `holdings.json` 中录入份额与成本净值：

```json
{
  "holdings": {
    "002112": {"shares": 3222.21, "cost_nav": 4.5161},
    "025687": {"shares": 3321.00, "cost_nav": 2.1812}
  }
}
```

### 4.2 每日输出

| 字段 | 说明 |
|---|---|
| 最新净值 | 前一交易日确认净值 |
| 市值 | 份额 × 最新净值 |
| 浮盈/浮亏 | (最新净值 - 成本净值) / 成本净值 |
| 次日净值区间 | 基于近 20 日收益波动率估算 1σ 区间 |
| 申赎状态 | 开放 / 暂停 |
| 弱参考姿态 | 偏多 / 偏空 / 中性 |

## 六、风险控制与纪律

1. **不自动交易**：系统只出参考建议，最终决策由用户手动执行
2. **弱参考不构成买卖指令**：任何「偏多 / 偏空」都不应直接等同于买入/卖出
3. **持仓纪律**：关注浮盈浮亏、成本线、申赎状态即可
4. **数据风险提示**：新基金历史净值不足 200 条时，标注 ⚠️ 数据不足
5. **T+1 规则**：场外基金 15:00 前申赎按当日净值确认，15:00 后按下一交易日净值
6. **异常波动告警**：近 5 日波动超过近 20 日 1.8 倍时提示，不自动调仓
