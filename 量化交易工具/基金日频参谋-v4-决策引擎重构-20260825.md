## 二、v4 数据流

```
基金净值 → 穿透（季报前十大）→ 实时行情（腾讯）
    → 日内特征引擎（估算/同向度/集中度/覆盖率/新鲜度/可信度）
    → [mid 11:30 存快照] / [post 14:55 读快照 → 变化量 Δ]
    → 决策倾向引擎（五维加权 → 倾向分 -100~+100）
    → 四道准入门槛（覆盖率≥60% / 持仓≤120天 / 仓位≤80% / history_validated）
    → 报告 + 飞书推送 + 人工确认
```

| 维度 | 权重 | 口径 |
|---|---:|---|
| 日内趋势 | 35% | 14:55 估算涨跌 + 午盘→尾盘变化量 |
| 重仓一致性 | 25% | 前十大同向度 + 集中度惩罚 |
| 池内相对 | 15% | 本基金 vs 池内其他基金实时估算均值（行业指数待接入） |
| 中期趋势 | 15% | 原三因子总分（保留为解释维度） |
| 账户约束 | 10% | 仓位余量 / 成本保护 / 连续加仓限制 |
