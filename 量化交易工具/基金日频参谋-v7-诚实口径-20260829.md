### 1. P0-2：split_date_oos 加 label-end purge（正式进代码）

**问题**：原切分 `train = date < oos_start`，train 尾部样本的 fwd≤5 标签窗口伸进 OOS 段

**修法**（`backtest_forecast.py`）：`cutoff = oos_start 前 max_horizon(=5) 个交易日`，train 收窄为

极端小池子不崩、分区完备（train+oos=全量−purge 段）、**纪律本质断言**（train 最大日期+5 交易日 < oos_start）、空样本回归。

### 2. P0-4：删假 max_dd（标「未建模」）

`forecast_engine.py` 的 `max_dd = min(0, q10)` 是估算不是建模 → 从 `HorizonForecast`/`predict_dist`/

**「max_dd 未建模（P2 真 MDD 标签后再上）」**。连带修掉一个 latent bug：
`decision_engine.py` NO_FEATURES 分支的位置参数构造（11 参 → 9 参，此前一触发就 TypeError，单测未覆盖 live 路径）。

### 3. P0-5：q50 改名 E[return]

**裁决规则升级（P1 同步落地）**：

**结论（诚实口径）**：
1. **T+5 是唯一真显著的周期**（CI 下界 +0.017 > 0，且两次独立重跑都为正 +0.062/+0.080）；
   Brier 0.537 优于多数类 0.549，RankIC 优于 est_chg −0.015。
2. **T+1/T+3 的 08-28 ✅ 被推翻**：purge 后点估计漂到 +0.002~+0.005，CI 跨零——
   此前的「信号」部分是 train 尾部偷看 OOS 开头撑起来的。
3. 整体 ❌ → **model_ready 维持 false，不重训**（重训=把 OOS 段再榨一遍，违反冻结纪律）。
4. **复现性留痕**：两次重跑 IC 漂移 ±0.03~0.05（08-28 口径 vs 08-29 口径 T+3 从 +0.034→+0.051→+0.002）。

   样本特征向量随数据可用性波动。**T+5 两次均显著为正 → 结论稳健；T+3 在噪声边缘 → 不可靠。**

## 四、P2 四项（最小版 + 真标签 + 实验）

### 1. path forecast（最小版）

新建 `core/path_forecast.py`：日收益 N(μ,σ)（经验参数）蒙特卡洛 2000 路径 →
终点 E/Q10/Q90 + MDD 分位 + MFE 分位 + 中点路径。纯正 numpy，观察层不产动作。
局限（如实）：全局常数 μ/σ，不区分基金/状态；条件化版本（horizon×state）为后续迭代。

### 2. MDD/MFE 真标签（backtest_spread.load_samples）

新增 `mdd1/mdd3/mdd5` + `mfe1/mfe3/mfe5`：未来 h 日 NAV 窗口内「任意时点起的最大后续
跌幅/涨幅」，**历史净值真实计算，非模型估计**。含起点（决策日本身）。
供 path_forecast 预测侧的真值对照（Q10 排序 vs 真 MDD 的 RankIC，见联合回测报告）。

### 3. state→forecast 增量实验

`experiment_state_feature.py`：A（7 基线特征）vs B（+4 状态数值编码
trend/pos/bucket/event），同 purge 切分同裁决。
**PIT 口径**：状态用 `states_for_fund`（日 i 的状态 = navs[:i] 前缀重放，即截至 i-1 净值，
与 _nav_state_at T-1 口径对齐——14:55 决策时 d 日净值未公布）。
**判定规则事先写死**（v5.1/v5.2 先例）：任一周期 ΔIC < −0.01 → 判过拟合风险维持 A；
全周期不劣且至少一周期 +0.01 → 报 Summer 决策。本脚本只产证据，不改 FEATURE_KEYS。

**结果**（`output/experiment_state_feature_v7_20260829.log`）：
| 周期 | A（基线7特征） | B（+4状态特征） | Δ |
|---|---|---|---|
| T+1 | +0.0107 | +0.0219 | +0.0112 |
| T+3 | +0.0149 | +0.0027 | **−0.0122** |
| T+5 | +0.0852 | +0.1179 | +0.0327 |
→ **判定：T+3 恶化 >0.01 → 过拟合风险，维持基线 A（不改 FEATURE_KEYS）**。
模式与 v5.1/v5.2 一致：状态特征在 T+5 有增量（+0.0327，与 main 重跑 T+5 显著性方向一致），
但短周期被稀释。后续若接入，应做「T+5 专用状态特征」而非全周期共享（待数据积累后第二轮实验）。

### 4. Forecast→Policy 联合回测

`backtest_forecast_policy.py`：政策规则固定 θ=0.6（p_up≥θ 加 / p_down≥θ 减 / 否则不动），
次日实现收益 fwd1（T+1 决策→次日结算，场外基金口径）。
只产证据**不接下单**（config.decision 门禁一律不动）：
- ML 概率政策 vs est_chg 单因子同规则（Δ = ML 增量）
- 加日超额 cluster bootstrap 95% CI
- Q10 预测 vs 真 mdd5/mfe5 的 RankIC（v7 移除 max_dd 后的尾部证据替代）
- path forecast 模拟 vs OOS 经验分位校准对照

**结果**（报告 `output/backtest_forecast_policy_v7_20260829.md`）：
1. **ML 政策无稳定超额**：θ=0.6 下 ML 只在 9/305 日触发「加」（概率分布集中在 0.2~0.5，
   触顶罕见），加日 −0.999% vs 不动 +0.201%（n=9，统计上不可用）；est_chg 单因子同规则
   加超额 +0.181%（n=466，样本足但量级=噪声级，CI 不足）。**结论：概率→动作这一步
   在现有模型精度下不成立，证据不支持接下单**（与 v4 history_validated=false 同向）。
   附带发现：θ=0.6 对 ML 概率是死区——后续做政策回测应先做概率分位自适应 θ 或
   用「p_up−p_down 差值排序 top-k」口径，固定阈值对未充分校准的概率分布不公平。
2. **Q10 vs 真 mdd5 RankIC = +0.0201**（弱正）：Q10 有尾部排序力的微弱证据，
   max_dd 移除后这个口径是替代证据；远未达到「可当风险指标对外」的强度。
3. **path 校准**：模拟 MDD Q50 −4.59% vs 经验 −3.76%（量级对）；但终点 Q10/Q90 模拟
   [−8.2%, +10.2%] 明显宽于经验 [−3.4%, +4.1%]——全局 N(μ,σ) 假设高估了 5 日波动
   （真实日收益序列有自相关/聚集，独立正态假设偏保守宽）。条件化版本再修。
