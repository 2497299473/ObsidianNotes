## 一、四个 P0 硬契约

### ① 统一样本入口 `frozen_dataset.py`（P0-1）

- **病灶**：12 个回测/评估脚本各自直调 `backtest_spread.load_samples()`，每跑一次都**活拉**当前缓存
  ⇒ 两次「同代码、同日」跑出两套数字，历史报告无法对数复现。
- **修法**：新增 `frozen_dataset.resolve_samples()` 作**唯一入口**，默认强制消费 canonical 冻结件：

| 情形 | 判定 | 行为 |
|---|---|---|
| 无冻结件且未 `--fresh` | **MISSING** | fail-closed，调用方 `exit 4`，**拒绝静默活拉兜底** |
| G-A 失败（sha/行数/降级征兆/个股K线失败） | **INVALID** | 同上 `exit 4` |
| G-B `DRIFTED` / `UNKNOWN` | 软标记 | 样本照用，`report_line` 必须写进报告，且该轮**不得引用历史绝对值作门槛** |
| `--fresh` 显式活拉 | **FRESH** | 报告标 `FRESH`，与冻结基线不可比 |

- **接入面（12 个脚本）**：`backtest_action` / `backtest_forecast` / `backtest_forecast_policy` /
  `backtest_lofo` / `backtest_quantile_calib` / `backtest_rolling_oos` / `backtest_spread` /
  `backtest_t5_scorecard` / `backtest_walk_forward` / `drift_monitor` / `experiment_state_feature` /
  `train_forecast_model`。
- **口径复用而非另起炉灶**：`frozen_dataset` 直接 import `freeze_verify_tool`，G-A 判据与
  `freeze_verify_tool.py verify` **逐字一致**——避免「verify 过但 resolve 拒」的夹缝破坏三件套可信度。
- 新增 `frozen_dataset.py`（195 行）+ `tests/test_frozen_dataset.py`（207 行，tempdir 零网络）。

### ② KFP as-of + universe 口径（P0-2）

- **病灶**：K 线指纹原为**全量口径**（扫全部 `data/stock_klines/*.json`、全部日期）⇒
  冻结日之后新增行（窗口滚动）也会改指纹 ⇒ **假漂移**，让真问题淹没在噪音里。
- **修法**：`build_fingerprint(stock_codes=<本次样本 universe>, cutoff=<冻结日>)`
  - 冻结日之后新增行 **不改**指纹（窗口滚动假漂移消除）；
  - cutoff 前历史 close 被复权追溯改写 **仍改**指纹（对真问题的敏感度不变）；
  - canonical 串加 scope 头 `#scope stocks=…;cutoff=…` ⇒ **与 09-20 前全量口径锚点不可混用**；
  - 两者都不指定时 canonical 与旧口径**逐字节一致**（09-10 / 09-16 锚点仍可比）。
- **校验侧同口径重算**：`freeze_verify_tool.current_kline_fingerprint()` 读留档 scope 决定是否带参——
  混口径会改变 canonical 串 ⇒ 假漂移（`DRIFTED` 会误报为结构性问题）。

### ③ 个股 K 线失败契约（P0-3）

- **病灶**：`fetch_stock_klines` 旧实现 `except Exception: pass` **静默跳过** ⇒ 不完整样本被当完整样本冻结，
  `covered_pct` 靠不完整数据算，事后无迹可查。
- **修法**：每次失败记入 `{code, market, error}` 并返回调用方：
  - `freeze_samples.py`：任一失败 ⇒ 快照 **SNAPSHOT_INVALID**（隔离，不发布 canonical）；
  - 回测/报告层：打印失败清单，报告必须记录。
  - 成功路径行为**零变更**（`series_map` / `close_map` 口径与旧实现逐字一致）。

### ④ T+5 证据清理（P0-4）

- **+0.080 降为历史档案**（2026-09-01 冻结模型 pooled 档案值，09-08 WF 曾 +0.089）——
  已被特征非不变性复算推翻。
- **当前结论 = UNRESOLVED**：09-18 C2/CTRL WF 部署式 pooled RankIC **−0.079** CI[−0.158, −0.016]（不显著）。
- README 状态行同步改写，**不再引用 +0.080 作当前结论或门槛**。

## 二、三道 SNAPSHOT_INVALID 门禁（freeze 侧）

```mermaid
flowchart TD
    A[freeze_samples.py 启动] --> B{当日 canonical 已存在?}
    B -- 是 且未 --force --> Z1[exit 2 拒绝重采 no-clobber]
    B -- 否 --> C[load_samples 活拉 东财请求]
    C --> D{① 降级/频控征兆?}
    D -- 是 --> Q[freeze_failed_* 留证<br/>canonical 一个都不写<br/>exit 1]
    D -- 否 --> E{② 个股K线失败?}
    E -- 是 --> Q
    E -- 否 --> F[写 .staging 三件套<br/>jsonl / kfp / meta]
    F --> G{③ KFP unreadable 非空?}
    G -- 是 --> Q
    G -- 否 --> H{④ code commit 取不到?}
    H -- 是 --> Q
    H -- 否 --> I[os.replace 原子发布<br/>staging → canonical]
    I --> J[exit 0]
```

- **关键顺序**：降级检查必须**先于**任何 canonical 落盘。旧实现先写 canonical 再查 flags，
  `exit 1` 时件已残留 ⇒ no-clobber 把「降级残留」误当「当日已冻结」，挡住 09-26 预注册的「同日重试 1 次」。
- **原子发布**：三件套（jsonl / kfp / meta）一律先写 `forecast_outputs/.staging/`，
  检查通过才逐个 `os.replace` 进 canonical 名；降级 ⇒ staging 整体 rename 到
  `forecast_outputs/freeze_failed_<YYYYMMDD>_<HHMMSS>/` 留证。
- **fail-closed 而非静默**：`code_commit` 取不到（git 缺失/非仓库）⇒ 三件套第①件断链 ⇒ INVALID 不发布，
  不留无主件。

## 三、首次「带 scope 指纹」冻结：执行裁决

### 结论：**本轮不执行** —— 时间盒闸门硬否决

授权前必过四项征兆闸门。本次逐项核查（**全部为本地只读检查，零网络**）：

| # | 闸门 | 核查结果 | 判定 |
|---|---|---|---|
| 1 | 上游已跑完 | 最新 `daily_runs` = 09-18；今日 09-20 为**周日非交易日** | ⚪ 不适用 |

| 3 | 无并行拉取 | 仅 OpenSquilla gateway + Tabbit runtime；**无 ZCode 侧同类拉取** | ✅ PASS |

兜底自动重启浏览器 12 次全灭、至 09-10 才自愈）；而**缓一天的代价 ≈ 0**。

## 四、代理环境核查（回答「开着代理是否适合请求东财」）

**结论：代理不是阻塞项。** 四项本地实证：

1. **系统代理确实开着**：注册表 `ProxyEnable=1` / `ProxyServer=127.0.0.1:7892`，
   且 `FastLinkCore.exe`（PID 4584）正监听 `127.0.0.1:7892`。
2. **但生产链路不读它**：`core/netutil.py` 自 2026-09-02（v3）起**主链路不走 urllib opener、
   完全不读环境代理**——自己做 DNS 解析（v4 优先）后逐 IP 建连。
   模块 docstring 明写：「数据源（腾讯/东财/Tushare）全部国内直连，不需要代理」。
3. **环境变量为空**：`http_proxy` / `https_proxy` / `ALL_PROXY` / `NO_PROXY` **全部未设置**
   （`getproxies_environment()` 返回 `{}`）。故 `curl_cffi` 浏览器指纹兜底路径
   （`trust_env` 默认 `True`，读的是**环境变量**而非注册表）同样**不会**注入代理。
4. **无透明路由劫持**：无 TUN/WireGuard 类网卡处于 Up（`QMTAP Adapter V9` 为 Disconnected）；
   DNS 解析返回**真实国内 IP**（push2his → `61.129.129.199`、fundf10 → `117.135.148.x`），
   非代理伪造地址；hosts 文件无 eastmoney / gtimg 条目。

⇒ **代理开着不影响东财请求**。真正的阻塞项是**时间盒**（20:33 ≫ 11:20）+ **周日非交易日**。
