**设计**：`deploy/probe_lifecycle/<probe_id>.yaml` + `_index.json`，schema 借鉴 trader-memory-core 但去掉 P&L、换上预注册语义：

```yaml

status_history: []        # append-only，每条 {at, from, to, reason, actor}

retire_rule: "连续 N 窗 |RankIC| 跨零 且 CI 含 0 → 进入 RETIRED 评审"
adjudication:             # 退役归因四分类（借鉴 signal-postmortem，替换掉盈亏语义）
  reason_class: null      # 信号质量 | 数据链路 | 市场环境 | 随机性
  evidence: []            # 指向 evidence/probes/ 逐字节落档件
fingerprint: {klines_sha: null, code_commit: null}   # 裁决当时输入
review_due: 2027-03-26    # 季度节点对齐
```

**纪律三点直接复用**：原子写（tempfile+os.replace）、git 即审计轨迹、状态不变式（RETIRED ⇒ adjudication 非空）。**与预注册同构的核心**：退役 = 预注册判据的「跑数→裁决」半程，归因四分类强迫回答「退役是判据兑现还是链路事故」——不许把随机性当信号质量，也不许把熔断当判据。
