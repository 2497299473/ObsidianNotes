## 二、发现 1：CS 三拆在生产轨结构性不可测

- `backtest_forecast.rank_ic()` 有 `if len(xs) < 10: return 0.0` 的小样本保护。
- 生产轨 `config.fund_pool` 只有 4 只基金 ⇒ 任何一天的样本数 ≤ 4 < 10
  ⇒ 逐日 IC **全部返回假 0**，CS 均值恒为 0.0、CI [0,0]。
- 这不是「CS 无信号」，是「CS 测不了」。脚本已改为显式 `computable=false` 并在
  判据里返回「不可测」，**不得**把假 0 记成 B1=False（否则等于用工具的盲区造结论）。
- 对照：C1 用的 D-lite 面板日宽 21–26（≥10），CS 可测 —— 三拆天生只适合宽面板。

**沉淀**：任何按日/按成员切分的统计，调用前先核「分组后组内 n」是否越过引擎保护阈值。

### 3.2 根因（D1 已分离两个因素，原假设①被证伪）

**D1 实验（09-18 21:0x，零网络）**：`git worktree` 检出 `ed9e0d3^`（09-11 修复**前**的代码），
喂**同一份** `samples_frozen_20260910.jsonl`：

| 代码版本 × 输入 | T+5 WF pooled |
|---|---|
| 修复前 `ed9e0d3^` × 09-10 冻结件 | **−0.079 [−0.158, −0.016]** |
| 修复后 HEAD × 09-10 冻结件 | **−0.079 [−0.158, −0.016]**（逐位相同） |
| 修复后 HEAD × 09-16 重放件 | +0.049 [−0.004, +0.126] |
| 09-08 实时 `load_samples()` | +0.089 [+0.034, +0.155] |

⇒ **翻负 100% 来自输入数据，与 09-11 的 build_xy 日期对齐修复无关。**
（自我纠错：本节先前写的「+0.089 可能是 bug 产物」是**未经检验的猜测**，已被 D1 否证——
09-08 那个数字在它自己的输入下是诚实的，只是那个输入今天复现不出来。）

**真正的根因是②：特征不是时点不变的。**
比对两份冻结件（09-10 与 09-16）共有 3371 行：

共有行 3371 条，按「是否在 `FEATURE_KEYS`」分列：

| 类别 | 字段 | 漂移行占比 |
|---|---|---|
| 标签（不进 X） | `fwd1/2/3/5/10/20`、`mdd5`、`mfe5` | **0.0%** 全部一字不动 |
| 特征·非个股K线 | `score`（缠论/弱信号分，纯基金净值） | **0.0%** |
| 特征·个股K线衍生 | `est_chg` | **81.7%** |
| 特征·个股K线衍生 | `concentration` | **81.6%** |
| 特征·个股K线衍生 | `covered_pct` | **38.1%** |
| 特征·个股K线衍生 | `breadth` | **31.9%** |
| 特征·个股K线衍生 | `composite` / `est_sign` | 2.6% / 2.4% |
| 派生列（**不在** FEATURE_KEYS，不进模型） | `excess10` | 100%（= fwd10 − 该基金全样本均值，样本多 16 行即全体平移） |

⇒ **`FEATURE_KEYS` 7 个特征里 6 个会漂，全部标签 0 漂**。
分界干净得可疑：**凡是只依赖基金自身净值的字段全稳，凡依赖穿透个股 K 线的字段全漂。**

补一句免误读：`composite`（取值 {−1,0,1}）与 `est_sign`（±1）是**离散化后的**个股衍生量，
2.4%/2.6% 不是「它们比 est_chg 稳」，而是连续量 `est_chg` 漂了 81.7% 之后
只有约 2.5% 跨过了取整阈值。连续层面的漂移幅度，以 `est_chg` 的 81.7% 为准。

个股 K 线指纹印证来源：`kline_fingerprint_20260910` (f5a2f607) →
`kline_fingerprint_20260916_panel` (b5b25cd3)，**240 只里 186 只 sha 变了**。
即：穿透估算所用的个股收盘价序列被**追溯改写**（复权因子 / 分红除权重算），
于是「同一天同一基金」的特征值在两个月后不是同一个数。

这正是 09-10 Summer 拍板加 `kline_fingerprint` 时预判的风险（脚本注释原话：
「缓存 TTL 到期重取会追溯改写历史 close，样本没变、语义变了」）——
指纹**抓到了**，但下游一直没把它当裁决前提用。

### 3.4 敏感度的量级（诚实标注）

同一份代码、同一天跑的两次，只换冻结件版本（09-10 vs 09-16，相差 6 天），
T+5 就从 **−0.079（显著负）** 变到 **+0.049（跨零）**。
⇒ 该口径下 T+5 点估计对**样本快照版本**的敏感度 ≥ 它对**模型/折构造**的敏感度。
在这种敏感度上谈「T+5 显著 / 不显著」都没有意义，先把输入钉死才有可比性。
