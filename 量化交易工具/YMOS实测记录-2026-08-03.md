## 三、关键发现

### 1. 三层架构（可复用到 Summer 的基金工具）

```
投研层 Eyes        → 策略内核层 Brain      → 操盘层 Console
看市场、做研究        形成自己的判断            计划、门禁、执行、留痕
市场洞察/投资雷达     Profile + P1-P18 判断     Reader/买卖决策台/交易计划台
```

**换掉它会改变什么，就归哪一层**——这是 YMOS 的核心分层法则。

### 2. 暗号驱动的日频工作流（最契合 Summer 需求）

| 暗号 | 动作 | 入口 |
|:---|:---|:---|
| `跑一下市场洞察` | 获取并压缩外部市场事实 | `Eyes/SOP_市场洞察.md` |
| `跑一下投资雷达` | 外部变化映射到持仓/关注 | `Eyes/SOP_投资雷达.md` |
| `查一下价格 [ticker]` | 实时价格（美股→Finnhub，A股→Tushare，港股→Yahoo，兜底问财） | `Eyes/scripts/fetch_price_router_v2.py` |
| `跑一下策略分析` | 状态机+雷达双输入判断 | `Brain/SOP_策略分析.md` |
| `配置一下我的内核` | 逐题建立个人 Strategy Profile | `Brain/内核审计/SOP_内核入职配置.md` |
| `审计一下我的内核` | 聚合证据找重复缺口提变更 | `Brain/内核审计/SOP_内核周期审计.md` |

### 3. 数据源分级（进阶指南）

| 级别 | 能力 | 需要的 Key |
|:---|:---|:---|
| Level 0 | RSS + Yahoo Finance（零配置，本次实测） | 无 |
| Level 1 | 美股/Crypto 实时报价 + 个股新闻 | Finnhub Free（免费注册） |
| Level 1+ | A股日线（比 Yahoo 稳定） | Tushare Pro Token（免费） |
| Level 2 | 结构化中英文市场事件（28源预处理） | 需联系作者 |
| Level 1++ | 问财：选股/公告/研报/新闻/财务 | iwencai Skills |

### 4. 策略 Profile 是唯一策略接口

- 判断方法（P 系列）与判断参数（Profile）**分离**
- 模块标注 `invariant`（结构约束）/ `profile`（可替换）/ `optional`
- **作者默认不内置任何参数**，所有数值由用户定义
- 机器接口：`Brain/策略配置/strategy-profile.schema.json`
- 人类模板：`Brain/策略配置/_模板_策略_Profile.md`

### 5. 系统边界（重要）

- **不荐股、不自动交易**，所有报告只是输入，最终决策在 Human
- Agent 不得写「已成交/已执行/已验证」
- 策略修改必须经过：证据 → 提案 → Human 审批 → 试运行 → 复核 → 回滚条件
- 内核更新要求写明「如果这次修改是错的，会看到什么」——**可证伪条件**

## 五、遇到的问题与注意

1. **PowerShell 中文乱码**：脚本输出中文在终端显示乱码，但写入 JSON 文件是正常 UTF-8，不影响使用
2. **git clone 红色报错**：是 stderr 误报，验证目录存在即可
3. **Python 3.14**：requests/feedparser 正常，若后续装 yfinance 等需注意兼容
4. **免费源限制**：Level 0 只有 RSS 摘要+Yahoo 收盘价，要做盘中实时需要注册 Finnhub/Tushare（均免费）
5. **ETF 行情**：Yahoo 对 510300.SS 支持良好，但 tdxrs 本地源对 ETF 更全（K线/列表）
