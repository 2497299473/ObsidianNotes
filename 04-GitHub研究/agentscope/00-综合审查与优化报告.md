2. **"千问 3.7 Max"失败不是模型路由问题** — 当前路由目标只有 `deepseek-v4-flash` / `deepseek-v4-pro` / `kimi-k2.7-code` / `glm-5.2`，不存在"千问 3.7 Max"。根因是沙箱后端不可用（`windows_default=not ready`），导致子 Agent 文件 I/O 全部被拦截。关闭沙箱后已恢复。
