## 三、背驰判断流程

1. 确认是趋势（至少两个同级别中枢），否则按盘整背驰处理（课37）
2. 定比较对象：围绕同一中枢的两同向段（先定中间中枢，课64）
3. MACD：B段黄白线回拉0轴后，比A、C柱面积；1分钟以下只比柱面积，1分钟以上兼看黄白线回抽0轴（课24/56）
4. 背驰位置规则：第一个中枢后只有盘整背驰，绝大多数趋势背驰在第二中枢后（课27）
5. 成立则三结局分类＋回跌下限（至少回B段中枢，课24）
6. 精确点用区间套逐级下移定位（课27/61）
7. 按操作级别执行：1分钟操作者见1分钟顶背驰即走，月线操作者忽略1分钟震荡（课61）

## 四、线段划分速查

- 包含合并：向上取高高点与较高低点，向下取低低点与较低高点；无传递性按顺序合并（课62/65）
- 笔：顶底分型间至少一根独立K线；顶不高于底的笔不成立（课62/77）
- 线段：至少三笔且前三笔重叠；向上段必终于向上笔；任何一段都破坏前一段（课65/77/78）
- 终结：无缺口＝第一种情况，分型极值点终结；有缺口＝第二种情况，须第二特征序列分型（课67）
- 线段必须被线段破坏；单纯一笔不构成破坏；突然逆向缺口须当成一段（课64/65）
- 精度（取整/小数位）可任意预设，一旦预设全程保持（课64）

## 五、操作纪律速查

- 节奏：买点买、卖点卖；逆大级别参与小级别＝刀口舔血（课41/32）
- 资金：无期限资金；绝不向上加码；一次性建仓；留1/10机动资金（课26/31）
- 短差：每次短差不增加股数；只做操作级别中枢震荡的差价；三卖不回补（课31/49）
- 清仓：0成本后挣股票，直到月线以上卖点一次性清仓（课31）
- 不参与：操作级别以上的下跌与超级别盘整；初学者不用小级别，至少5分钟（课41/49）
- 退出：持仓与当下走势相反最快速度退出；分型后有效破5周/5日线必走（课34/94）
- 改错：错过一买有二买三买；连错三次去休息；节奏错一步停止操作调心态（课41/39）
- 防狼术：能力所定最低周期MACD黄白线在0轴下＝彻底离场（课103）
