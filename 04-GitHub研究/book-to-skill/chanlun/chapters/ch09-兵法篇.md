# 第九篇 兵法篇
> 涵盖课程：课28、51、66、97、98、100
> 定位：市场大佬的境界——中医、兵法、诗歌、操作；主力资金食物链；荐股传销把戏

## 核心概念
- **主力资金食物链**（课66）：不存在统一控制市场的"主力"；资金从来分派别，有联手有暗算。从最顶层资金到散户分若干层次，顶层维持生态平衡，重点绞杀破坏平衡的暴发户式次级资金。
- **合法传销**（课28）：基金的本质。命门是"钱不是自己的"——赎回潮、净值考核、单票持仓比例限制都可被攻击；价值投资不过是一种传销手段。
- **荐股传销**（课51）：高流量处荐股→一小部分人买入推高股价→"推荐准"被证明→吸引更多资金，如此循环；精细化为分级会员制后可演化成私募。市场中绝大多数人都在无意识地参加传销游戏，充当炮灰。
- **猎鲸者**（课51）：缠君自况的角色：必须对所有猎杀对象有最清楚的认识，只对最大的生物下手；授人以渔，不搞传销。
- **上帝式思维**（课97）：贪婪的产物——寻求一种先验地决定一切、一劳永逸的预测性指标或万能拐杖。这种东西不存在。
- **中医类比**（课97、98）：先吃透理论→望闻问切（机会的当下显发）→开药方（操作），开药方的难度占九成；用药因人因时因地而异，效果要吃药后再测、随反馈增减。
- **格律诗与拗体**（课97）：初学必须严格按买卖点纪律（格律）；熟练自由之后才可为了更大目的偏移买卖点（拗体），自设声律。
- **完全分类、没有意外**（课98、100）：背驰后理论只保证回拉原中枢，回拉之后必须把所有可能情况与对策事先备齐；对真正的操作者没有任何情况是意外的。分类必须多层次（如30/5/1分钟），构成立体系统。

## 关键结论与规则
1. 长期持有某股的唯一理由：一个长期买点出现后，长期卖点还没到来（课28）。
2. 投资第一要点：手中的钱必须能长期稳定地留在股市，不能有任何借贷（课28）。
3. 技术分析只解决战术问题；战略问题（运作主力资金）超出其外。但散户无须知道馅饼怎么制造，只需知道怎么吃到（课66）。
4. 任何主力资金无论背景级别，都不能逆整个经济大势而行；不折腾就没有江湖地位（课66）。
5. 打仗不能假设明天的山头还在自己手里；操作只依当下触及的分类边界进行，利好利空不改变操作逻辑（课98）。
6. T+1对策：买比大盘略先一步的股票（而非完全逆势，逆势者常补跌），保证回转时有退出空间（课98）。
7. 能力与分类匹配：应付不了某种可能后果就不参与；都能应付就上；想培养能力就用小仓位（课100）。

## 常见误区与注意
- 信短线股评、每天N股推荐，不知不觉成了传销链条的一环（课51）。
- 追基金如追星，无视其借贷本性与赎回命门（课28）。
- 寻找自动给出买卖的万能拐杖（课97）。
- 基于对未来的假设而非当下条件操作（课98）。
- 小资金可用单层次分类，大资金必须多层次分类系统（课100）。

## 实战要点
- 操作前把后续所有可能情况与对策罗列清楚，答不齐就没资格操作（课98）。
- 走势图是世界上最昂贵的艺术品，多看以培养鉴赏力；热爱走势才能激发鉴赏力（课97）。
- 小资金把基金重仓股当"傻大个"观察其命门，理解短差与成本是攻击的核心（课28）。
