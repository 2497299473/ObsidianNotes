# 第五篇 同级别分解篇
> 涵盖课程：第33、36、38、39、40课
> 定位：合理走势分解是把握当下走势的关键，同级别分解是最简单的分解法

## 核心概念
- **走势的多义性**（课33）：同一段走势可以有多种合理读法，均与中枢有关。来源有三：中枢延伸导致级别升级、不同周期图对真实走势的简略模本、符合理论逻辑的多种合理释义。前两种可消除或忽略，第三种反而是多角度分析的工具。
- **结合律**（课36）：走势类型的连接满足 A+B+C＝(A+B)+C＝A+(B+C)，且A、B、C级别可以不同。据此任何走势都可以合法地重新组合，使结构更清晰、更利于操作。
- **同级别分解**（课38）：把所有走势按一个固定级别的走势类型进行分解。依据缠中说禅走势分解定理，这种分解具有唯一性，是最简单、不含糊的分解法。
- **级别换档**（课40）：小级别操作走出大级别行情时，若若干小级别段之和可重新分解为高一级别的同级别分解，即可切换到该级别节奏操作，如同开车按路况换档。
- **多重赋格**（课40）：大资金同时在多个级别上操作，每重对应不同资金、筹码、节奏与波动，各自独立又统一成整体，如赋格曲的多声部对位。

## 关键结论与规则
1. 多义性不是含糊性：多义性是站在严格精确的理论上用不同视角分析同一现象；含糊的理论没资格谈多义性（课36）。
2. 同级别分解两条规则：本级别不定义中枢延伸（次级别三段价格重合即中枢，延伸六段按两个盘整连接），允许盘整＋盘整；本级别以下允许延伸、不允许盘整＋盘整；以上级别不考虑（课38）。
3. 同级别分解具有唯一性，适合机械化操作：分解级别规定为30分钟，则30分钟上涨即牛市、否则熊市，无须判断市场实际状态（课38）。
4. 重新组合不涉及任何预测，只是对已走出走势的分解；组合要点是避繁就简——能避免中枢扩展的组合更有意义（课36）。
5. 围绕高级别中枢的震荡，最终必然可分解为若干次级别走势类型＋一个未完成的次级别走势a；a必完成，故其次级别第三类买卖点虽早于本级别买卖点，仍值得参与和重视（课36）。
6. 中枢延伸超过5段（连同形成中枢的三段）即构成更大级别中枢，借此可消除一种多义性（课33）。
7. 背驰可从中枢角度释义：顶背驰＝最后中枢向上离开比向下离开弱；中枢对上下离开的回拉作用相同，故向上离开也必被拉回中枢；盘整背驰同理（课33）。
8. a+A+b+B（B级别大于A）后不必然按原方向继续；反转段c与a+A+b比较力度，c弱则反转失败必回中枢，最强也至少要一次回拉确认第三类买点；MACD辅助时黄白线至少穿越0轴一次（课33）。
9. 当下判断的基础是所采取的分解方式：按5分钟分解已完成的走势，在30分钟分解中可能未完成；不同分解角度当下可见不同级别的未完成走势（课36）。

## 常见误区与注意
- 同级别分解允许盘整＋盘整；"不允许盘整＋盘整"只适用于非同级别分解方式，两者不可搞混（课38）。
- 同级别分解下的次级别不要求也做同级别分解；组合规则只需满足结合律与分解唯一性，以明晰易操作为准（课38）。
- 次级别第三类买卖点对次级别绝对安全，对本级别不一定（其后可能用一段走势回到本级别中枢继续震荡），但一旦其后出现趋势就须高度重视（课36）。
- 不预测、只分解：能否找到最合适的组合是功夫问题，只能在当下走势中不断磨练（课36）。
- 中枢延伸的定义是在两个中枢都完全走出后才适用；实操中第二个中枢往往还在延伸，此时可按有利原则当下组合（课36）。

## 实战要点
- 机械化操作程式（以30分钟为例，课38）：从下跌背驰买入开始→第一段向上按其内部背驰/盘整背驰卖点卖出→第二段向下若不破第一段低点则买回，跌破但与更前向下段盘整背驰也买回，否则观望等新下跌背驰→第三段向上若低于第一段高点先卖，超过第一段高点则看是否对第一段盘整背驰：背驰卖、不背驰持有→如此延续直到向上段不创新高或盘整背驰结束；向上段先买后卖，向下段先卖后买，完全对称。
- 精细化同级别操作（课39）：把a+A化为"a是本级别走势类型＋A含高一级中枢"；令a为A0，不断比较Ai与Ai+2的力度，盘整背驰则i+2为偶数时卖、奇数时买；若Ai+3不破Ai极值点则继续持有（不回补），直到Ai+k+3破Ai+k极值点后，在不创新极值或盘整背驰的Ai+k+4卖出（回补）。
- 操作韵律（课39）：最大的韵律是向上段先买后卖、向下段先卖后买；小段节奏错了就停止操作，先把心态与韵律调好再继续。
- 换档决策（课40）：当A0+…+At可重新分解为B1+B2（高一级别同级别分解）时，可按新级别节奏操作；是否换档取决于资金规模、时间与操作风格，小资金也值得在明显大级别向好时短线变中线。
- 围绕中枢的操作原则（课33）：向下离开出现底背驰可介入→看回拉顶背驰位置能否超越前次向上离开的顶背驰高点，不行必走→次级别回抽不回中枢即第三类买点必须买回；若底背驰后的次级别回拉不回中枢则第三类卖点必须走，之后等待新中枢重复此过程。
