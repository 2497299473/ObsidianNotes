# 第二篇 分型笔线段篇
> 涵盖课程：第62、65、67、69、71、77、78课
> 定位：最小级别中枢的构造基础——分型、笔、线段的定义与划分标准

## 核心概念
- **分型**（课62）：处理完包含关系后看相邻三根K线，中间一根高点最高且低点也最高为顶分型；低点最低且高点也最低为底分型。顶分型的最高点称"顶"，底分型的最低点称"底"。
- **包含关系**（课62、65）：一K线的高低区间完全落在另一K线区间内。合并看方向：向上时取高高点和较高的低点，向下时取低低点和较低的高点，合成新K线后按顺序继续比较。包含关系不满足传递律。
- **笔**（课62、65、77）：顶底分型交替连接而成，顶与底之间至少有一根不属于两个分型的独立K线。向上一笔＝底分型＋上升K线＋顶分型，向下反之。
- **线段**（课62、65、77、78）：至少由三笔构成且前三笔必须有重叠部分；所含笔数必为奇数；向上段必从向上笔开始、以向上笔结束。
- **特征序列**（课67）：向上段的笔序列记为S1X1S2X2…，其中与段方向相反的笔组成的序列X1X2…就是该段的特征序列；向下段取S序列。相邻元素无重合区间称为序列缺口。
- **标准特征序列**（课67）：把特征序列元素当作K线做包含（非包含）处理后的结果。之后像K线一样找分型：向上段只考察特征序列的顶分型，向下段只考察底分型。

## 关键结论与规则
1. 分型、笔、线段的划分客观唯一，与时间和人无关；当下分析与事后分析结果相同，唯一要求是被分析的K线已经走出（课65）。
2. 缠中说禅线段分解定理：线段被破坏，当且仅当至少被有重叠部分的连续三笔的其中一笔破坏；线段破坏的充要条件是被另一线段破坏（课65）。
3. 线段终结的两种情况（课67）：第一种，特征序列分型的第一、二元素间无缺口→线段直接终结于该分型极值点；第二种，有缺口→需从该极值点开始的反向序列的特征序列出现分型（不分第一第二种情况）才终结。
4. 特征序列元素的包含关系只在同一特征序列内讨论；转折点后的第一笔若直接破坏前段，属中间地带，不参与两边任何序列的包含处理；该笔一旦延伸出三笔且第三笔破第一笔终点，新线段必然成立（课71）。
5. 笔的划分唯一，实操三步：确定所有合格分型→同类分型中剔除非极值者（顶留更高、底留更低）→相邻顶底连成笔；连续同类分型时，取最先的一个与新出现的异类分型连成一笔（课77）。
6. 线段不可能被同方向的线段破坏；线段破坏可逆时间传递——被后段破坏的线段必然破坏了前线段，划分若违反此条必错（课77、78）。
7. 线段内最高或最低点若不是端点，在以此为基础的中枢等分析中可将线段标准化为高低点都在端点（课78）。
8. 图形未完成时分型允许修改，一旦完成不可更改；未完成性配合走势必完美原则，可把未来走势的边界条件收窄到极少可能（课69）。
9. 缺口力度三分类：不回补＝强势；回补后继续新高/新低＝平势；回补后不再新高/新低＝弱势（衰竭性缺口，至少引发比缺口所在趋势更大的级别调整）（课77）。

## 常见误区与注意
- 包含关系无传递性：第1、2根包含，第2、3根包含，不代表第1、3根包含；必须按顺序两根两根合并（课65）。
- 被笔破坏≠线段终结：笔破坏后若该方向形成不了特征序列分型，线段延续（课77、78）。
- 所有"古怪线段"（起点非极值点等）都源于第一种情况的笔破坏后未发展成线段破坏，属正常现象而非例外（课78）。
- 第二种情况的第二特征序列必须按包含关系处理，且不再分第一、二种情况——这是为避免线段串无限收敛倒推的麻烦（课77、78）。
- 两个同类分型相邻时：中间若有异类分型则照常分笔；若没有，只取更极值的一个，另一个不算笔的分型（课65、69）。
- 同一笔中顶分型最高点必须高于底分型最低点，否则划分必错；线段同理，顶必高于底（课77、78）。
- 实际划分不必从上市首日开始，但要知道这样对大走势缺乏完整认识（课78）。

## 实战要点
- 划笔三步法：①按包含关系处理后标出全部合格分型（顶用向下箭头、底用向上箭头）；②同类分型按"顶留更高、底留更低"剔除；③相邻顶底连成笔（课77）。
- 不熟练时按分型→笔→线段的顺序逐级划分，熟练后可心算直接分段（课78）。
- 实际划分一般从近期最高点或最低点起步（课78）。
- 任何周期图（1分钟到月线）标准完全相同；图上找不到分型就是没有，要更精细就换更小级别的图（课65、69）。
- 利用分型可修改性：图形未完成时，配合走势必完美，把未来走势的少数可能作为综合判断的关键条件（课69）。
