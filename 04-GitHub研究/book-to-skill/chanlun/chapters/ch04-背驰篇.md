# 第4篇 背驰篇
> 涵盖课程：24、25、27、29、37、43、44、61、64
> 定位：动力学部分——背驰判断是当下判断与转折预测的基础；含 MACD 辅助、盘整背驰、小级别背驰引发大转折、区间套

## 核心概念
- **A/B/C 三段结构**（课24）：比较背驰的前提——两段同向趋势 A、C，中间由盘整 B 连接，B 的中枢级别大于 A、C 内的中枢，且 A 之前还有一个与 B 同级别或更大的中枢；B 一般会把 MACD 黄白线回拉到 0 轴附近。
- **标准背驰**（课24、27）：趋势（至少两个同级别中枢）中，C 段对应的 MACD 柱子面积小于 A 段；背驰几乎只发生在第二个中枢之后，第一个中枢处只可能出现盘整背驰。
- **盘整背驰**（课24、27）：盘整中的类似力度比较，本质是企图脱离中枢的运动因力度不足被挡回中枢；比较的两段可以都是盘整；出现后分跌回中枢、不回中枢（转第三类买卖点）两种演化。
- **背驰段**（课27）：构成背驰或盘整背驰的那段走势类型。
- **区间套**（课27、61）：先定位大级别背驰段，再在次级别中找该段的背驰段，逐层收缩区间精确定位转折点；课61 用四重背驰段做了实战定位示范。
- **小级别引发大转折**（课43、44）：背驰级别小于当下走势级别时，转折并不必然回到原中枢，而是先形成比背驰级别大的中枢再选择突破，多出现在趋势冲顶赶底阶段。

## 关键结论与规则
1. 背驰-买卖点定理：任一背驰都必然制造某级别的买卖点，任一级别的买卖点都必然源自某级别的背驰（课24）。
2. 背驰-转折定理：某级别趋势背驰导致该趋势最后一个中枢的级别扩展、更大级别的盘整、或该级别以上级别的反趋势；即该级别原走势类型必然终止（课29、43）。
3. 趋势背驰成立后，回跌一定至少回到 B 段中枢区间，可预先知道最少跌幅（课24、25）。
4. 背驰有级别：小级别背驰不会制造大级别顶，除非大级别同时背驰；回跌力度取决于大级别位置——日线上涨初中段，5 分钟背驰只够打短差，日线上涨延伸阶段，1 分钟背驰足以引发暴跌（课24、25）。
5. 精确大转折点寻找：大级别转折点可由不同级别背驰段逐级收缩范围而确定（课27）。
6. a+A+b+B+c 须是趋势（A、B 同级别）才有背驰；c 必须是次级别且含 B 的第三类买卖点，b 级别不能大于 c；上涨 c 必创新高、下跌 c 必创新低（课37）。
7. 背驰级别=当下走势级别：必然拉回该走势最后一个中枢；背驰级别<当下级别：不必然回中枢，必先形成比背驰级别大的中枢再选方向，也可能走势继续延伸（课43）。
8. 小背驰-大转折定理：小级别顶背驰引发大级别向下的必要条件是最后一个次级别中枢出现第三类卖点（只必要非充分）；在其次级别中枢正常震荡的不转化（课44）。
9. "下跌+盘整"中盘整的中枢级别一定大于下跌的中枢级别；中枢扩展是未完成走势类型的延续，与两个已完成走势类型的连接不同（课29）。
10. 盘整背驰要求创新高/新低，不创新高/新低则背驰不成立（课61）。

## 常见误区与注意
- 均线系统（"吻"）与 MACD 同属或然性的辅助工具，不能与中枢理论混为一谈（课25）。
- 不是任何 a+A+b+B+c 都有背驰：没有趋势就没有背驰；A、B 级别不同时只能看作围绕较大中枢的震荡，最多按盘整背驰处理（课37）。
- 一看背驰就幻想跌 50% 或大级别反转，必须先看背驰的级别与大级别所处位置（课25、43）。
- 力度比较先搞清是哪两段比：围绕同一中枢两侧的两段才可相比，比错对象结论全错（课64）。
- 下上下结构中第二下刚破前低的一下力度最大，该处不可能出现背驰（课64）。
- MACD 只是辅助，精确判断最终要回到中枢本身；一字连续涨停时 MACD 失效，要看 1 分钟中枢是否持续上移（课24、25）。
- 盘整背驰与第三类买卖点的相互转化是必须分辨清楚的（课27、29）。

## 实战要点
- MACD 柱子伸长力度变慢时，已出现面积×2 即可当作该段面积，可在走势末段当下判断，不必等回跌（课24）。
- 盘整背驰中 C 上破中枢但面积小于 A：先出来；回跌不回中枢则在次级别第一类买点回补（恰构成第三类买点），跌回则继续盘整（课24）。
- 周线以上级别的盘整背驰往往对应历史性大底；大资金可越跌越买，小资金可自月线向日线以下逐级细分找精确买点（课27）。
- 抄底效率法：先买当下离最后一个中枢 DD 最远的超跌股，反弹第一波次级别背驰时出；再换反弹能到或突破该中枢且回试站稳的股，出现盘整背驰就出，不出则可能是 V 型反转（课29）。
- 严格按自己操作级别应对：本级别背驰直接行动；按 30 分钟操作就不因 1 分钟背驰清仓；小于操作级别的向下走势跌破第三类买点对应回试走势的高点，任何回抽先出来；筹码多时中枢出现第三类卖点先减半（课44、61）。
- c 段内部可再按次级别 a+A+b+B+c 分解，逐层嵌套定位背驰，越嵌套越精确（课37、61）。
- 标准两中枢上涨的 MACD 模版：0 轴上方停留形成第一中枢（第二类买点）→突破快速拉起（最有力度段）→回抽 0 轴形成第二中枢→再突破时黄白线或柱子不能创新高即背驰结束（课25）。
