# 第一篇 导引篇
> 涵盖课程：第72课
> 定位：缠中说禅本人为后来者制定的「懒人线路图」，说明总体学习顺序与各课程关系

## 核心概念
- **形态学**（课72）：理论中纯几何的部分，涵盖分型、笔、线段、中枢、走势类型等。它不依赖任何市场前提——哪怕一个庄家自买自卖，也逃不出形态学的框架。
- **动力学**（课72）：涉及背驰、中枢震荡、走势能量结构等内容，必须以「价格充分有效市场里的非完全绝对趋同交易」为前提才成立。
- **三＝两者的结合**（课72）：理论本质上分形态学与动力学两部分，"三"是两者的结合；所有买卖点归根结底都是第一类买卖点，必须两者合用才能说清。
- **懒人线路图**（课72）：分型 → 笔 → 线段 → 最小级别中枢 → 各级别中枢、走势类型。这是形态学中最基本、无法再简略的内容，再懒也必须先按此顺序搞清楚。
- **纯形态学操作**（课72）：不用背驰也能操作——对最后一个中枢回拉后，第一个与回拉反向、不创新高或新低的同级别离开，就是买卖段。能抓住第二买卖点，但抓不住第一买卖点。

## 关键结论与规则
1. 形态学无须前提；动力学需要「价格充分有效市场里的非完全绝对趋同交易」前提；理论整体上依然是几何（课72）。
2. 课程之所以形态学与动力学混着讲，是因为不说动力学就无法讲背驰、中枢震荡判别与第一类买卖点；若按正式课程顺序，应先讲形态学（课72）。
3. 课程由浅入深、先不严格后严格：未引入中枢前，上涨/盘整只能用高低点粗略定义；67课引入特征序列之前，关于线段的论述也不严格，此后才有精确定义（课72）。
4. 理解不了精确定义（如特征序列分型）可先用不精确的简化版，但必须精通一样东西，最怕半通不通（课72）。
5. 散户战胜市场的唯一途径是乘法原则下的技术面操作；基本面研究不如直接买指数基金或行业基金（课72）。
6. 光用形态学就足以形成有效操作体系；但实战中形态学＋动力学更有效，形态分析是动力学的基础（课72）。

## 常见误区与注意
- 不要以为只学形态学就够：对背驰没信心者可先从形态学入手，但最终要两者合用（课72）。
- 不要忽略中枢递归定义与从分型、笔、线段出发的最小级别定义之间的区别；不搞清楚虽不致命，但逻辑容易乱（课72）。
- 早期讲的均线系统与本理论无关，只是随手的漫谈，勿与正式理论混淆（课72）。
- 站在更大周期能看到更大方向：同一段调整，在周线视角下可能只是突破高位后的回抽（课72）。

## 实战要点
- 严格按线路图顺序过关：分型、笔、线段逐一搞熟，再进中枢与走势类型；实在懒，也至少把这五步走完（课72）。
- 读书时给概念归类：凡涉背驰、震荡、能量的属动力学；分型、笔、线段、中枢、走势类型属形态学（课72）。
- 纯形态学买卖段规则（回拉后第一个同级别反向不创新极值的离开）可作保底或简化操作模式（课72）。
- 均线偷懒参考：日线单边看5日线，5周线是中线关键，5月线是长线关系；牛市第一轮调整不会有效跌破5月线，首次跌破后等10、30月线上移构成新底部（课72）。
- 学习中务必把所有问题问出来、解决掉，精通一样胜过样样半通（课72）。
