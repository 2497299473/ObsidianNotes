# 第三篇 中枢、走势类型和买卖点
> 涵盖课程：17,83,18,63,20,21,35,101,102,53,56
> 定位：缠论的地基——走势终完美、中枢的生住坏灭、级别递归、走势类型分类、三类买卖点及其完备性。

## 核心概念
- **走势终完美**（课17/101/102）：原理一"任何级别的任何走势类型终要完成"。任何走势最终都要完成，完成后必转化为其他类型。数学实质：分型、笔、线段、各级走势类型的递归函数能把任何走势唯一分解，故走势可完全分类、可控。
- **中枢**（课17/18）：某级别走势类型中，至少三个连续次级别走势类型的重叠部分，由前三段重叠确定，区间=（三段低点取最大，三段高点取最小）。中枢本质是买卖双方反复较量的过程，越复杂说明赢家力量越弱（课83）。
- **级别**（课35/63/102）：打破中枢与走势类型循环定义的关键，从最低级别递归向上定义。走势客观，选级别分析主观；图表只是倍数不同的显微镜，图表级别≠走势级别。高级别的任何改变必从低级别开始（课102）。
- **走势类型**（课17/18）：盘整=只含一个中枢的完成走势类型；趋势=至少两个依次同向的中枢（上涨/下跌），且趋势内前后中枢绝对无重叠。
- **走势类型延伸**（课18）：唯一难点。趋势的延伸=同向同级别中枢不断产生；盘整的延伸=不产生新中枢。判断延伸是否结束的关键=是否产生新中枢。
- **级别扩张**（课20）：围绕连续两个同级别中枢的波动区间产生重叠，则生成更大级别中枢，此时不算趋势。
- **三类买卖点**（课17/20/21/53）：一类=该级别背驰转折点（中枢之下）；二类=一类买点后第一次次级别回调走势的结束点；三类=次级别离开中枢后回试不回中枢（低点不破ZG为买点，高点不升破ZD为卖点）。三类都是理论保证的100%安全买卖点，除此之外没有第四类（课21）。

## 关键结论与规则
1. 原理二：任何完成的走势类型必含一个以上中枢；分解定理一：任何走势可分解为盘整、下跌、上涨三类型的连接；分解定理二：任何走势类型至少由三段次级别走势类型构成（课17/35）。
2. 中枢生死（定理三）：中枢被破坏，当且仅当次级别走势离开后、次级别回抽不回中枢；最用力的破坏是"趋势+盘整"，底部突破后盘整回抽，其后上涨往往有力（课18）。
3. 级别延续定理一：更大级别中枢产生前，该级别走势类型将延续（别自己吓自己）；定理二：更大级别中枢产生当且仅当两个同级别中枢的波动区间重叠（课20）。
4. 中枢中心定理：中枢延伸等价于任意Zn区间与[ZD,ZG]重叠；前后两中枢的相对位置（GG/DD）完全决定下跌延续、上涨延续还是形成高级别中枢（课20）。
5. 买卖点完备性：市场必然产生赢利的买卖点只有三类；任何上涨或下跌都从三类买卖点中的某一类开始并结束（课21）。
6. 趋势转折定律：任何上涨转折由某级别第一类卖点构成，任何下跌转折由某级别第一类买点构成；任何级别的二类买卖点都由次级别相应走势的一类买卖点构成（课17）。
7. 买卖点级别定理：大级别买卖点必然是次级别以下某一级别的买卖点，不一定是次级别（课35）。
8. 最小中枢由线段而非笔构成：笔基于分型，一笔错单即可改变结构；线段破坏需特征序列分型确认，抗偶然干扰（课83）。
9. 走势类型连接运算满足结合律、不满足交换律，故高级别走势可重新拆分为次级别走势的连接（课35）。

## 常见误区与注意
- 把图表级别等同于走势级别：图只是显微镜，中枢与走势类型由递归定义保证，与看哪张图无关（课63/53）。
- 认为三类买卖点后必然是趋势：也可能进入更大级别盘整，走不出趋势就必须在盘整高点离场（课20）。
- 把任何一次回抽都当三类买卖点：必须是第一次回试/回抽才算（课20）。
- 中阴状态结束后还找一、二类买卖点：回升中阴结束后只剩三类买卖点与中枢震荡买卖点（课101）。
- 混用级别：确定操作级别后只处理该级别的买卖点，不参与该级别的调整与下跌（课35）。
- 幻想预判延续还是转折：当下延续与转折是两难，只能按完全分类应对，不能预测（课17/102）。
- 上涨趋势确立后不会再有一、二类买点，只可能有三类买点（课21）。

## 实战要点
- 先定操作级别：依据资金、T+1规则、交易成本与反应时间确定；该级别出现买卖点必须进出，可用次级别部分操作降低成本（成本为0才算真正脱离风险）（课35）。
- 突发消息大幅低开时，一类卖点已不可操作，唯一被理论保证的出场点是二、三类卖点，开盘前即可预先确定（课56）。
- 小级别转大级别时该级别没有一类买卖点，二类买卖点是最佳介入/离场位（课53）。
- 二、三类买点重合（一类买点直接上破前跌最后中枢且回抽不触及）往往对应大级别上涨，是最好补进机会（课21/101）。
- 一般操作用1、5、30分钟三个级别的分解足够，大资金加日线；大级别图用来记号辅助记忆、看MACD辅助背驰判断（课102/63）。
- 中枢级别足够大时可参与中枢震荡（用低级别买卖点），利润往往更大且稳定；最干脆的做法是不参与震荡，只在预设买卖点交易（课53）。
- 观察中枢复杂度：超复杂中枢之后走势往往反复；第二类线段破坏出现骨牌效应（分力趋同）时至少回到前一高低点范围，表现为V型（课83）。
