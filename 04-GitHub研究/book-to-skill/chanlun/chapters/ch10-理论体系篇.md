# 第10篇 理论体系篇
> 涵盖课程：30、52、81、84
> 定位：缠论自身的绝对性、哲学本质与必须注意的问题。

## 核心概念
- **价格充分有效市场**（课30）：交易以时间不可逆为前提完全等价地反映在价格轨迹上。纯交易角度除了价格与走势一无所有，理论只研究这条轨迹，不追问价格背后的决定因素。
- **非完全绝对趋同交易**（课30）：人的反应需要时间、社会结构多层、个体有差异，群体性交易不可能完全同时趋同，这是走势可分析的现实基础，也是理论的第二个界限。
- **不患与患**（课52）：以中枢、级别为基础的趋势与盘整等基本形态，以及事先确立的操作级别，是"不患"的、可绝对把握；具体点位只是基本形态当下演化出的"不患之患"，只能在当下把握。
- **自同构性结构**（课81、84）：即此前所称自相似结构的统一叫法。众人贪嗔痴疑慢的合力使分型、走势类型在各级别上同构复制，级别如同基因自组生长——理论的哲学本质即此种类生命现象。
- **零向量**（课30、84）：去掉自身贪惧，让自己成为加入合力而不改变总向量的零向量，才能感应合力的转折与破裂，这才是真正的顺势而为。

## 关键结论与规则
1. 理论只有两个界限：价格充分有效市场、非完全绝对趋同交易；界限之内永远绝对有效，多少人学、是否公开都不影响（课30）。
2. 唯一绝对可预测的是走势基本形态；背驰的级别一定不小于转折的级别，这是市场预测的最基础手段（课52）。
3. 有多少不同构的自同构性结构，就有多少种分析股市的正确道路；脱离自同构性结构的分析方法本质上都是错误的（课81）。
4. 所有的顶必是顶分型、所有的底必是底分型——没有顶分型就没有顶，操作级别图上无顶分型即可持有睡觉（课81）。
5. 视角的三个客观支点：走势不可重复→判断不可绝对预测；自同构性结构绝对复制→判断绝对可操作；理论纯逻辑推导→结论绝对有效（课84）。
6. 多级别联立如同联立方程，大幅压缩走势可能的解，因此必须立体地看走势（课81）。
7. 走势分解的唯一性由100%理论推导证明，这是理论最强大的力量所在（课84）。

## 常见误区与注意
- 上帝式思维：假定基本面、心理面等某种因素决定价格，或纠缠决定论/随机论，对交易毫无价值（课30）。
- 企图对点位做非当下的把握：点位是当下形成中的，逃离"不患"去谋其"患"是方向性错误（课52）。
- 把分型混同于分形：分形是经验归纳、有缺陷且划分不唯一；分型源自K线组合的完全分类，是纯理论推导（课84）。
- 把级别当时间结构：级别只是按规则自生长出的分类，对任何时间结构没有绝对承诺（课84）。
- 神化"当下"：反复提当下是为了破预测执念，最终要破的正是当下本身（课84）。
- 分型只是中枢递归定义的起始程序（f1），可用其他保证分解唯一性的定义替代；中枢的过程递归规则（f2）从未改变（课84）。
- MACD只是辅助判别，关键永远是走势分解本身（课84）。

## 实战要点
- 操作级别出现本级别顶背驰后绝对退出：其后必然是同级别下跌或扩展成更大级别的盘整，这是被理论绝对保证的预测（课52）。
- 广泛研究其他理论，用本理论的绝对视角定位其优劣、发现其操作程式的致命缺陷——这些缺陷就是将来猎杀其使用者的武器（独孤九剑式学习）（课84）。
- 最终比的是人本身：同样的理论在不同资金、水平、性格下呈现不同结果；心态与功力的细微差别积累下来足以令盈亏天差地别，要在交易中修炼、与走势合一（课30、52、84）。
