## 核心心智模型

**两块内容**：形态学（分型、笔、线段、中枢、走势类型——纯几何、不依赖任何市场前提）＋动力学（背驰、中枢震荡、能量结构——依赖「价格充分有效市场里的非完全绝对趋同交易」前提）；两者结合即全部买卖点，且归根结底都是第一类买卖点（课72）。

**递归骨架**：分型 → 笔 → 线段 → 最小级别中枢 → 各级别中枢 → 走势类型（盘整/趋势）→ 背驰 → 三类买卖点。级别按自同构性结构自下而上生长，与时间无本质关系（课81/84）。

**三根支柱**：①走势终完美——任何级别任何走势类型终要完成并转化，是一切操作的哲学基础（课17）；②唯一分解＋完全分类——好的分解必须唯一，走势可数量化精确分类，操作＝分段函数（课38/68/102）；③区间套——各级别背驰段逐级收缩，精确定位转折点（课27/61）。

**操作哲学**：买点买、卖点卖（节奏，课41）；只搞能搞的（课8/10）；不预测，让市场当下选择（课45/68）；0 成本是唯一真正安全（课31）；技术解决不了人的问题，贪嗔痴疑慢才是研究对象（课52/80）。
