# i-have-adhd 项目笔记

> 记录日期：2026-08-24 ｜ 项目：`ayghri/i-have-adhd`

## 一句话定位

一个让 AI 编码助手（Claude Code 等）**别把答案埋在一堆铺垫和废话里**的输出优化 Skill。灵感来自《The Adult ADHD Tool Kit》，核心目的是让 AI 输出"对 ADHD 友好"——直接、好扫读。

> "No ADHD diagnosis needed!" —— 适用人群不限于 ADHD，所有容易在长回复里走神/刷屏的人都需要。

## 技术要点

- **类型**：Agent 输出风格 Skill（SKILL.md 标准，供 Claude Code / Copilot CLI / Amp 等加载）
- **语言**：Python（本体为 skill 规则文件）
- **协议**：MIT
- **Stars**：约 23k

## 核心机制

通过一份 `SKILL.md`（output-style skill）注入编码 Agent 的系统提示，强制输出遵循一组规则。常见实现是"无内容隔离审查"（`kind: content_review`），让每个回复在被采用前按规则审查。

## 10 条输出规则

1. 先给出下一步行动
2. 多步骤任务用编号
3. 结尾给一个具体可执行的下一步（"打开 `src/auth.ts`" 也算）
4. 砍掉与问题无关的跑题内容
5. 长任务中定期重申当前进度
6. 给具体时间估计（分钟，不说"一会儿""很快"）
7. 让进展可见
8. 错误平铺直叙，不渲染情绪
9. 列表缩短（单条最好 ≤5 项）
10. 无开场白、无总结、无结尾寒暄
