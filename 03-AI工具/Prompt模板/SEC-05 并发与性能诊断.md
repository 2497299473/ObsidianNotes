## 适用场景

高并发交易、日终批量、对账批处理等场景下的性能问题诊断。覆盖死锁分析、连接池耗尽、GC 停顿、内存泄漏、缓存穿透等常见并发问题。

## 使用说明

诊断难度较高，建议**分两轮执行**。轮一收集症状和上下文，轮二给出根因假设和验证方法。两轮之间由开发者补充实际监控数据。

## 并发问题速查表

| 症状 | 最可能原因 | 优先检查 |
|------|-----------|----------|
| 接口超时但CPU不高 | 连接池耗尽/外部依赖慢 | 数据库连接数、线程 dump |
| CPU 突然飙高 | 死循环/频繁 Full GC | top -H + jstack |
| 间歇性 OOM | 内存泄漏/缓存无界增长 | heap dump + MAT 分析 |
| 偶发死锁 | 锁顺序不一致 | 数据库死锁日志 / jstack |
| 缓存穿透 | 大量不存在的 key 同时请求 | Redis 监控 + 布隆过滤器 |
| 日终批处理越来越慢 | 数据量增长 + 全表扫描 | 慢查询日志 + EXPLAIN |
