# 千问 3.6 27B 适配速查卡

> 每次写 Prompt 前扫一眼。贴在显示器旁边。

---

## 🚦 硬性上限

| 维度 | 上限 | 超限后果 |
|------|:--:|------|
| 每轮核心约束数 | **≤ 5 条** | 随机遗忘一半以上 |
| 单轮 prompt 总字数 | **< 1200 字** | "中间迷失"，指令权重衰减 |
| 连续对话轮数 | **≤ 6 轮** | 第 7 轮开始遗忘早期约束 |
| 单个代码块行数 | **≤ 100 行** | 超出部分逻辑丢失 |
| 并行检查维度 | **≤ 4 个** | 后期维度检查质量断崖下降 |

---

## ✅ 每次 Prompt 必做

1. **第一句贴系统指令**（见 [[内网开发 Prompt 模板集#零、系统指令前缀|系统指令前缀]]）
2. **输出格式前置**：先写"请按以下 Markdown 表格输出"，再写任务
3. **给退出口**：加一句"不确定就标注 [不确定]"
4. **禁止废话**：加"直接给结论，不要开场白/感谢/总结"

---

## ❌ 绝对不要做

- 一个 prompt 里塞多个独立任务（如"审查这段代码 + 顺便优化 SQL"）
- 不固定输出格式就问开放式问题
- 超过 6 轮不插 checkpoint（见 [[内网开发 Prompt 模板集#9.2|9.2]]）
- 让模型在没有代码上下文的情况下猜测代码行为
- 代码生成后不跑自审步骤（见 [[GEN-02 自审闭环代码生成|GEN-02]]）

---

## 📏 Prompt 长度自查

```
你的 Prompt 总字数（含代码）：
  < 800 字  ✅ 安全
  800-1200   ⚠️ 临界，简化
  > 1200     ❌ 拆成两轮
```

---

## 🔄 多轮对话节奏

```
轮 1: 贴系统指令 + 任务
轮 2: 继续（无需重复指令）
轮 3: 继续（无需重复指令）
轮 4: ⚡ 贴精简版系统指令 + checkpoint（见 9.2）
轮 5: 继续
轮 6: 继续
轮 7: ⚡ 贴精简版系统指令 + 关键约束重申
... 建议此时开新对话，粘贴 checkpoint
```
