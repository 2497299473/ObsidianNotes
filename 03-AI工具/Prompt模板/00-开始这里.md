## 30 秒速览

这套模板集帮你**把千问 3.6 27B 变成银行内网 AI 助手**。

**怎么用？** 找到场景 → 复制模板里的 prompt → 把 `{{}}` 替换成你的代码/日志/配置 → 粘贴到千问 → 得到结果。

**关键规则（27B 适配）**：
- 每轮 ≤ 5 条约束
- 单次 prompt < 1200 字
- 连续对话 ≤ 6 轮，第 4 轮插 checkpoint
- 每个模板都内置了"不确定就标注"的退出口

> 📋 详细规则见 [[27B 模型适配速查卡]]

## 三个最重要的习惯

1. **每次新对话第一句贴系统指令**（防废话 + 防幻觉）。模板见 [[内网开发 Prompt 模板集#零|原 零]]
2. **不确定就标注**。所有模板都内置了退出口——信息不足时说"无法确定"，不编造
3. **每 4 轮插 checkpoint**。长对话用 [[内网开发 Prompt 模板集#9.2|原 9.2]] 保存状态
