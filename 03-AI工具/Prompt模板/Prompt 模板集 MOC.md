## 🔗 工作流推荐链路

### 链路 1：新功能开发全流程
```
需求分析(10.1) → 边界确认(5.6) → 代码生成(GEN-02) → 安全审查(SEC-01) → 测试生成(14.2) → 变更风险(SEC-03)
```

### 链路 2：Bug 修复全流程
```
日志排查(SEC-06) → Bug定位(3.1~3.4) → 修复流水线(3.5) → 回归验证(14.5) → 变更风险(SEC-03)
```

### 链路 3：遗留系统接手
```
项目上手(4.12) → 遗留逆向(LEG-01) → 代码审查(1.1) → 安全审查(SEC-01) → 重构(5.2)
```

### 链路 4：生产变更
```
变更风险(SEC-03) → 幂等检查(SEC-04) → 并发诊断(SEC-05) → 日志监控(SEC-06)
```

## 🏷️ 模板类型说明

| 标记 | 含义 |
|------|------|
| **原子模板** | 单次对话独立完成，无需多轮 |
| **工作流模板** | 多步骤串联，需按阶段执行（每阶段确认后再进入下一阶段） |
| **系统模板** | 全局有效，每次对话必贴 |
