# MotionSites.ai

**日期**: 2026-08-02
**来源**: https://motionsites.ai/

## 是什么

MotionSites.ai 是一个 **AI 网站 Prompt 精选库**，不是传统的网站构建器。

核心玩法：
1. 浏览 65+ 个精选动画网站设计（有视频/图片预览）
2. 找到喜欢的 → 复制 Prompt
3. 粘贴到 AI 编程工具（Lovable、Bolt、Cursor、Claude Code 等）
4. AI 直接生成完整的三维动画网站/组件

## 覆盖类别

SaaS 落地页、个人作品集（Portfolio）、企业官网、电商页面、Hero 动画区、404 页面、网络安全、旅游、房地产等。

## 核心卖点

- 三维动画 Hero Section（视差滚动、鼠标追踪、滚动动画）
- 视觉预览 → 复制 Prompt → 粘贴即生成
- 有 Academy 教程
- 有 Lifetime 买断方案（含商业授权）
- 免费 Prompt 和 Premium Prompt 分开，Premium 需付费

## 探索路径

1. 首页 → motionsites.ai，看 Featured 视频预览

4. 试用 → 找免费 Prompt，粘贴到 Cursor/Claude Code 试效果
