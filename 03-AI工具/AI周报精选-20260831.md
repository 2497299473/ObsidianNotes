## MCP-Builder.ai

- **是什么**：SaaS（Product Hunt 2026-08-26 上榜），定位 "Lovable for MCP connectors"——自然语言描述需求 → 几分钟生成**托管的、带企业级鉴权的 MCP Server**，把数据库 / REST API / XML / CSV / FTP / 第三方应用暴露给 Claude、ChatGPT、Cursor 等
- **安全是主打卖点**（行业背景：2026 年公开扫描显示公共 MCP Server 38–41% 完全无鉴权）
  - OAuth 2.0 / API Key / JWT / 自定义 IdP 开箱即用
  - 细粒度访问控制 + 每次工具调用全量审计日志
  - 全链路 TLS，凭证静态加密存储
- **"数据不落盘"承诺**：数据在请求时读取并转发，服务端不持久化（企业采购关键话术，实际以合同定义为准）
- **EU 托管可选**（合规向）
- 企业档：不限 Server / 请求 / 工具数、自定义域名、MCP Cloud Gateway、可自带 LLM Key、白标 Chat 前端、可自建用户体系、观测性堆栈；**支持 On-Premise**（部署到自己环境）
- 定价：有免费档（足够 PoC），企业档 Contact Sales
- **关联度**（⭐⭐⭐）：全栈 / DevOps 下把内部 API / 数据库最快暴露给 Agent 的路子；价值在省时 + 托管运维 + 审计合规，偏工具而非研究方向（自己能写 MCP Server）
- ⚠️ 生产凭证别贴进生成对话；敏感系统用 On-Premise 模式
- **试用**：免费档 + 一个已有 REST API（如基金参谋行情接口）→ 生成 server → 接 Claude Code 跑通一轮
- 链接：https://mcp-builder.ai

## Framer AI Agents

- **⚠️ 信息修正**：非 8/25 新功能。Agents 是 **2026-06-16 随 Framer 3.0 发布**（当天 PH 日榜 #1），8/25 只是二次上榜
- **Framer 3.0 发布内容**：
  1. **Framer Agents**：Agent 直接活在**设计画布里**（非独立聊天窗口）——生成页面（从零 / 从截图）、响应式布局与断点、组件创建、样式与交互、**写自定义代码**、CMS 内容管理、站点审计（死链 / 无障碍 / 样式一致性）、SEO 设置、发布工作流
  2. **Branching（分支）**：Agent 改动落隔离分支 → 人工审查对比 → 合并 → 发布（让 Agent 改生产站可接受的关键机制；也说明官方承认 Agent 产出是"草稿"）
  3. **External Agents**：把 **Claude Code / Cursor / Codex / Gemini CLI** 接进来，直接创建 / 编辑 / 审计 / 管理 Framer 项目——开发者不用切进画布，在现有环境驱动站点变更
  4. 配套：AI credits 计量 Agent 用量；Framer Community 创作者平台（2025 年付创作者 $6.5M，同比 +200%）；计划与编辑器降价
- **边界**（第三方评测一致判断）：强于"网站层"（访客看到的 + CMS），**不碰**后端逻辑、数据管道、转化后跨系统工作流（支付 / CRM / 通知）
- **关联度**（⭐⭐）：纯产品观察项；若以后搭落地页 / 作品集（MotionSites 链路），"Claude Code 直接改 Framer + 分支审查"可作候选方案
- 链接：https://www.framer.com/blog/framer-3
